`nuxt.config` 파일 확장자는 `.js`, `.ts` 또는 `.mjs`가 될 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  // 나의 Nuxt 설정
})
```

::tip
`defineNuxtConfig` 헬퍼는 import 없이 전역에서 사용할 수 있습니다.
::

원한다면 `defineNuxtConfig`를 `nuxt/config`에서 명시적으로 import할 수도 있습니다:

```ts twoslash [nuxt.config.ts]
import { defineNuxtConfig } from 'nuxt/config'

export default defineNuxtConfig({
  // 나의 Nuxt 설정
})
```

::read-more{to="/docs/4.x/api/configuration/nuxt-config"}
**Nuxt 설정** 문서에서 사용 가능한 모든 옵션을 확인하세요.
::

구성이 최신 상태인지 확인하기 위해, Nuxt는 기본 설정 파일, [`.env`](/docs/4.x/directory-structure/env), [`.nuxtignore`](/docs/4.x/directory-structure/nuxtignore) 및 [`.nuxtrc`](/docs/4.x/directory-structure/nuxtrc) 점(dot) 파일에서 변경 사항을 감지하면 전체 재시작을 수행합니다.
