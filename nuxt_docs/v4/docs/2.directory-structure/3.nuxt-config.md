`nuxt.config` 파일 확장자는 `.js`, `.ts`, `.mjs` 중 하나일 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  // 내 Nuxt 설정
})
```

::tip
`defineNuxtConfig` 헬퍼는 import 없이 전역에서 사용할 수 있습니다.
::

원한다면 `nuxt/config`에서 `defineNuxtConfig`를 명시적으로 import할 수도 있습니다:

```ts twoslash [nuxt.config.ts]
import { defineNuxtConfig } from 'nuxt/config'

export default defineNuxtConfig({
  // 내 Nuxt 설정
})
```

::read-more{to="/docs/4.x/api/configuration/nuxt-config"}
**Nuxt 설정** 문서에서 사용 가능한 모든 옵션을 확인하세요.
::

설정이 최신 상태로 유지되도록 Nuxt는 메인 설정 파일과 [`.env`](/docs/4.x/directory-structure/env), [`.nuxtignore`](/docs/4.x/directory-structure/nuxtignore), [`.nuxtrc`](/docs/4.x/directory-structure/nuxtrc) dotfile의 변경을 감지하면 전체 재시작을 수행합니다.
