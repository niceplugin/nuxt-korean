Nuxt는 프로젝트에 권장되는 기본 TypeScript 설정, [auto-import](/docs/4.x/guide/concepts/auto-imports) 참조, [API route 타입](/docs/4.x/guide/concepts/server-engine#typed-api-routes), 경로 별칭 등을 포함하는 여러 TypeScript 설정 파일(`.nuxt/tsconfig.app.json`, `.nuxt/tsconfig.server.json`, `.nuxt/tsconfig.node.json`, `.nuxt/tsconfig.shared.json`)을 [자동으로 생성](/docs/4.x/guide/concepts/typescript#auto-generated-types)합니다.

Nuxt 프로젝트 루트에는 다음과 같은 `tsconfig.json` 파일이 있어야 합니다:

```json [tsconfig.json]
{
  "files": [],
  "references": [
    {
      "path": "./.nuxt/tsconfig.app.json"
    },
    {
      "path": "./.nuxt/tsconfig.server.json"
    },
    {
      "path": "./.nuxt/tsconfig.shared.json"
    },
    {
      "path": "./.nuxt/tsconfig.node.json"
    }
  ]
}
```

::warning
이 파일의 내용을 직접 수정하는 것은 권장하지 않습니다. 그렇게 하면 Nuxt나 다른 모듈이 의존하는 중요한 설정을 덮어쓸 수 있기 때문입니다. 대신 `nuxt.config.ts`를 통해 확장하세요.
::

::read-more{to="/docs/4.x/guide/concepts/typescript#project-references"}
Nuxt 프로젝트의 서로 다른 타입 컨텍스트에 대해 더 알아보세요.
::

## TypeScript 설정 확장 %{#extending-typescript-configuration}%

`nuxt.config.ts` 파일에서 각 컨텍스트(`app`, `shared`, `node`, `server`)별로 Nuxt 프로젝트의 TypeScript 설정을 사용자 정의할 수 있습니다.
<!-- @case-police-ignore tsConfig -->
```ts twoslash [nuxt.config.ts]
// @errors: 2353
export default defineNuxtConfig({
  typescript: {
    // tsconfig.app.json 사용자 정의
    tsConfig: {
      // ...
    },
    // tsconfig.shared.json 사용자 정의
    sharedTsConfig: {
      // ...
    },
    // tsconfig.node.json 사용자 정의
    nodeTsConfig: {
      // ...
    },
  },
  nitro: {
    typescript: {
      // tsconfig.server.json 사용자 정의
      tsConfig: {
        // ...
      },
    },
  },
})
```
