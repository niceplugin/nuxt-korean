::important
빌드 출력물이 저장소에 푸시되지 않도록 이 디렉터리를 [`.gitignore`](/docs/4.x/directory-structure/gitignore) 파일에 추가해야 합니다.
::

이 디렉터리를 사용해 Nuxt 애플리케이션을 프로덕션에 배포합니다.

:read-more{to="/docs/4.x/getting-started/deployment"}

::warning
전체 디렉터리가 [`nuxt build`](/docs/4.x/api/commands/build) 실행 시 다시 생성되므로 내부 파일은 건드리지 말아야 합니다.
::
