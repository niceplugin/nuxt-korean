::important
이 디렉터리는 빌드 결과물이 저장되는 곳이므로, 저장소에 푸시되지 않도록 [`.gitignore`](/docs/4.x/directory-structure/gitignore) 파일에 추가해야 합니다.
::

이 디렉터리를 사용하여 Nuxt 애플리케이션을 프로덕션 환경에 배포할 수 있습니다.

:read-more{to="/docs/4.x/getting-started/deployment"}

::warning
[`nuxt build`](/docs/4.x/api/commands/build)를 실행할 때 전체 디렉터리가 다시 생성되므로, 내부의 어떤 파일도 수정해서는 안 됩니다.
::
