`shared/` 디렉터리를 사용하면 Vue 앱과 Nitro 서버 양쪽에서 사용할 수 있는 코드를 공유할 수 있습니다.

::note
`shared/` 디렉터리는 Nuxt v3.14+에서 사용할 수 있습니다.
::

::important
`shared/` 디렉터리 안의 코드는 어떤 Vue 또는 Nitro 코드도 import할 수 없습니다.
::

## 사용법 %{#usage}%

**방법 1:** 이름 있는 export

```ts twoslash [shared/utils/capitalize.ts]
export const capitalize = (input: string) => {
  return input[0] ? input[0].toUpperCase() + input.slice(1) : ''
}
```

**방법 2:** 기본 export

```ts twoslash [shared/utils/capitalize.ts]
export default function (input: string) {
  return input[0] ? input[0].toUpperCase() + input.slice(1) : ''
}
```

이제 [자동 import되는](/docs/4.x/directory-structure/shared) 유틸리티를 Nuxt 앱과 `server/` 디렉터리에서 사용할 수 있습니다.

```vue [app/app.vue]
<script setup lang="ts">
const hello = capitalize('hello')
</script>

<template>
  <div>
    {{ hello }}
  </div>
</template>
```

```ts [server/api/hello.get.ts]
export default defineEventHandler((event) => {
  return {
    hello: capitalize('hello'),
  }
})
```

## 파일 스캔 방식 %{#how-files-are-scanned}%

`shared/utils/`와 `shared/types/` 디렉터리 안의 파일만 auto-import됩니다. 이 디렉터리의 하위 디렉터리에 중첩된 파일은 `imports.dirs`와 `nitro.imports.dirs`에 해당 디렉터리를 추가하지 않는 한 auto-import되지 않습니다.

::tip
`shared/utils`와 `shared/types`의 auto-import 동작 방식과 스캔 방식은 [`app/composables/`](/docs/4.x/directory-structure/app/composables) 및 [`app/utils/`](/docs/4.x/directory-structure/app/utils) 디렉터리와 동일합니다.
::

:read-more{to="/docs/4.x/directory-structure/app/composables#how-files-are-scanned"}

```bash [Directory Structure]
-| shared/
---| capitalize.ts        # 자동 import되지 않음
---| formatters
-----| lower.ts           # 자동 import되지 않음
---| utils/
-----| lower.ts           # 자동 import됨
-----| formatters
-------| upper.ts         # 자동 import되지 않음
---| types/
-----| bar.ts             # 자동 import됨
```

`shared/` 폴더 안에 만드는 다른 파일은 `#shared` 별칭(Nuxt가 자동 설정함)을 사용해 수동으로 import해야 합니다:

```ts
// shared 디렉터리 바로 아래 파일용
import capitalize from '#shared/capitalize'

// 중첩 디렉터리 안의 파일용
import lower from '#shared/formatters/lower'

// utils 안의 하위 폴더에 있는 파일용
import upper from '#shared/utils/formatters/upper'
```

이 별칭은 import하는 파일의 위치와 관계없이 애플리케이션 전반에서 일관된 import를 보장합니다.
