애플리케이션이 동작하는 동안 일부 오류가 런타임에 예기치 않게 나타날 수 있습니다. 이런 경우 `error.vue` 파일을 사용해 기본 오류 파일을 덮어쓰고 오류를 보기 좋게 표시할 수 있습니다.

```vue [error.vue]
<script setup lang="ts">
import type { NuxtError } from '#app'

const props = defineProps<{ error: NuxtError }>()
</script>

<template>
  <div>
    <h1>{{ error.status }}</h1>
    <NuxtLink to="/">홈으로 돌아가기</NuxtLink>
  </div>
</template>
```

::note
'오류 페이지'라고 부르지만 이는 라우트가 아니며 `~/pages` 디렉터리에 두어서는 안 됩니다. 같은 이유로 이 페이지 안에서는 `definePageMeta`를 사용해서도 안 됩니다. 다만 [`NuxtLayout`](/docs/4.x/api/components/nuxt-layout) 컴포넌트를 사용하고 레이아웃 이름을 지정하면 오류 파일 안에서도 레이아웃을 사용할 수 있습니다.
::

오류 페이지에는 처리할 오류를 담고 있는 단 하나의 prop `error`가 있습니다.

`error` 객체는 다음 필드를 제공합니다:
```ts
interface NuxtError {
  status: number
  fatal: boolean
  unhandled: boolean
  statusText?: string
  data?: unknown
  cause?: unknown
}
```

사용자 정의 필드가 있는 오류를 사용하면 그 필드는 사라지므로 대신 `data`에 할당해야 합니다:

```ts
throw createError({
  status: 404,
  statusText: 'Page Not Found',
  data: {
    myCustomField: true,
  },
})
```
