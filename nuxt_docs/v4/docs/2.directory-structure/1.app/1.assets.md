이 디렉터리에는 일반적으로 다음 유형의 파일이 들어 있습니다:

- 스타일시트(CSS, SASS 등)
- 폰트
- [`public/`](/docs/4.x/directory-structure/public) 디렉터리에서 제공되지 않을 이미지

서버에서 에셋을 제공하고 싶다면 [`public/`](/docs/4.x/directory-structure/public) 디렉터리를 살펴보는 것을 권장합니다.
