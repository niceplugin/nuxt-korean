## 레이아웃 활성화 %{#enable-layouts}%

[`app.vue`](/docs/4.x/directory-structure/app/app)에 [`<NuxtLayout>`](/docs/4.x/api/components/nuxt-layout)를 추가하면 레이아웃이 활성화됩니다:

```vue [app/app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

레이아웃을 사용하려면:
- 페이지에서 [definePageMeta](/docs/4.x/api/utils/define-page-meta)로 `layout` 속성을 설정합니다.
- `<NuxtLayout>`의 `name` prop을 설정합니다.
- route rules에서 `appLayout` 속성을 설정합니다.

::note
레이아웃 이름은 kebab-case로 정규화되므로 `someLayout`은 `some-layout`이 됩니다.
::

::note
레이아웃을 지정하지 않으면 `app/layouts/default.vue`가 사용됩니다.
::

::important
애플리케이션에 레이아웃이 하나뿐이라면 대신 [`app.vue`](/docs/4.x/directory-structure/app/app)를 사용하는 것을 권장합니다.
::

::important
다른 컴포넌트와 달리 레이아웃은 Nuxt가 레이아웃 변경 사이에 트랜지션을 적용할 수 있도록 단일 루트 요소를 가져야 하며, 이 루트 요소는 `<slot />`일 수 없습니다.
::

## 기본 레이아웃 %{#default-layout}%

`~/layouts/default.vue`를 추가합니다:

```vue [app/layouts/default.vue]
<template>
  <div>
    <p>모든 페이지에서 공유되는 기본 레이아웃 콘텐츠입니다</p>
    <slot />
  </div>
</template>
```

레이아웃 파일에서는 페이지의 콘텐츠가 `<slot />` 컴포넌트 안에 표시됩니다.

## 이름 있는 레이아웃 %{#named-layout}%

```bash [Directory Structure]
-| layouts/
---| default.vue
---| custom.vue
```

그러면 페이지에서 `custom` 레이아웃을 사용할 수 있습니다:

```vue twoslash [pages/about.vue]
<script setup lang="ts">
declare module 'nuxt/app' {
  interface NuxtLayouts {
    'custom': unknown
  }
}
// ---cut---
definePageMeta({
  layout: 'custom',
})
</script>
```

::read-more{to="/docs/4.x/directory-structure/app/pages#page-metadata"}
`definePageMeta`에 대해 더 알아보세요.
::

[`<NuxtLayout>`](/docs/4.x/api/components/nuxt-layout)의 `name` 속성을 사용하면 모든 페이지의 기본 레이아웃을 직접 덮어쓸 수 있습니다:

```vue [app/app.vue]
<script setup lang="ts">
// API 호출 결과나 로그인 상태를 기준으로 이를 선택할 수 있습니다
const layout = 'custom'
</script>

<template>
  <NuxtLayout :name="layout">
    <NuxtPage />
  </NuxtLayout>
</template>
```

중첩 디렉터리에 레이아웃이 있으면 레이아웃 이름은 해당 경로의 디렉터리와 파일명을 기준으로 하며, 중복 구간은 제거됩니다.

File | Layout Name
-- | --
`~/layouts/desktop/default.vue` | `desktop-default`
`~/layouts/desktop-base/base.vue` | `desktop-base`
`~/layouts/desktop/index.vue` | `desktop`

명확성을 위해 레이아웃 파일명이 이름과 일치하도록 하는 것을 권장합니다:

File | Layout Name
-- | --
`~/layouts/desktop/DesktopDefault.vue` | `desktop-default`
`~/layouts/desktop-base/DesktopBase.vue` | `desktop-base`
`~/layouts/desktop/Desktop.vue` | `desktop`

## 동적으로 레이아웃 변경하기 %{#changing-the-layout-dynamically}%

[`setPageLayout`](/docs/4.x/api/utils/set-page-layout) 헬퍼를 사용해 레이아웃을 동적으로 변경할 수도 있습니다:

```vue twoslash [app/pages/index.vue]
<script setup lang="ts">
declare module 'nuxt/app' {
  interface NuxtLayouts {
    'custom': unknown
  }
}
// ---cut---
function enableCustomLayout () {
  setPageLayout('custom')
}
definePageMeta({
  layout: false,
})
</script>

<template>
  <div>
    <button @click="enableCustomLayout">
      레이아웃 업데이트
    </button>
  </div>
</template>
```

route rules의 `appLayout` 속성을 사용해 특정 라우트에 레이아웃을 설정할 수도 있습니다:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    // 특정 라우트에 레이아웃 설정
    '/admin': { appLayout: 'admin' },
    // 여러 라우트에 레이아웃 설정
    '/dashboard/**': { appLayout: 'dashboard' },
    // 라우트의 레이아웃 비활성화
    '/landing': { appLayout: false },
  },
})
```

::tip
이 방법은 각 페이지 파일이 아니라 설정에서 레이아웃을 중앙 관리하고 싶을 때, 또는 대응하는 페이지 컴포넌트가 없는 라우트(예: 많은 경로와 매칭될 수 있는 catchall 페이지)에 레이아웃을 적용해야 할 때 유용합니다.
::

## 레이아웃에 Props 전달하기 :badge[+4.4]{color="primary" class="align-middle"} %{#passing-props-to-layouts}%

여러 가지 방법으로 레이아웃에 props를 전달할 수 있습니다.

### `definePageMeta`를 통해 %{#via-definepagemeta}%

페이지에서 직접 props를 전달하려면 `layout` 속성에 객체 문법을 사용합니다:

::code-group

```vue [app/pages/dashboard.vue]
<script setup lang="ts">
definePageMeta({
  layout: {
    name: 'panel',
    props: {
      sidebar: true,
      title: '대시보드',
    },
  },
})
</script>
```

```vue [app/layouts/panel.vue]
<script setup lang="ts">
const props = defineProps<{
  sidebar?: boolean
  title?: string
}>()
</script>

<template>
  <div>
    <aside v-if="sidebar">
      사이드바
    </aside>
    <main>
      <h1>{{ title }}</h1>
      <slot />
    </main>
  </div>
</template>
```

::

::tip
props는 레이아웃의 `defineProps`를 기준으로 완전히 타입 지정됩니다. 에디터에서 자동 완성과 타입 검사를 받을 수 있습니다.
::

### `setPageLayout`를 통해 %{#via-setpagelayout}%

[`setPageLayout`](/docs/4.x/api/utils/set-page-layout)로 레이아웃을 동적으로 변경할 때도 props를 전달할 수 있습니다:

```ts
setPageLayout('panel', { sidebar: true, title: '대시보드' })
```

## 페이지별로 레이아웃 덮어쓰기 %{#overriding-a-layout-on-a-per-page-basis}%

pages를 사용 중이라면 `layout: false`를 설정한 뒤 페이지 안에서 `<NuxtLayout>` 컴포넌트를 사용해 완전히 제어할 수 있습니다.

::code-group

```vue [app/pages/index.vue]
<script setup lang="ts">
definePageMeta({
  layout: false,
})
</script>

<template>
  <div>
    <NuxtLayout name="custom">
      <template #header>
        일부 헤더 템플릿 콘텐츠입니다.
      </template>

      페이지의 나머지 내용
    </NuxtLayout>
  </div>
</template>
```

```vue [app/layouts/custom.vue]
<template>
  <div>
    <header>
      <slot name="header">
        기본 헤더 콘텐츠
      </slot>
    </header>
    <main>
      <slot />
    </main>
  </div>
</template>
```

::

::important
페이지 안에서 `<NuxtLayout>`을 사용한다면 이것이 루트 요소가 아니도록 하세요(또는 [레이아웃/페이지 트랜지션을 비활성화](/docs/4.x/getting-started/transitions#disable-transitions)하세요).
::
