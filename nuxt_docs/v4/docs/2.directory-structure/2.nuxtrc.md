`.nuxtrc` 파일을 사용하면 평평한 문법으로 Nuxt를 설정할 수 있습니다. 이 파일은 [`unjs/rc9`](https://github.com/unjs/rc9)을 기반으로 합니다.

::tip
더 고급 설정이 필요하다면 [`nuxt.config`](/docs/4.x/directory-structure/nuxt-config)를 사용하세요.
::

## 사용법 %{#usage}%

```bash [.nuxtrc]
# SSR 비활성화
ssr=false

# `@nuxt/devtools` 설정
devtools.enabled=true

# Nuxt 모듈 추가
modules[]=@nuxt/image
modules[]=nuxt-security

# 모듈 설정 상태 (Nuxt가 자동 추가)
setups.@nuxt/test-utils="3.23.0"
```

`nuxt.config` 파일에 동일한 속성이 있으면 `.nuxtrc` 파일의 속성을 덮어씁니다.

::note
Nuxt는 모듈 설치와 업그레이드 상태를 추적하기 위해 `setups` 섹션을 자동으로 추가합니다. 이는 [모듈 라이프사이클 훅](/docs/4.x/api/kit/modules#using-lifecycle-hooks-for-module-installation-and-upgrade)에 내부적으로 사용되며 수동으로 수정해서는 안 됩니다.
::

::read-more{to="/docs/4.x/api/configuration/nuxt-config"}
**Nuxt 설정** 문서에서 사용 가능한 모든 옵션을 확인하세요.
::

## 전역 `.nuxtrc` 파일 %{#global-nuxtrc-file}%

홈 디렉터리에 전역 `.nuxtrc` 파일을 만들어 설정을 전역으로 적용할 수도 있습니다.

- macOS/Linux에서는 이 파일이 다음 위치에 있습니다:

  ```md
  ~/.nuxtrc
  ```

- Windows에서는 다음 위치에 있습니다:

  ```md
  C:\Users\{username}\.nuxtrc
  ```

이 전역 `.nuxtrc` 파일을 사용하면 시스템의 모든 Nuxt 프로젝트에 적용되는 기본 설정을 정의할 수 있습니다. 다만 프로젝트 수준 `.nuxtrc` 파일이 이 전역 설정을 덮어쓰며, `nuxt.config`가 둘보다 우선합니다.
