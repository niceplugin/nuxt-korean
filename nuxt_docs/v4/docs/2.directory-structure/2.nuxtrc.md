`.nuxtrc` 파일은 평면 문법으로 Nuxt를 설정하는 데 사용할 수 있습니다. [`unjs/rc9`](https://github.com/unjs/rc9)를 기반으로 합니다.

::tip
더 고급 설정이 필요하다면 [`nuxt.config`](/docs/4.x/directory-structure/nuxt-config)를 사용하세요.
::

## Usage %{usage}%

```bash [.nuxtrc]
# SSR 비활성화
ssr=false

# `@nuxt/devtools` 설정
devtools.enabled=true

# Nuxt 모듈 추가
modules[]=@nuxt/image
modules[]=nuxt-security
```

`nuxt.config` 파일에 속성이 존재하는 경우, `.nuxtrc` 파일의 속성보다 우선하여 덮어씁니다.

::note
Nuxt는 모듈 설치 및 업그레이드 상태를 추적하기 위해 자동으로 `setups` 섹션을 추가합니다. 이는 [모듈 라이프사이클 훅](/docs/4.x/api/kit/modules#using-lifecycle-hooks-for-module-installation-and-upgrade)에 내부적으로 사용되며, 수동으로 수정해서는 안 됩니다.
::

::read-more{to="/docs/4.x/api/configuration/nuxt-config"}
**Nuxt configuration** 문서에서 사용 가능한 모든 옵션을 확인하세요.
::

## Global `.nuxtrc` File %{global-nuxtrc-file}%

홈 디렉터리에 전역 `.nuxtrc` 파일을 생성하여 전역적으로 설정을 적용할 수도 있습니다.

- macOS/Linux에서는 이 파일이 다음 위치에 있습니다:

  ```md
  ~/.nuxtrc
  ```

- Windows에서는 다음 위치에 있습니다:

  ```md
  C:\Users\{username}\.nuxtrc
  ```

이 전역 `.nuxtrc` 파일을 사용하면 시스템의 모든 Nuxt 프로젝트에 적용되는 기본 설정을 정의할 수 있습니다. 그러나 프로젝트 수준의 `.nuxtrc` 파일이 이러한 전역 설정을 재정의하며, `nuxt.config`가 둘 다보다 우선합니다.
