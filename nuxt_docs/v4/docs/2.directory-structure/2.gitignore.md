`.gitignore` 파일은 git이 무시해야 하는 의도적으로 추적되지 않는 파일을 지정합니다.

:read-more{icon="i-simple-icons-git" title="git 문서" to="https://git-scm.com/docs/gitignore" target="_blank"}

`.gitignore` 파일에 **최소한** 다음 항목이 포함되어 있기를 권장합니다:

```bash [.gitignore]
# Nuxt 개발/빌드 출력물
.output
.data
.nuxt
.nitro
.cache
dist

# Node 의존성
node_modules

# 로그
logs
*.log

# 기타
.DS_Store

# 로컬 env 파일
.env
.env.*
!.env.example
```
