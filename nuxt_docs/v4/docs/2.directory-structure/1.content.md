[Nuxt Content](https://content.nuxt.com)는 프로젝트의 `content/` 디렉터리를 읽고 `.md`, `.yml`, `.csv`, `.json` 파일을 파싱하여 애플리케이션용 파일 기반 CMS를 생성합니다.

- 내장 컴포넌트로 콘텐츠를 렌더링합니다.
- MongoDB와 유사한 API로 콘텐츠를 조회합니다.
- MDC 문법으로 Markdown 파일 안에서 Vue 컴포넌트를 사용할 수 있습니다.
- 내비게이션을 자동으로 생성합니다.

::read-more{to="https://content.nuxt.com" target="_blank"}
**Nuxt Content** 문서에서 더 알아보세요.
::

## Nuxt Content 활성화 %{#enable-nuxt-content}%

다음 명령 하나로 프로젝트에 `@nuxt/content` 모듈을 설치하고 `nuxt.config.ts`에도 추가할 수 있습니다:

```bash [Terminal]
npx nuxt module add content
```

## 콘텐츠 만들기 %{#create-content}%

Markdown 파일을 `content/` 디렉터리 안에 두세요:

```md [content/index.md]
# 안녕하세요 콘텐츠
```

모듈이 이 파일들을 자동으로 불러오고 파싱합니다.

## 콘텐츠 렌더링 %{#render-content}%

콘텐츠 페이지를 렌더링하려면 [`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer) 컴포넌트를 사용해 [catch-all route](/docs/4.x/directory-structure/app/pages/#catch-all-route)를 추가하세요:

```vue [app/pages/[...slug\\].vue]
<script lang="ts" setup>
const route = useRoute()
const { data: page } = await useAsyncData(route.path, () => {
  return queryCollection('content').path(route.path).first()
})
</script>

<template>
  <div>
    <header><!-- ... --></header>

    <ContentRenderer
      v-if="page"
      :value="page"
    />

    <footer><!-- ... --></footer>
  </div>
</template>
```
