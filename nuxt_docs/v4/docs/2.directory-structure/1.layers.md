`layers/` 디렉터리를 사용하면 Nuxt 애플리케이션 전반에서 재사용 가능한 코드, 컴포넌트, 컴포저블, 설정을 구성하고 공유할 수 있습니다. 프로젝트의 `layers/` 디렉터리 안에 있는 모든 레이어는 자동으로 등록됩니다.

::note
`layers/` 디렉터리 자동 등록은 Nuxt v3.12.0+에서 사용할 수 있습니다.
::

::tip{icon="i-lucide-lightbulb"}
레이어는 **도메인 주도 설계(DDD)** 로 큰 코드베이스를 구성하거나, 재사용 가능한 **UI 라이브러리** 또는 **테마**를 만들거나, 프로젝트 간 **설정 프리셋**을 공유하거나, **관리자 패널**이나 **기능 모듈** 같은 관심사를 분리하는 데 적합합니다.
::

## 구조 %{#structure}%

`layers/` 안의 각 하위 디렉터리는 별도의 레이어로 취급됩니다. 레이어는 표준 Nuxt 애플리케이션과 동일한 구조를 가질 수 있습니다.

::important
모든 레이어는 비어 있더라도 유효한 레이어로 인식되기 위해 **반드시** `nuxt.config.ts` 파일을 가져야 합니다.
::

```bash [Directory structure]
-| layers/
---| base/
-----| nuxt.config.ts
-----| app/
-------| components/
---------| BaseButton.vue
-------| composables/
---------| useBase.ts
-----| server/
-------| api/
---------| hello.ts
---| admin/
-----| nuxt.config.ts
-----| app/
-------| pages/
---------| admin.vue
-------| layouts/
---------| admin.vue
```

## 자동 별칭 %{#automatic-aliases}%

각 레이어의 `srcDir`에 대한 이름 있는 레이어 별칭이 자동으로 생성됩니다. `#layers/[name]` 별칭으로 레이어에 접근할 수 있습니다:

```ts
// base 레이어에 접근
import something from '#layers/base/path/to/file'

// admin 레이어에 접근
import { useAdmin } from '#layers/admin/composables/useAdmin'
```

::note
이름 있는 레이어 별칭은 Nuxt v3.16.0에서 도입되었습니다.
::

## 레이어 내용 %{#layer-content}%

각 레이어에는 다음이 포함될 수 있습니다:

- [`nuxt.config.ts`](/docs/4.x/directory-structure/nuxt-config) - 메인 설정과 병합될 레이어 전용 설정
- [`app.config.ts`](/docs/4.x/directory-structure/app/app-config) - 반응형 애플리케이션 설정
- [`app/components/`](/docs/4.x/directory-structure/app/components) - Vue 컴포넌트(auto-import)
- [`app/composables/`](/docs/4.x/directory-structure/app/composables) - Vue 컴포저블(auto-import)
- [`app/utils/`](/docs/4.x/directory-structure/app/utils) - 유틸리티 함수(auto-import)
- [`app/pages/`](/docs/4.x/directory-structure/app/pages) - 애플리케이션 페이지
- [`app/layouts/`](/docs/4.x/directory-structure/app/layouts) - 애플리케이션 레이아웃
- [`app/middleware/`](/docs/4.x/directory-structure/app/middleware) - 라우트 미들웨어
- [`app/plugins/`](/docs/4.x/directory-structure/app/plugins) - Nuxt 플러그인
- [`server/`](/docs/4.x/directory-structure/server) - 서버 라우트, 미들웨어, 유틸리티
- [`shared/`](/docs/4.x/directory-structure/shared) - 앱과 서버 사이의 공유 코드

## 우선순위 %{#priority-order}%

여러 레이어가 같은 리소스(컴포넌트, 컴포저블, 페이지 등)를 정의하면 **우선순위가 더 높은** 레이어가 적용됩니다. 레이어는 알파벳순으로 정렬되며, 더 뒤의 글자가 더 높은 우선순위를 가집니다(Z > A).

순서를 제어하려면 디렉터리 앞에 숫자 접두사를 붙이세요: `1.base/`, `2.features/`, `3.admin/`.
