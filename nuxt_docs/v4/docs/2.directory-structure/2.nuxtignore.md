`.nuxtignore` 파일은 빌드 단계에서 프로젝트 루트 디렉터리([`rootDir`](/docs/4.x/api/nuxt-config#rootdir))의 파일을 Nuxt가 무시하도록 지시합니다.

[`.gitignore`](/docs/4.x/directory-structure/gitignore) 및 `.eslintignore` 파일과 동일한 명세를 따르며, 각 줄은 어떤 파일을 무시해야 하는지를 나타내는 glob 패턴입니다.

::tip
`nuxt.config` 파일에서 [`ignoreOptions`](/docs/4.x/api/nuxt-config#ignoreoptions), [`ignorePrefix`](/docs/4.x/api/nuxt-config#ignoreprefix), [`ignore`](/docs/4.x/api/nuxt-config#ignore)도 설정할 수 있습니다.
::

## 사용법 %{#usage}%

```bash [.nuxtignore]
# layout foo.vue 무시
app/layouts/foo.vue
# 이름이 -ignore.vue로 끝나는 layout 파일 무시
app/layouts/*-ignore.vue

# page bar.vue 무시
app/pages/bar.vue
# ignore 폴더 안의 page 무시
app/pages/ignore/*.vue

# foo/bar.js를 제외한 foo 폴더 아래 route middleware 파일 무시
app/middleware/foo/*.js
!app/middleware/foo/bar.js
```

::read-more{icon="i-simple-icons-git" title="git 문서" to="https://git-scm.com/docs/gitignore" target="_blank"}
명세에 대한 자세한 내용은 **gitignore 문서**에서 확인할 수 있습니다.
::
