::important
이 디렉터리는 개발 빌드 결과물이 저장소에 푸시되지 않도록 [`.gitignore`](/docs/4.x/directory-structure/gitignore) 파일에 추가해야 합니다.
::

이 디렉터리는 디렉터리 구조를 기반으로 Nuxt가 생성하는 파일들에 대해 더 자세히 알고 싶을 때 유용합니다.

Nuxt는 또한 모듈이 디스크에 실제 파일을 쓰지 않고도 이 디렉터리에 템플릿을 추가할 수 있도록 가상 파일 시스템(VFS)을 제공합니다.

개발 모드에서 [Nuxt DevTools](https://devtools.nuxt.com)를 열고 **Virtual Files** 탭으로 이동하여 생성된 파일들을 탐색할 수 있습니다.

::warning
[`nuxt dev`](/docs/4.x/api/commands/dev)를 실행할 때 전체 디렉터리가 다시 생성되므로, 내부의 어떤 파일도 수정해서는 안 됩니다.
::
