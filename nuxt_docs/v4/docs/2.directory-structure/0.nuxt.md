::important
개발 빌드 출력물이 저장소에 푸시되지 않도록 이 디렉터리를 [`.gitignore`](/docs/4.x/directory-structure/gitignore) 파일에 추가해야 합니다.
::

이 디렉터리는 Nuxt가 디렉터리 구조를 바탕으로 어떤 파일을 생성하는지 더 알고 싶을 때 유용합니다.

Nuxt는 또한 모듈이 디스크에 쓰지 않고도 이 디렉터리에 템플릿을 추가할 수 있도록 Virtual File System(VFS)도 제공합니다.

개발 모드에서 [Nuxt DevTools](https://devtools.nuxt.com)를 열고 **Virtual Files** 탭으로 이동하면 생성된 파일을 살펴볼 수 있습니다.

::warning
전체 디렉터리가 [`nuxt dev`](/docs/4.x/api/commands/dev) 실행 시 다시 생성되므로 내부 파일은 건드리지 말아야 합니다.
::
