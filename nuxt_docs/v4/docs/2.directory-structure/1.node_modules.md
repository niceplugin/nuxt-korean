패키지 매니저([`npm`](https://docs.npmjs.com/cli/commands/npm/) 또는 [`yarn`](https://yarnpkg.com) 또는 [`pnpm`](https://pnpm.io/cli/install) 또는 [`bun`](https://bun.com/package-manager) 또는 [`deno`](https://docs.deno.com/runtime/getting_started/installation/))는 프로젝트의 의존성을 저장하기 위해 이 디렉터리를 생성합니다.

::important
의존성이 저장소에 푸시되지 않도록 이 디렉터리를 [`.gitignore`](/docs/4.x/directory-structure/gitignore) 파일에 추가해야 합니다.
::
