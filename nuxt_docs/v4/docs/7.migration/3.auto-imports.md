title: Auto Imports
description:  Nuxt 3는 가능한 곳에서는 컴포넌트와 컴포저블을 자동 import하는 최소 마찰 접근 방식을 채택합니다.
---

::note
이후의 마이그레이션 문서에서는 핵심 Nuxt 및 Vue 유틸리티에 명시적인 import가 없는 것을 보게 될 것입니다. 이것은 오타가 아닙니다. Nuxt가 이를 자동으로 import해 주며, Nuxt의 TypeScript 지원을 사용하기 위해 [안내](/docs/4.x/migration/configuration#typescript)를 따랐다면 완전한 타입 힌트도 받을 수 있습니다.
::

[자동 import에 대해 더 알아보기](/docs/4.x/guide/concepts/auto-imports)

## 마이그레이션 %{#migration}%

1. Nuxt 2에서 `@nuxt/components`를 사용해 왔다면 `nuxt.config`의 `components: true`를 제거할 수 있습니다. 더 복잡한 설정을 사용했다면 컴포넌트 옵션이 다소 바뀌었다는 점에 유의하세요. 자세한 내용은 [components 문서](/docs/4.x/directory-structure/app/components)를 참고하세요.

::tip
`.nuxt/types/components.d.ts`와 `.nuxt/types/imports.d.ts`를 보면 Nuxt가 컴포넌트와 컴포저블 자동 import를 어떻게 해석했는지 확인할 수 있습니다.
::
