---
title: 자동 임포트
description:  Nuxt 3는 마찰을 최소화하는 접근 방식을 채택하여, 가능한 한 컴포넌트와 컴포저블을 자동으로 임포트합니다.
---

::note
이후의 마이그레이션 문서들에서 핵심 Nuxt 및 Vue 유틸리티에 명시적인 임포트가 없는 것을 보게 될 것입니다. 이것은 오타가 아니며, Nuxt가 이를 자동으로 임포트해 주기 때문입니다. 또한 Nuxt의 TypeScript 지원을 사용하기 위해 [설명서](/docs/4.x/migration/configuration#typescript)의 지침을 따랐다면, 전체 타입 힌트를 받을 수 있어야 합니다.
::

[자동 임포트에 대해 더 읽어보기](/docs/4.x/guide/concepts/auto-imports)

## 마이그레이션 %{migration}%

1. Nuxt 2에서 `@nuxt/components`를 사용해 왔다면, `nuxt.config`에서 `components: true`를 제거할 수 있습니다. 더 복잡한 설정을 사용했다면, 컴포넌트 옵션이 다소 변경되었다는 점에 유의하세요. 자세한 내용은 [컴포넌트 문서](/docs/4.x/directory-structure/app/components)를 참고하세요.

::tip
Nuxt가 컴포넌트와 컴포저블 자동 임포트를 어떻게 해석했는지 확인하려면 `.nuxt/types/components.d.ts`와 `.nuxt/types/imports.d.ts`를 살펴볼 수 있습니다.
::
