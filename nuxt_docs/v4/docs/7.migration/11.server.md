---

빌드된 Nuxt 3 애플리케이션에는 런타임 Nuxt 의존성이 없습니다. 이는 사이트가 매우 높은 성능을 가지며, 극도로 슬림해진다는 것을 의미합니다. 하지만 더 이상 런타임 Nuxt 서버 훅에 연결할 수 없다는 뜻이기도 합니다.

:read-more{to="/docs/4.x/guide/concepts/server-engine"}

## 단계 %{steps}%

1. `nuxt.config`에서 `render` 키를 제거합니다.
2. `~/server/api` 및 `~/server/middleware`의 모든 파일은 자동으로 등록되므로, `serverMiddleware` 배열에서 제거할 수 있습니다.
3. `serverMiddleware` 배열의 다른 항목들은 인라인 함수 대신 파일 또는 npm 패키지를 직접 가리키도록 업데이트합니다.
