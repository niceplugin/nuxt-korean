빌드된 Nuxt 3 애플리케이션에는 런타임 Nuxt 종속성이 없습니다. 즉, 사이트가 매우 높은 성능과 매우 작은 크기를 갖게 됩니다. 하지만 그만큼 런타임 Nuxt 서버 훅에 더 이상 연결할 수 없다는 뜻이기도 합니다.

:read-more{to="/docs/4.x/guide/concepts/server-engine"}

## 단계 %{#steps}%

1. `nuxt.config`에서 `render` 키를 제거합니다.
2. `~~/server/api` 및 `~~/server/middleware` 안의 모든 파일은 자동으로 등록되므로 `serverMiddleware` 배열에서 제거할 수 있습니다.
3. `serverMiddleware` 배열의 다른 항목도 인라인 함수를 사용하는 대신 파일이나 npm 패키지를 직접 가리키도록 업데이트합니다.
