Nuxt 3는 메타 태그를 관리하는 여러 가지 방법을 제공합니다:
1. `nuxt.config`를 통해.
2. [`useHead`](/docs/4.x/api/composables/use-head) [컴포저블](/docs/4.x/getting-started/seo-meta)을 통해
3. [전역 메타 컴포넌트](/docs/4.x/getting-started/seo-meta)를 통해

`title`, `titleTemplate`, `base`, `script`, `noscript`, `style`, `meta`, `link`, `htmlAttrs`, `bodyAttrs`를 사용자 지정할 수 있습니다.

::tip
Nuxt는 현재 메타 태그 관리를 위해 [`Unhead`](https://github.com/unjs/unhead)를 사용하지만, 구현 세부 사항은 변경될 수 있습니다.
::

:read-more{to="/docs/4.x/getting-started/seo-meta"}

## Migration %{#migration}%

1. `nuxt.config`에서 `head`를 `meta`로 이름을 바꾸세요. 이 공통 메타 구성을 대신 `app.vue`로 옮기는 것도 고려해 보세요. (객체에는 더 이상 중복 제거용 `hid` 키가 없습니다.)
2. `head`로 컴포넌트 상태에 접근해야 한다면 [`useHead`](/docs/4.x/api/composables/use-head) 사용으로 마이그레이션해야 합니다. 내장 메타 컴포넌트 사용도 고려할 수 있습니다.
3. Options API를 사용해야 한다면 `defineNuxtComponent`를 사용할 때 `head()` 메서드를 사용할 수 있습니다.

### useHead %{#usehead}%

::code-group

```vue [Nuxt 2]
<script>
export default {
  data: () => ({
    title: '내 앱',
    description: '내 앱 설명',
  }),
  head () {
    return {
      title: this.title,
      meta: [{
        hid: 'description',
        name: 'description',
        content: this.description,
      }],
    }
  },
}
</script>
```

```vue [Nuxt 3]
<script setup lang="ts">
const title = ref('내 앱')
const description = ref('내 앱 설명')

// 위의 title/description을 바꾸면 반응적으로 동작합니다
useHead({
  title,
  meta: [{
    name: 'description',
    content: description,
  }],
})
</script>
```

::

### 메타 컴포넌트 %{#meta-components}%

Nuxt 3는 같은 작업을 수행할 수 있는 메타 컴포넌트도 제공합니다. 이 컴포넌트들은 HTML 태그처럼 보이지만 Nuxt가 제공하며 비슷한 기능을 가집니다.

::code-group

```vue [Nuxt 2]
<script>
export default {
  head () {
    return {
      title: '내 앱',
      meta: [{
        hid: 'description',
        name: 'description',
        content: '내 앱 설명',
      }],
    }
  },
}
</script>
```

```vue [Nuxt 3]
<template>
  <div>
    <Head>
      <Title>내 앱</Title>
      <Meta
        name="description"
        content="내 앱 설명"
      />
    </Head>
    <!-- -->
  </div>
</template>
```

::

::important
1. 이 컴포넌트 이름은 네이티브 HTML 요소와 구분되도록 대문자로 사용해야 합니다 (`<title>`이 아니라 `<Title>`).
2. 페이지 템플릿의 어느 위치에나 이 컴포넌트들을 배치할 수 있습니다.
::

### Options API %{#options-api}%

```vue [Nuxt 3 (Options API)]
<script>
// Options API `head` 메서드를 사용한다면 `defineNuxtComponent`를 사용해야 합니다
export default defineNuxtComponent({
  head (nuxtApp) {
    // `head`는 nuxt app을 전달받지만 컴포넌트 인스턴스에는 접근할 수 없습니다
    return {
      meta: [{
        name: 'description',
        content: '이것은 내 페이지 설명입니다.',
      }],
    }
  },
})
</script>
```
