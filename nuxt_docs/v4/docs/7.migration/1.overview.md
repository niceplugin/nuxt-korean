title: 개요
description: Nuxt 3는 Nuxt 2를 완전히 새로 작성한 버전이며, 새로운 기반 기술 스택을 바탕으로 합니다.
---

Nuxt 2 앱을 Nuxt 3로 마이그레이션할 때는 상당한 변화가 있지만, 안정 버전 출시로 나아가면서 마이그레이션 과정은 점점 더 단순해질 것으로 기대할 수 있습니다.

::note
이 마이그레이션 가이드는 Nuxt 3의 개발 진행 상황에 맞추어 계속해서 업데이트되고 있습니다.
::

이러한 주요 변경 사항에는 다음이 포함됩니다:

1. Vue 2에서 Vue 3로의 전환, 기본값으로 Composition API와 script setup 사용 포함.
1. webpack 4와 Babel에서 Vite 또는 webpack 5와 esbuild로의 전환.
1. 런타임 Nuxt 의존성에서 nitropack으로 컴파일된 최소한의 독립 실행형 서버로의 전환.

::tip
Nuxt 2를 계속 사용해야 하지만 Nuxt 2에서 Nuxt 3 기능의 이점을 얻고 싶다면, 대신 [Bridge로 시작하는 방법](/docs/4.x/bridge/overview)을 확인해 볼 수 있습니다.
::
