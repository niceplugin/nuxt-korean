---

Nuxt 2 앱을 Nuxt 3로 마이그레이션할 때는 큰 변화가 있지만, 안정 릴리스에 가까워질수록 마이그레이션은 더 간단해질 것입니다.

::note
이 마이그레이션 가이드는 Nuxt 3의 개발에 맞추기 위해 계속 진행 중입니다.
::

이러한 큰 변경 사항에는 다음이 포함됩니다:

1. Vue 2에서 Vue 3로 이동하며, Composition API와 script setup이 기본이 됩니다.
1. webpack 4와 Babel에서 Vite 또는 webpack 5와 esbuild로 이동합니다.
1. 런타임 Nuxt 종속성에서 nitropack으로 컴파일된 최소한의 독립형 서버로 이동합니다.

::tip
Nuxt 2에 머물러야 하지만 Nuxt 2에서 Nuxt 3 기능의 이점을 누리고 싶다면, 대신 [Bridge 시작하기](/docs/4.x/bridge/overview)를 확인할 수 있습니다.
::
