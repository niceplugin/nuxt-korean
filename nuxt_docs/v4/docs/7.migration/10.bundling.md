기본적으로 다음과 같은 빌드 도구를 사용합니다:

- [Vite](https://vite.dev) 또는 [webpack](https://webpack.js.org)
- [Rollup](https://rollupjs.org)
- [PostCSS](https://postcss.org)
- [esbuild](https://esbuild.github.io)

이러한 이유로, `nuxt.config`의 이전 `build` 설정 대부분은 이제 무시되며, 커스텀 babel 설정도 포함됩니다.

Nuxt의 빌드 도구를 설정해야 하는 경우, 새로운 최상위 키인 `vite`, `webpack`, `postcss`를 사용하여 `nuxt.config`에서 설정할 수 있습니다.

또한 Nuxt는 TypeScript 지원을 기본으로 제공합니다.

:read-more{to="/docs/4.x/guide/concepts/typescript"}

## 단계 %{steps}%

1. 의존성과 모듈에서 `@nuxt/typescript-build`와 `@nuxt/typescript-runtime`을 제거합니다.
2. 사용하지 않는 babel 관련 의존성을 프로젝트에서 제거합니다.
3. 명시적으로 추가한 core-js 의존성을 제거합니다.
4. `require`를 `import`로 마이그레이션합니다.
