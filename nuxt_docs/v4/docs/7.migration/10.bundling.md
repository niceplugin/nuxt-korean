기본적으로 다음 빌드 도구를 사용합니다:

- [Vite](https://vite.dev) 또는 [webpack](https://webpack.js.org)
- [Rollup](https://rollupjs.org)
- [PostCSS](https://postcss.org)
- [esbuild](https://esbuild.github.io)

이 때문에 기존 `nuxt.config`의 대부분의 `build` 설정은 이제 무시되며, 사용자 정의 babel 설정도 여기에 포함됩니다.

Nuxt의 빌드 도구를 구성해야 한다면 `nuxt.config`에서 새로운 최상위 키인 `vite`, `webpack`, `postcss`를 사용해 설정할 수 있습니다.

또한 Nuxt는 기본적으로 TypeScript 지원을 포함합니다.

:read-more{to="/docs/4.x/guide/concepts/typescript"}

## 단계 %{#steps}%

1. 종속성과 모듈에서 `@nuxt/typescript-build` 및 `@nuxt/typescript-runtime`을 제거합니다.
2. 프로젝트에서 사용하지 않는 babel 종속성을 제거합니다.
3. 명시적인 core-js 종속성을 제거합니다.
4. `require`를 `import`로 마이그레이션합니다.
