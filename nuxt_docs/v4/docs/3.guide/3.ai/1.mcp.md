## MCP란 무엇인가요? %{#what-is-mcp}%

MCP(Model Context Protocol)는 AI 어시스턴트가 외부 데이터 소스와 도구에 접근할 수 있게 해주는 표준화된 프로토콜입니다. Nuxt는 Claude Code, Cursor, Windsurf 같은 AI 어시스턴트가 문서, 블로그 게시물, 배포 가이드에 직접 접근할 수 있도록 하는 MCP 서버를 제공합니다.

MCP 서버는 Nuxt 문서에 대한 구조화된 접근 방식을 제공하므로, AI 도구가 Nuxt 개발을 더 쉽게 이해하고 도와줄 수 있게 합니다.

## 리소스 %{#resources}%

Nuxt MCP 서버는 탐색을 위해 다음 리소스를 제공합니다:

- **`resource://nuxt-com/documentation-pages`**: 사용 가능한 모든 문서 페이지를 탐색합니다(기본값은 v4.x)
- **`resource://nuxt-com/blog-posts`**: 릴리스와 튜토리얼을 포함한 모든 Nuxt 블로그 게시물을 탐색합니다
- **`resource://nuxt-com/deploy-providers`**: 모든 배포 provider와 호스팅 플랫폼을 탐색합니다

Claude Code 같은 도구에서는 `@`를 사용해 이러한 리소스에 접근할 수 있습니다.

## 도구 %{#tools}%

Nuxt MCP 서버는 카테고리별로 정리된 다음 도구를 제공합니다:

### 문서 %{#documentation}%

- **`list_documentation_pages`**: 카테고리와 기본 정보와 함께 사용 가능한 모든 Nuxt 문서 페이지를 나열합니다. 버전 필터링(3.x, 4.x, 또는 전체)을 지원합니다
- **`get_documentation_page`**: 경로를 기준으로 문서 페이지 내용과 세부 정보를 가져옵니다
- **`get_getting_started_guide`**: 특정 Nuxt 버전에 대한 시작 가이드를 가져옵니다

### 블로그 %{#blog}%

- **`list_blog_posts`**: 날짜, 카테고리, 태그를 포함한 메타데이터와 함께 모든 Nuxt 블로그 게시물을 나열합니다
- **`get_blog_post`**: 경로를 기준으로 블로그 게시물의 내용과 세부 정보를 가져옵니다

### 배포 %{#deployment}%

- **`list_deploy_providers`**: Nuxt 애플리케이션용 모든 배포 provider와 호스팅 플랫폼을 나열합니다
- **`get_deploy_provider`**: 경로를 기준으로 배포 provider의 세부 정보와 지침을 가져옵니다

## 프롬프트 %{#prompts}%

Nuxt MCP 서버는 일반적인 워크플로를 위한 가이드 프롬프트를 제공합니다:

- **`find_documentation_for_topic`**: 특정 주제나 기능에 가장 적합한 Nuxt 문서를 찾습니다
- **`deployment_guide`**: 특정 호스팅 provider에 대한 배포 지침을 가져옵니다
- **`migration_help`**: Nuxt 버전 간 마이그레이션 도움을 제공합니다

Claude Code 같은 도구에서는 `/`를 사용해 이러한 리소스에 접근할 수 있습니다.

## 설정 %{#setup}%

Nuxt MCP 서버는 HTTP transport를 사용하며 여러 AI 어시스턴트에 설치할 수 있습니다.

### ChatGPT %{#chatgpt}%

::note{icon="i-lucide-info"}
**MCP를 사용하는 커스텀 커넥터는 웹의 ChatGPT Pro 및 Plus 계정에서 사용할 수 있습니다.**
::

다음 단계에 따라 ChatGPT 내에서 Nuxt를 커넥터로 설정하세요:

1. **Developer mode 활성화:**
   - Settings → Connectors → Advanced settings → Developer mode 로 이동합니다

2. **ChatGPT 설정 열기**

3. **Connectors 탭에서 새 커넥터 생성:**
   - 이름 지정: `Nuxt`
   - MCP 서버 URL: `https://nuxt.com/mcp`
   - Authentication: `None`

4. **Create 클릭**

이후 대화 중 composer의 "Developer mode" 도구에서 Nuxt 커넥터가 나타납니다.

### Claude Code %{#claude-code}%

::note{icon="i-lucide-info"}
**Claude Code가 설치되어 있는지 확인하세요** - 설치 지침은 [Anthropic 문서](https://code.claude.com/docs/en/quickstart)를 참고하세요.
::

CLI 명령어를 사용해 서버를 추가합니다:

```bash
claude mcp add --transport http nuxt-remote https://nuxt.com/mcp
```

### Claude Desktop %{#claude-desktop}%

#### 설정 지침 %{#setup-instructions}%

1. Claude Desktop을 열고 "Settings" > "Developer"로 이동합니다.
2. "Edit Config"를 클릭합니다. 로컬 Claude 디렉터리가 열립니다.
3. `claude_desktop_config.json` 파일을 커스텀 MCP 서버 설정으로 수정합니다.
    ```json [claude_desktop_config.json]
    {
      "mcpServers": {
        "nuxt": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://nuxt.com/mcp"
          ]
        }
      }
    }
    ```
4. Claude Desktop 앱을 재시작합니다. 이제 Nuxt MCP 서버가 등록되어 있어야 합니다.

수동 설정을 원한다면 다음 단계를 따르세요:

1. Cursor를 열고 "Settings" > "Tools & MCP"로 이동합니다
2. Nuxt MCP 서버 설정을 추가합니다

또는 프로젝트 루트에 `.cursor/mcp.json`을 직접 생성/수정합니다:

```json [.cursor/mcp.json]
{
  "mcpServers": {
    "nuxt": {
      "type": "http",
      "url": "https://nuxt.com/mcp"
    }
  }
}
```

### Le Chat Mistral %{#le-chat-mistral}%

1. "Intelligence" > "Connectors"로 이동합니다
2. "Add Connector" 버튼을 클릭한 뒤 "Custom MCP Connector"를 선택합니다
3. 커스텀 MCP 커넥터를 생성합니다:
    - Connector Name : `Nuxt`
    - Connector Server : `https://nuxt.com/mcp`

### Visual Studio Code %{#visual-studio-code}%

::note{icon="i-lucide-info"}
**필수 확장 프로그램 설치** - [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)과 [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat) 확장을 설치했는지 확인하세요.
::

1. VS Code를 열고 Command Palette(Ctrl/Cmd + Shift + P)를 엽니다
2. "Preferences: Open Workspace Settings (JSON)"을 입력하고 선택합니다
3. 프로젝트의 `.vscode` 폴더로 이동하거나, 없다면 생성합니다
4. 다음 설정으로 `mcp.json` 파일을 생성하거나 수정합니다:

```json [.vscode/mcp.json]
{
  "servers": {
    "nuxt": {
      "type": "http",
      "url": "https://nuxt.com/mcp"
    }
  }
}
```

### GitHub Copilot Agent %{#github-copilot-agent}%

::note{icon="i-lucide-info"}
**GitHub Copilot coding agent의 MCP 서버를 구성하려면 저장소 관리자 권한이 필요합니다.**
::

VS Code에서 이미 MCP 서버를 구성했다면(GitHub Copilot Agent에서는 `servers` 키를 `mcpServers`로 바꾸세요), 비슷한 설정을 GitHub Copilot coding agent에도 활용할 수 있습니다. Copilot이 어떤 도구를 사용할 수 있는지 지정하는 `tools` 키를 추가해야 합니다.

1. GitHub 저장소로 이동합니다
2. **Settings** > **Code & automation** > **Copilot** > **Coding agent** 로 이동합니다
3. **MCP configuration** 섹션에 다음 설정을 추가합니다:
    ```json
    {
      "mcpServers": {
        "nuxt": {
          "type": "http",
          "url": "https://nuxt.com/mcp",
          "tools": ["*"]
        }
      }
    }
    ```
4. **Save**를 클릭합니다

#### 설정 검증 %{#validating-the-configuration}%

MCP 서버가 올바르게 설정되었는지 확인하려면:

1. 저장소에 이슈를 만들고 Copilot에 할당합니다
2. Copilot이 pull request를 만들 때까지 기다립니다
3. pull request에서 "Copilot started work" 타임라인 이벤트의 **View session**을 클릭합니다
4. 오른쪽 위의 줄임표 버튼(**...**)을 클릭한 뒤, 사이드바에서 **Copilot**을 클릭합니다
5. **Start MCP Servers** 단계를 펼쳐 구성된 Nuxt 도구를 확인합니다

GitHub Copilot coding agent에서 MCP를 사용하는 자세한 내용은 [Extend coding agent with MCP](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/coding-agent/extend-coding-agent-with-mcp)를 참고하세요.

### Windsurf %{#windsurf}%

1. Windsurf를 열고 "Settings" > "Windsurf Settings" > "Cascade"로 이동합니다
2. "Manage MCPs" 버튼을 클릭한 뒤 "View raw config" 옵션을 선택합니다
3. MCP 설정에 다음 구성을 추가합니다:

```json [.codeium/windsurf/mcp_config.json]
{
  "mcpServers": {
    "nuxt": {
      "type": "http",
      "url": "https://nuxt.com/mcp"
    }
  }
}
```

### Zed %{#zed}%

1. Zed를 열고 "Settings" > "Open Settings"로 이동합니다
2. JSON 설정 파일로 이동합니다
3. 설정에 다음 컨텍스트 서버 구성을 추가합니다:

```json [.config/zed/settings.json]
{
  "context_servers": {
    "nuxt": {
      "source": "custom",
      "command": "npx",
      "args": ["mcp-remote", "https://nuxt.com/mcp"],
      "env": {}
    }
  }
}
```

### Opencode %{#opencode}%

1. 프로젝트 루트에 `opencode.json`을 생성합니다
2. 다음 설정을 추가합니다:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "nuxt": {
      "type": "remote",
      "url": "https://nuxt.com/mcp",
      "enabled": true
    }
  }
}
```

## 프롬프트 예제 %{#prompts-examples}%

설정이 끝나면 다음과 같은 질문을 AI 어시스턴트에 할 수 있습니다:

- "사용 가능한 모든 Nuxt 문서 페이지를 나열해줘"
- "소개 문서를 가져와줘"
- "v3와 v4의 차이점이 뭐야?"
- "Vercel에 어떻게 배포해?"
- "최신 블로그 게시물을 보여줘"
- "Nuxt 3에서 Nuxt 4로 마이그레이션하는 걸 도와줘"
- "composables에 관한 문서를 검색해줘"
- "Cloudflare용 배포 가이드를 찾아줘"

AI 어시스턴트는 MCP 서버를 사용해 구조화된 JSON 데이터를 가져오고, Nuxt 개발을 위한 가이드형 도움을 제공하게 됩니다.
