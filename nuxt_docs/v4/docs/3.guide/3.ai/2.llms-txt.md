## LLMs.txt란 무엇인가요? %{what-is-llmstxt}%

LLMs.txt는 대규모 언어 모델(LLM)을 위해 특별히 설계된 구조화된 문서 형식입니다. Nuxt는 프레임워크에 대한 포괄적인 정보를 담은 LLMs.txt 파일을 제공하여, AI 도구가 Nuxt 개발을 쉽게 이해하고 도울 수 있도록 합니다.

이 파일들은 AI가 활용하기에 최적화되어 있으며, 개념, API, 사용 패턴, 모범 사례에 대한 구조화된 정보를 포함합니다.

## 사용 가능한 라우트 %{available-routes}%

AI 도구가 우리의 문서에 접근할 수 있도록 LLMs.txt 라우트를 제공합니다:

- **`/llms.txt`** - 모든 문서 페이지와 그 링크에 대한 구조화된 개요를 포함합니다 (~5K 토큰)
- **`/llms-full.txt`** - 시작 가이드, API 레퍼런스, 블로그 글, 배포 가이드 등을 포함한 포괄적인 문서를 제공합니다 (~1M+ 토큰)

## 올바른 파일 선택하기 %{choosing-the-right-file}%

::note{icon="i-lucide-info"}
**대부분의 사용자는 `/llms.txt`부터 시작해야 합니다** - 필수 정보가 모두 포함되어 있으며, 표준 LLM 컨텍스트 윈도우에서 잘 동작합니다.

구현 세부사항까지 모두 필요하고, 사용하는 AI 도구가 큰 컨텍스트(200K+ 토큰)를 지원하는 경우에만 `/llms-full.txt`를 사용하세요.
::

## 중요한 사용 주의사항 %{important-usage-notes}%

::warning{icon="i-lucide-alert-triangle"}
**@ 기호는 반드시 직접 입력해야 합니다** - Cursor나 Windsurf 같은 도구를 사용할 때, 채팅 인터페이스에서 `@` 기호는 반드시 손으로 직접 입력해야 합니다. 복사-붙여넣기를 하면 도구가 이를 컨텍스트 참조로 인식하는 기능이 깨집니다.
::

## AI 도구와 함께 사용하기 %{usage-with-ai-tools}%

### Cursor %{cursor}%

Nuxt는 Cursor에서 Nuxt 개발에 대한 더 나은 AI 지원을 받을 수 있도록, 참조 가능한 특화된 LLMs.txt 파일을 제공합니다.

#### 사용 방법 %{how-to-use}%

1. **직접 참조**: 질문할 때 LLMs.txt URL을 언급합니다
2. `@docs`를 사용해 이 특정 URL들을 프로젝트 컨텍스트에 추가합니다

[Cursor Web 및 Docs Search에 대해 더 알아보기](https://cursor.com/docs/context/symbols)

### Windsurf %{windsurf}%

Windsurf는 Nuxt LLMs.txt 파일에 직접 접근하여 프레임워크 사용법과 모범 사례를 이해할 수 있습니다.

#### Windsurf에서 LLMs.txt 사용하기 %{using-llmstxt-with-windsurf}%

- `@docs`를 사용해 특정 LLMs.txt URL을 참조합니다
- 워크스페이스에 이 URL들을 참조하는 지속적인 규칙을 생성합니다

[Windsurf Web 및 Docs Search에 대해 더 알아보기](https://docs.windsurf.com/windsurf/cascade/web-search)

### 기타 AI 도구 %{other-ai-tools}%

LLMs.txt를 지원하는 모든 AI 도구는 이 라우트를 사용해 Nuxt를 더 잘 이해할 수 있습니다.

#### ChatGPT, Claude 또는 기타 LLM을 위한 예시 %{examples-for-chatgpt-claude-or-other-llms}%

- "https://nuxt.com/llms.txt 에 있는 Nuxt 문서를 사용해 주세요"
- "https://nuxt.com/llms-full.txt 에 있는 전체 Nuxt 가이드라인을 따라 주세요"
