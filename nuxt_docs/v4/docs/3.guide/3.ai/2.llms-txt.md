## LLMs.txt란? %{#what-is-llms-txt}%

LLMs.txt는 대규모 언어 모델(LLM)을 위해 특별히 설계된 구조화된 문서 형식입니다. Nuxt는 프레임워크에 대한 포괄적인 정보를 담은 LLMs.txt 파일을 제공하여 AI 도구가 Nuxt 개발을 더 쉽게 이해하고 지원할 수 있도록 합니다.

이 파일들은 AI가 읽기 좋게 최적화되어 있으며 개념, API, 사용 패턴, 모범 사례에 대한 구조화된 정보를 담고 있습니다.

## 사용 가능한 경로 %{#available-routes}%

AI 도구가 문서에 접근할 수 있도록 다음 LLMs.txt 경로를 제공합니다:

- **`/llms.txt`** - 모든 문서 페이지와 링크에 대한 구조화된 개요를 포함합니다 (~5K tokens)
- **`/llms-full.txt`** - 시작 가이드, API 레퍼런스, 블로그 글, 배포 가이드를 포함한 포괄적인 문서를 제공합니다 (~1M+ tokens)

## 적절한 파일 선택하기 %{#choosing-the-right-file}%

::note{icon="i-lucide-info"}
**대부분의 사용자는 `/llms.txt`로 시작해야 합니다** - 이 파일에는 핵심 정보가 모두 포함되어 있고 일반적인 LLM 컨텍스트 창에서 동작합니다.

구현 세부 사항이 폭넓게 필요하고 AI 도구가 큰 컨텍스트(200K+ tokens)를 지원할 때만 `/llms-full.txt`를 사용하세요.
::

## 중요한 사용 참고 사항 %{#important-usage-notes}%

::warning{icon="i-lucide-alert-triangle"}
**@ 기호는 직접 입력해야 합니다** - Cursor나 Windsurf 같은 도구를 사용할 때 `@` 기호는 채팅 인터페이스에 손으로 직접 입력해야 합니다. 복사해서 붙여 넣으면 도구가 이를 컨텍스트 참조로 인식하지 못합니다.
::

## AI 도구에서 사용하기 %{#usage-with-ai-tools}%

### Cursor %{#cursor}%

Nuxt는 Cursor에서 참조할 수 있는 특화된 LLMs.txt 파일을 제공하여 Nuxt 개발 시 더 나은 AI 지원을 받을 수 있게 합니다.

#### 사용 방법 %{#how-to-use}%

1. **직접 참조**: 질문할 때 LLMs.txt URL을 언급합니다
2. `@docs`를 사용해 이 특정 URL들을 프로젝트 컨텍스트에 추가합니다

[Cursor Web 및 Docs Search 더 알아보기](https://cursor.com/docs/context/mentions)

### Windsurf %{#windsurf}%

Windsurf는 프레임워크 사용법과 모범 사례를 이해하기 위해 Nuxt LLMs.txt 파일에 직접 접근할 수 있습니다.

#### Windsurf에서 LLMs.txt 사용하기 %{#using-llms-txt-with-windsurf}%

- `@docs`를 사용해 특정 LLMs.txt URL을 참조합니다
- 워크스페이스에서 이 URL을 참조하는 지속 규칙을 만듭니다

[Windsurf Web 및 Docs Search 더 알아보기](https://docs.windsurf.com/windsurf/cascade/web-search)

### 기타 AI 도구 %{#other-ai-tools}%

LLMs.txt를 지원하는 어떤 AI 도구든 이 경로를 사용해 Nuxt를 더 잘 이해할 수 있습니다.

#### ChatGPT, Claude 또는 기타 LLM을 위한 예시 %{#examples-for-chatgpt-claude-or-other-llms}%

- "https://nuxt.com/llms.txt 의 Nuxt 문서를 사용해 주세요"
- "https://nuxt.com/llms-full.txt 의 전체 Nuxt 가이드라인을 따라 주세요"
