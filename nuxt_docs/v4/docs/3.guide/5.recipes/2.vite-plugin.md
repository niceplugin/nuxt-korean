Nuxt 모듈은 광범위한 기능을 제공하지만, 때로는 특정 Vite 플러그인이 요구 사항을 더 직접적으로 충족할 수 있습니다.

먼저 Vite 플러그인을 설치해야 합니다. 이 예제에서는 `@rollup/plugin-yaml`을 사용합니다:

::code-group{sync="pm"}

  ```bash [npm]
  npm install @rollup/plugin-yaml
  ```

  ```bash [yarn]
  yarn add @rollup/plugin-yaml
  ```

  ```bash [pnpm]
  pnpm add @rollup/plugin-yaml
  ```

  ```bash [bun]
  bun add @rollup/plugin-yaml
  ```

  ```bash [deno]
  deno add npm:@rollup/plugin-yaml
  ```

::

다음으로 이를 가져와 [`nuxt.config.ts`](/docs/4.x/directory-structure/nuxt-config) 파일에 추가해야 합니다:

```ts [nuxt.config.ts]
import yaml from '@rollup/plugin-yaml'

export default defineNuxtConfig({
  vite: {
    plugins: [
      yaml(),
    ],
  },
})
```

이제 Vite 플러그인을 설치하고 구성했으므로, 프로젝트에서 YAML 파일을 직접 사용할 수 있습니다.

예를 들어 구성 데이터를 저장하는 `config.yaml`을 두고, 이 데이터를 Nuxt 컴포넌트에서 가져올 수 있습니다:

::code-group

```yaml [data/hello.yaml]
greeting: "안녕, Vite와 함께하는 Nuxt!"
```

```vue [app/components/Hello.vue]
<script setup>
import config from '~/data/hello.yaml'
</script>

<template>
  <h1>{{ config.greeting }}</h1>
</template>
```

::

## Nuxt 모듈에서 Vite 플러그인 사용하기 %{#using-vite-plugins-in-nuxt-modules}%

Nuxt 모듈을 개발 중이며 Vite 플러그인을 추가해야 한다면, [`addVitePlugin`](/docs/4.x/api/kit/builder#addviteplugin) 유틸리티를 사용해야 합니다:

```ts [modules/my-module.ts]
import { addVitePlugin, defineNuxtModule } from '@nuxt/kit'
import yaml from '@rollup/plugin-yaml'

export default defineNuxtModule({
  setup () {
    addVitePlugin(yaml())
  },
})
```

Nuxt 5+에서 환경별 플러그인을 사용하려면 `applyToEnvironment()` 메서드를 사용하세요:

```ts [modules/my-module.ts]
import { addVitePlugin, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    addVitePlugin(() => ({
      name: 'my-client-plugin',
      applyToEnvironment (environment) {
        return environment.name === 'client'
      },
      // 플러그인 설정
    }))
  },
})
```

::important
resolve된 Vite 구성에 접근해야 하는 코드를 작성한다면, Nuxt의 `vite:extend`, `vite:extendConfig`, `vite:configResolved`를 사용하는 대신 Vite 플러그인 _내부의_ `config` 및 `configResolved` 훅을 사용해야 합니다.
::
