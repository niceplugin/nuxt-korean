---

Nuxt로 작업할 때 프런트엔드를 만들면서 외부 API를 가져오고 있을 수 있으며, 이 API를 가져올 때 몇 가지 기본 옵션을 설정하고 싶을 수 있습니다.

[`$fetch`](/docs/4.x/api/utils/dollarfetch) 유틸리티 함수([`useFetch`](/docs/4.x/api/composables/use-fetch) 컴포저블에서 사용됨)는 의도적으로 전역 설정이 가능하지 않게 되어 있습니다. 그래야 애플리케이션 전반의 패칭 동작이 일관되게 유지되고, 다른 통합 기능(예: 모듈)도 `$fetch` 같은 핵심 유틸리티의 동작을 신뢰할 수 있기 때문입니다.

하지만 Nuxt는 여러분의 API용 커스텀 fetcher를 만드는 방법을 제공합니다(호출할 API가 여러 개라면 여러 fetcher도 만들 수 있습니다).

## 레시피: 인증이 있는 API 클라이언트 %{#recipe-api-client-with-auth}%

예를 들어 `https://api.nuxt.com`에 [nuxt-auth-utils](https://github.com/atinux/nuxt-auth-utils)를 통한 JWT 인증이 필요한 외부 API가 있고, `401` 응답이 오면 `/login`으로 리디렉션하고 싶다고 가정해 보겠습니다.

```ts [app/composables/useAPI.ts]
export const useAPI = createUseFetch({
  baseURL: 'https://api.nuxt.com',
  onRequest ({ options }) {
    const { session } = useUserSession()
    if (session.value?.token) {
      options.headers.set('Authorization', `Bearer ${session.value.token}`)
    }
  },
  async onResponseError ({ response }) {
    if (response.status === 401) {
      await navigateTo('/login')
    }
  },
})
```

이제 `useAPI`를 호출할 때마다 인증 헤더가 자동으로 포함되고 401 리디렉션도 처리됩니다:

```vue [app/pages/dashboard.vue]
<script setup lang="ts">
const { data: profile } = await useAPI('/me')
const { data: orders } = await useAPI('/orders')
</script>
```

## 레시피: 커스텀 `$fetch` 인스턴스 %{#recipe-custom-fetch-instance}%

더 낮은 수준의 제어가 필요하다면 [Nuxt plugin](/docs/4.x/directory-structure/app/plugins)으로 커스텀 `$fetch` 인스턴스를 만들고, 이를 `useAsyncData`와 직접 함께 쓰거나 `createUseFetch`에 전달할 수 있습니다.

::note
`$fetch`는 [ofetch](https://github.com/unjs/ofetch)의 설정된 인스턴스로, Nuxt 서버의 base URL 추가와 SSR 중 직접 함수 호출(HTTP 왕복 회피)을 지원합니다.
::

```ts [app/plugins/api.ts]
export default defineNuxtPlugin((nuxtApp) => {
  const { session } = useUserSession()

  const api = $fetch.create({
    baseURL: 'https://api.nuxt.com',
    onRequest ({ request, options, error }) {
      if (session.value?.token) {
        options.headers.set('Authorization', `Bearer ${session.value?.token}`)
      }
    },
    async onResponseError ({ response }) {
      if (response.status === 401) {
        await nuxtApp.runWithContext(() => navigateTo('/login'))
      }
    },
  })

  return {
    provide: {
      api,
    },
  }
})
```

이후에는 커스텀 `$fetch` 인스턴스를 직접 사용할 수 있습니다:

```vue [app/app.vue]
<script setup>
const { $api } = useNuxtApp()
const { data: modules } = await useAsyncData('modules', () => $api('/modules'))
</script>
```

::callout
[`useAsyncData`](/docs/4.x/api/composables/use-async-data)로 감싸면 **서버 사이드 렌더링 시 데이터 이중 패칭을 피할 수 있습니다**(서버와 hydration 중 클라이언트).
::
