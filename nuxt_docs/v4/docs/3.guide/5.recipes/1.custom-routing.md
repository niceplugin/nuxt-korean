## 사용자 정의 라우트 추가 %{#adding-custom-routes}%

Nuxt에서는 [app/pages 디렉터리](/docs/4.x/directory-structure/app/pages) 안의 파일 구조로 라우팅이 정의됩니다. 하지만 내부적으로 [vue-router](https://router.vuejs.org)를 사용하므로, Nuxt는 프로젝트에 사용자 정의 라우트를 추가하는 여러 방법을 제공합니다.

### Router 설정 %{#router-config}%

[router options](/docs/4.x/guide/recipes/custom-routing#router-options)를 사용하면 스캔된 라우트를 받아 사용자 지정된 라우트를 반환하는 함수를 통해 라우트를 선택적으로 덮어쓰거나 확장할 수 있습니다.

`null` 또는 `undefined`를 반환하면 Nuxt는 기본 라우트로 되돌아갑니다 (입력 배열을 수정할 때 유용함).

```ts [router.options.ts]
import type { RouterConfig } from '@nuxt/schema'

export default {
  // https://router.vuejs.org/api/interfaces/routeroptions#routes
  routes: _routes => [
    {
      name: 'home',
      path: '/',
      component: () => import('~/pages/home.vue'),
    },
  ],
} satisfies RouterConfig
```

::note
Nuxt는 `routes` 함수에서 반환한 새 라우트에 대해, 제공한 컴포넌트의 `definePageMeta`에 정의된 메타데이터를 보강하지 않습니다. 그렇게 되길 원한다면 [빌드 타임에 호출되는](/docs/4.x/api/advanced/hooks#nuxt-hooks-build-time) `pages:extend` 훅을 사용해야 합니다.
::

### Pages 훅 %{#pages-hook}%

`pages:extend` Nuxt 훅을 사용하면 스캔된 라우트에서 페이지를 추가, 변경, 제거할 수 있습니다.

예를 들어 `.ts` 파일에 대한 라우트 생성을 막으려면:

```ts [nuxt.config.ts]
import type { NuxtPage } from '@nuxt/schema'

export default defineNuxtConfig({
  hooks: {
    'pages:extend' (pages) {
      // 라우트 추가
      pages.push({
        name: 'profile',
        path: '/profile',
        file: '~/extra-pages/profile.vue',
      })

      // 라우트 제거
      function removePagesMatching (pattern: RegExp, pages: NuxtPage[] = []) {
        const pagesToRemove: NuxtPage[] = []
        for (const page of pages) {
          if (page.file && pattern.test(page.file)) {
            pagesToRemove.push(page)
          } else {
            removePagesMatching(pattern, page.children)
          }
        }
        for (const page of pagesToRemove) {
          pages.splice(pages.indexOf(page), 1)
        }
      }
      removePagesMatching(/\.ts$/, pages)
    },
  },
})
```

### Nuxt 모듈 %{#nuxt-module}%

특정 기능과 관련된 페이지 집합 전체를 추가할 계획이라면 [Nuxt 모듈](/modules)을 사용하는 편이 좋을 수 있습니다.

[Nuxt kit](/docs/4.x/guide/going-further/kit)는 [라우트를 추가하는](/docs/4.x/api/kit/pages) 몇 가지 방법을 제공합니다:
- [`extendPages`](/docs/4.x/api/kit/pages#extendpages) (callback: pages => void)
- [`extendRouteRules`](/docs/4.x/api/kit/pages#extendrouterules) (route: string, rule: NitroRouteConfig, options: ExtendRouteRulesOptions)

## Router 옵션 %{#router-options}%

[`vue-router`](https://router.vuejs.org/api/interfaces/routeroptions)의 옵션을 사용자 지정하는 것 외에도, Nuxt는 router를 사용자 지정할 수 있는 [추가 옵션](/docs/4.x/api/nuxt-config#router)을 제공합니다.

### Using `router.options` %{#using-router-options}%

이는 [router options](/docs/4.x/api/nuxt-config#router)를 지정하는 권장 방식입니다.

```ts [app/router.options.ts]
import type { RouterConfig } from '@nuxt/schema'

export default {
} satisfies RouterConfig
```

`pages:routerOptions` 훅 안에 파일을 추가하면 router options 파일을 더 추가할 수 있습니다. 배열의 뒤쪽 항목이 앞쪽 항목을 덮어씁니다.

::callout
이 훅에서 router options 파일을 추가하면 페이지 기반 라우팅이 켜집니다. 단, `optional`이 설정된 경우에는 페이지 기반 라우팅이 이미 활성화된 경우에만 적용됩니다.
::

```ts [nuxt.config.ts]
import { createResolver } from '@nuxt/kit'

export default defineNuxtConfig({
  hooks: {
    'pages:routerOptions' ({ files }) {
      const resolver = createResolver(import.meta.url)
      // 라우트 추가
      files.push({
        path: resolver.resolve('./runtime/router-options'),
        optional: true,
      })
    },
  },
})
```

### Using `nuxt.config` %{#using-nuxt-config}%

**참고:** JSON으로 직렬화 가능한 [options](/docs/4.x/api/nuxt-config#router)만 구성할 수 있습니다:

- `linkActiveClass`
- `linkExactActiveClass`
- `end`
- `sensitive`
- `strict`
- `hashMode`
- `scrollBehaviorType`

```ts [nuxt.config]
export default defineNuxtConfig({
  router: {
    options: {},
  },
})
```

### 해시 모드 (SPA) %{#hash-mode-spa}%

`hashMode` [config](/docs/4.x/api/nuxt-config#router)를 사용해 SPA 모드에서 해시 히스토리를 활성화할 수 있습니다. 이 모드에서 router는 내부적으로 전달되는 실제 URL 앞에 해시 문자(#)를 사용합니다. 활성화하면 **URL이 서버로 전송되지 않으며** **SSR은 지원되지 않습니다**.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ssr: false,
  router: {
    options: {
      hashMode: true,
    },
  },
})
```

### 해시 링크의 스크롤 동작 %{#scroll-behavior-for-hash-links}%

선택적으로 해시 링크의 스크롤 동작을 사용자 지정할 수 있습니다. [config](/docs/4.x/api/nuxt-config#router)를 `smooth`로 설정하고 해시 링크가 있는 페이지를 로드하면 (예: `https://example.com/blog/my-article#comments`) 브라우저가 해당 앵커로 부드럽게 스크롤하는 것을 볼 수 있습니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  router: {
    options: {
      scrollBehaviorType: 'smooth',
    },
  },
})
```

#### 사용자 정의 History (고급) %{#custom-history-advanced}%

base URL을 받아 history 모드를 반환하는 함수를 사용해 선택적으로 history 모드를 덮어쓸 수 있습니다. `null` 또는 `undefined`를 반환하면 Nuxt는 기본 history로 되돌아갑니다.

```ts [router.options.ts]
import type { RouterConfig } from '@nuxt/schema'
import { createMemoryHistory } from 'vue-router'

export default {
  // https://router.vuejs.org/api/interfaces/routeroptions
  history: base => import.meta.client ? createMemoryHistory(base) : null, /* 기본값 */
} satisfies RouterConfig
```
