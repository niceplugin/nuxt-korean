## 소스맵 %{#sourcemaps}%

소스맵은 기본적으로 서버 빌드에 활성화되어 있고 클라이언트 빌드에는 dev 모드에서 활성화되지만, 구성에서 더 구체적으로 설정할 수 있습니다.

```ts
export default defineNuxtConfig({
  // 또는 sourcemap: true
  sourcemap: {
    server: true,
    client: true,
  },
})
```

## Node Inspector로 디버깅하기 %{#debugging-with-node-inspector}%

[Node inspector](https://nodejs.org/en/learn/getting-started/debugging)를 사용해 Nuxt 서버 사이드를 디버깅할 수 있습니다.

```bash
nuxt dev --inspect
```
이렇게 하면 디버거가 활성화된 상태로 Nuxt가 `dev` 모드에서 시작됩니다. 모든 것이 올바르게 동작하면 Chrome DevTools에 Node.js 아이콘이 나타나고 디버거에 연결할 수 있습니다.

::important
Node.js와 Chrome 프로세스는 동일한 플랫폼에서 실행되어야 합니다. 이는 Docker 내부에서는 동작하지 않습니다.
::

## IDE에서 디버깅하기 %{#debugging-in-your-ide}%

개발하는 동안 IDE에서 Nuxt 앱을 디버깅할 수 있습니다.

### VS Code 디버그 구성 예시 %{#example-vs-code-debug-configuration}%

아래 구성을 웹 브라우저 경로에 맞게 수정해야 할 수 있습니다. 자세한 내용은 [VS Code 디버그 구성 문서](https://code.visualstudio.com/docs/debugtest/debugging#_launch-configurations)를 참고하세요.

```json5
{
  // IntelliSense를 사용해 가능한 속성을 확인하세요.
  // 마우스를 올려 기존 속성 설명을 확인하세요.
  "version": "0.2.0",
  "configurations": [
    {
      "type": "chrome",
      "request": "launch",
      "name": "client: chrome",
      "url": "http://localhost:3000",
      // 이것은 기본값이 `app`인 Nuxt의 `srcDir`를 가리켜야 합니다
      "webRoot": "${workspaceFolder}/app"
    },
    {
      "type": "node",
      "request": "launch",
      "name": "server: nuxt",
      "outputCapture": "std",
      "program": "${workspaceFolder}/node_modules/nuxt/bin/nuxt.mjs",
      "args": [
        "dev"
      ],
    }
  ],
  "compounds": [
    {
      "name": "fullstack: nuxt",
      "configurations": [
        "server: nuxt",
        "client: chrome"
      ]
    }
  ]
}
```

평소 사용하던 브라우저 확장을 선호한다면 위 _chrome_ 구성에 다음을 추가하세요:

```json5
"userDataDir": false,
```

### JetBrains IDE 디버그 구성 예시 %{#example-jetbrains-ides-debug-configuration}%

IntelliJ IDEA, WebStorm, PhpStorm 같은 JetBrains IDE에서도 Nuxt 앱을 디버깅할 수 있습니다.

1. 프로젝트 루트 디렉터리에 새 파일을 만들고 이름을 `nuxt.run.xml`로 지정합니다.

2. `nuxt.run.xml` 파일을 열고 다음 디버그 구성을 붙여넣습니다:

```html
<component name="ProjectRunConfigurationManager">
  <configuration default="false" name="client: chrome" type="JavascriptDebugType" uri="http://localhost:3000" useFirstLineBreakpoints="true">
    <method v="2" />
  </configuration>

  <configuration default="false" name="server: nuxt" type="NodeJSConfigurationType" application-parameters="dev" path-to-js-file="$PROJECT_DIR$/node_modules/nuxt/bin/nuxt.mjs" working-dir="$PROJECT_DIR$">
    <method v="2" />
  </configuration>

  <configuration default="false" name="fullstack: nuxt" type="CompoundRunConfigurationType">
    <toRun name="client: chrome" type="JavascriptDebugType" />
    <toRun name="server: nuxt" type="NodeJSConfigurationType" />
    <method v="2" />
  </configuration>
</component>
```
