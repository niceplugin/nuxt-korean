이벤트를 사용하는 것은 애플리케이션을 느슨하게 결합하고 코드의 서로 다른 부분 간 통신을 더 유연하고 모듈식으로 만드는 훌륭한 방법입니다. 이벤트는 서로 의존하지 않는 여러 리스너를 가질 수 있습니다. 예를 들어 주문이 발송될 때마다 사용자에게 이메일을 보내고 싶을 수 있습니다. 주문 처리 코드를 이메일 코드에 직접 결합하는 대신, 리스너가 수신해 이메일 발송에 사용할 수 있는 이벤트를 emit할 수 있습니다.

Nuxt 이벤트 시스템은 [unjs/hookable](https://github.com/unjs/hookable) 기반으로 동작하며, 이는 Nuxt hooks 시스템에도 사용되는 동일한 라이브러리입니다.

## 이벤트와 리스너 만들기 %{#creating-events-and-listeners}%

`hook` 메서드를 사용해 직접 커스텀 이벤트를 만들 수 있습니다:

```ts
const nuxtApp = useNuxtApp()

nuxtApp.hook('app:user:registered', (payload) => {
  console.log('새 사용자가 등록되었습니다!', payload)
})
```

이벤트를 emit하고 모든 리스너에 알리려면 `callHook`을 사용하세요:

```ts
const nuxtApp = useNuxtApp()

await nuxtApp.callHook('app:user:registered', {
  id: 1,
  name: 'John Doe',
})
```

payload 객체를 사용해 emitter와 리스너 간 양방향 통신을 구현할 수도 있습니다. payload는 참조로 전달되므로 리스너가 이를 수정해 emitter에 데이터를 되돌려줄 수 있습니다.

```ts
const nuxtApp = useNuxtApp()

nuxtApp.hook('app:user:registered', (payload) => {
  payload.message = '우리 앱에 오신 것을 환영합니다!'
})

const payload = {
  id: 1,
  name: 'John Doe',
}

await nuxtApp.callHook('app:user:registered', {
  id: 1,
  name: 'John Doe',
})

// payload.message는 '우리 앱에 오신 것을 환영합니다!'가 됩니다
```

::tip
**Nuxt DevTools** Hooks 패널을 사용하면 모든 이벤트를 살펴볼 수 있습니다.
::
