---
title: "나이틀리 릴리스 채널"
description: "나이틀리 릴리스 채널을 사용하면 저장소의 최신 커밋으로 직접 빌드된 Nuxt를 사용할 수 있습니다."
---

Nuxt에는 매일 커밋, 개선 사항, 버그 수정이 반영됩니다. 다음 릴리스 전에 이를 더 일찍 시험해 보고 싶다면 이 채널을 사용할 수 있습니다.

[nuxt/nuxt](https://github.com/nuxt/nuxt)의 `main` 브랜치에 커밋이 병합되고 **모든 테스트를 통과하면**, GitHub Actions를 사용해 자동 npm 릴리스를 트리거합니다.

이러한 'nightly' 릴리스를 사용해 새로운 기능과 변경 사항을 베타 테스트할 수 있습니다.

이러한 'nightly' 릴리스의 빌드 및 배포 방식과 품질은 안정 버전과 동일합니다. 차이점은 GitHub 저장소의 업데이트를 자주 확인해야 한다는 점뿐입니다. 검토 과정과 자동화된 테스트에서 회귀가 잡히지 않을 가능성이 약간 있습니다. 그래서 내부적으로도 각 릴리스 전에 모든 것을 한 번 더 점검하기 위해 이 채널을 사용합니다.

::note
나이틀리 릴리스 채널에서만 사용할 수 있는 기능은 문서에서 알림으로 표시됩니다.
::

::warning
`latest` 나이틀리 릴리스 채널은 현재 Nuxt v4 브랜치를 추적하고 있으므로 지금은 호환성이 깨지는 변경 사항이 포함될 가능성이 특히 높습니다 &mdash; 주의하세요! `"nuxt": "npm:nuxt-nightly@3x"`로 3.x 브랜치 나이틀리 릴리스를 사용할 수도 있습니다.
::

## 사용 시작 %{#opting-in}%

`package.json` 안의 `nuxt` 의존성을 업데이트하세요:

```diff [package.json]
{
  "devDependencies": {
--    "nuxt": "^4.0.0"
++    "nuxt": "npm:nuxt-nightly@latest"
  }
}
```

lockfile(`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `bun.lock` 또는 `bun.lockb`)를 제거하고 의존성을 다시 설치하세요.

## 사용 중단 %{#opting-out}%

`package.json` 안의 `nuxt` 의존성을 업데이트하세요:

```diff [package.json]
{
  "devDependencies": {
--    "nuxt": "npm:nuxt-nightly@latest"
++    "nuxt": "^4.0.0"
  }
}
```

lockfile(`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `bun.lock` 또는 `bun.lockb`)를 제거하고 의존성을 다시 설치하세요.

## 나이틀리 `@nuxt/cli` 사용하기 %{#using-nightly-nuxt-cli}%

[nuxt/cli](https://github.com/nuxt/cli)의 최신 버전을 사용해 보려면:

```bash [Terminal]
npx @nuxt/cli-nightly@latest [command]
```

사용 가능한 명령에 대해 더 알아보세요.
