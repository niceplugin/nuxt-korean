---
title: "나이트리 릴리스 채널"
description: "나이트리 릴리스 채널을 사용하면 저장소의 최신 커밋으로부터 직접 빌드된 Nuxt를 사용할 수 있습니다."
---

Nuxt는 매일 커밋, 개선 사항 및 버그 수정을 반영합니다. 다음 릴리스 전에 더 일찍 이를 테스트해 볼 수 있습니다.

[nuxt/nuxt](https://github.com/nuxt/nuxt)의 `main` 브랜치에 커밋이 머지되고 **모든 테스트를 통과하면**, GitHub Actions를 사용해 자동 npm 릴리스를 트리거합니다.

이러한 '나이트리' 릴리스를 사용해 새로운 기능과 변경 사항을 베타 테스트할 수 있습니다.

이러한 '나이트리' 릴리스의 빌드 및 배포 방식과 품질은 안정 버전과 동일합니다. 유일한 차이점은 GitHub 저장소에서 업데이트를 자주 확인해야 한다는 점입니다. 리뷰 과정과 자동화된 테스트에서 회귀(regression)가 잡히지 않을 약간의 가능성이 있습니다. 따라서 우리는 각 릴리스 전에 모든 것을 이중 확인하기 위해 내부적으로 이 채널을 사용합니다.

::note
나이트리 릴리스 채널에서만 사용할 수 있는 기능은 문서에서 알림으로 표시됩니다.
::

::warning
`latest` 나이트리 릴리스 채널은 현재 Nuxt v4 브랜치를 추적하고 있으므로, 지금은 특히 파괴적인 변경 사항이 포함될 가능성이 높습니다 &mdash; 주의해서 사용하세요! `"nuxt": "npm:nuxt-nightly@3x"`로 3.x 브랜치 나이트리 릴리스에 opt-in 할 수 있습니다.
::

## Opting In %{opting-in}%

`package.json` 안의 `nuxt` 의존성을 업데이트하세요:

```diff [package.json]
{
  "devDependencies": {
--    "nuxt": "^4.0.0"
++    "nuxt": "npm:nuxt-nightly@latest"
  }
}
```

락 파일(`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `bun.lock` 또는 `bun.lockb`)을 제거하고 의존성을 다시 설치하세요.

## Opting Out %{opting-out}%

`package.json` 안의 `nuxt` 의존성을 업데이트하세요:

```diff [package.json]
{
  "devDependencies": {
--    "nuxt": "npm:nuxt-nightly@latest"
++    "nuxt": "^4.0.0"
  }
}
```

락 파일(`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `bun.lock` 또는 `bun.lockb`)을 제거하고 의존성을 다시 설치하세요.

## 나이트리 `@nuxt/cli` 사용하기 %{using-nightly-nuxtcli}%

최신 버전의 [nuxt/cli](https://github.com/nuxt/cli)를 사용해 보려면:

```bash [Terminal]
npx @nuxt/cli-nightly@latest [command]
```

::read-more{to="/docs/4.x/api/commands"}
사용 가능한 명령어에 대해 더 알아보세요.
::
