테스트는 다양한 설정에서 모듈이 기대대로 동작하는지 확인하는 데 도움이 됩니다. 이 섹션에서는 모듈에 대해 여러 종류의 테스트를 수행하는 방법을 알아봅니다.

## 단위 테스트 작성하기 %{#write-unit-tests}%

::tip
Nuxt 모듈에서 단위 테스트와 통합 테스트를 더 쉽게 만드는 방법을 계속 논의하고 탐색하고 있습니다.
:br :br
[이 RFC를 확인하고 논의에 참여해 보세요](https://github.com/nuxt/nuxt/discussions/18399).
::

## E2E 테스트 작성하기 %{#write-e2e-tests}%

[Nuxt Test Utils](/docs/4.x/getting-started/testing)는 모듈을 엔드 투 엔드 방식으로 테스트하는 데 가장 적합한 라이브러리입니다. 다음과 같은 워크플로를 사용할 수 있습니다:

1. `test/fixtures/*` 안에 "fixture"로 사용할 Nuxt 애플리케이션을 만듭니다
2. 테스트 파일 안에서 이 fixture로 Nuxt를 설정합니다
3. `@nuxt/test-utils`의 유틸리티로 fixture와 상호작용합니다(예: 페이지 가져오기)
4. 이 fixture와 관련된 검사를 수행합니다(예: "HTML에 ...이 포함됨")
5. 반복합니다

실제로 fixture는 다음과 같습니다:

```ts [test/fixtures/ssr/nuxt.config.ts]
// 1. "fixture"로 사용할 Nuxt 애플리케이션을 만듭니다
import MyModule from '../../../src/module'

export default defineNuxtConfig({
  ssr: true,
  modules: [
    MyModule,
  ],
})
```

그리고 해당 테스트는 다음과 같습니다:

```ts [test/rendering.ts]
import { describe, expect, it } from 'vitest'
import { fileURLToPath } from 'node:url'
import { $fetch, setup } from '@nuxt/test-utils/e2e'

describe('ssr', async () => {
  // 2. 테스트 파일 안에서 이 fixture로 Nuxt를 설정합니다
  await setup({
    rootDir: fileURLToPath(new URL('./fixtures/ssr', import.meta.url)),
  })

  it('인덱스 페이지를 렌더링한다', async () => {
    // 3. `@nuxt/test-utils`의 유틸리티로 fixture와 상호작용합니다
    const html = await $fetch('/')

    // 4. 이 fixture와 관련된 검사를 수행합니다
    expect(html).toContain('<div>ssr</div>')
  })
})

// 5. 반복합니다
describe('csr', async () => { /* ... */ })
```

::tip
이러한 워크플로의 예시는 [module starter](https://github.com/nuxt/starter/blob/module/test/basic.test.ts)에서 확인할 수 있습니다.
::

## 수동으로 테스트하기 %{#test-manually}%

개발 중인 모듈을 시험해 볼 playground Nuxt 애플리케이션이 있으면 매우 유용합니다. [module starter에는 이를 위한 구성이 포함되어 있습니다](/docs/4.x/guide/modules/getting-started#develop-your-module).

다른 Nuxt 애플리케이션(모듈 저장소에 포함되지 않은 애플리케이션)에서도 로컬에서 모듈을 테스트할 수 있습니다. 이렇게 하려면 [`npm pack`](https://docs.npmjs.com/cli/commands/npm-pack/) 명령이나 이에 해당하는 패키지 매니저 명령으로 모듈의 tarball을 만든 뒤, 테스트 프로젝트의 `package.json` 패키지에 `"my-module": "file:/path/to/tarball.tgz"`처럼 추가하면 됩니다.

그 후에는 일반 프로젝트에서처럼 `my-module`을 참조할 수 있습니다.
