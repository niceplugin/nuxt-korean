Nuxt를 만들면서 우리는 새로운 서버 엔진 [Nitro](https://nitro.build/)를 만들었습니다.

Nitro는 다음과 같은 다양한 기능과 함께 제공됩니다:

- Node.js, 브라우저, 서비스 워커 등을 위한 크로스 플랫폼 지원.
- 기본 제공되는 서버리스 지원.
- API 라우트 지원.
- 자동 코드 분할 및 비동기 로드 청크.
- 정적 + 서버리스 사이트를 위한 하이브리드 모드.
- 핫 모듈 리로딩이 가능한 개발 서버.

## API 레이어 %{#api-layer}%

서버 [API endpoints](/docs/4.x/directory-structure/server#server-routes)와 [Middleware](/docs/4.x/directory-structure/server#server-middleware)는 내부적으로 [h3](https://github.com/h3js/h3)를 사용하는 Nitro에 의해 추가됩니다.

주요 기능은 다음과 같습니다:

- 핸들러가 자동 처리되는 JSON 응답을 위해 객체/배열을 직접 반환할 수 있습니다
- 핸들러가 promise를 반환할 수 있으며, 이 경우 await 처리됩니다 (`res.end()`와 `next()`도 지원)
- body 파싱, 쿠키 처리, 리다이렉트, 헤더 등을 위한 헬퍼 함수

[h3 문서](https://github.com/h3js/h3)에서 더 자세한 내용을 확인하세요.

`server/` 디렉터리의 API 레이어에 대해 더 알아보세요.

## 직접 API 호출 %{#direct-api-calls}%

Nitro는 전역에서 사용할 수 있는 [`$fetch`](/docs/4.x/api/utils/dollarfetch) 헬퍼를 통해 라우트를 '직접' 호출할 수 있게 합니다. 브라우저에서 실행되면 서버에 API 호출을 수행하지만, 서버에서 실행되면 관련 함수를 직접 호출하므로 **추가 API 호출을 줄일 수 있습니다**.

[`$fetch`](/docs/4.x/api/utils/dollarfetch) API는 [ofetch](https://github.com/unjs/ofetch)를 사용하며, 주요 기능은 다음과 같습니다:

- JSON 응답 자동 파싱(필요하면 raw response 접근 가능)
- 요청 body와 params 자동 처리 및 올바른 `Content-Type` 헤더 설정

`$fetch` 기능에 대한 자세한 내용은 [ofetch](https://github.com/unjs/ofetch)를 확인하세요.

## 타입이 지정된 API 라우트 %{#typed-api-routes}%

API 라우트(또는 미들웨어)를 사용할 때 `res.end()`로 응답을 보내는 대신 값을 반환하면 Nitro가 해당 라우트에 대한 타입 정보를 생성합니다.

이 타입은 [`$fetch()`](/docs/4.x/api/utils/dollarfetch) 또는 [`useFetch()`](/docs/4.x/api/composables/use-fetch)를 사용할 때 접근할 수 있습니다.

## 독립 실행형 서버 %{#standalone-server}%

Nitro는 `node_modules`에 의존하지 않는 독립 실행형 서버 dist를 생성합니다.

Nuxt 2의 서버는 독립 실행형이 아니며 `nuxt start` 실행( [`nuxt-start`](https://www.npmjs.com/package/nuxt-start) 또는 [`nuxt`](https://www.npmjs.com/package/nuxt) 배포판 사용) 또는 커스텀 프로그래밍 방식 사용을 통해 Nuxt 코어의 일부가 함께 동작해야 합니다. 이런 방식은 취약하고 깨지기 쉬우며 서버리스와 서비스 워커 환경에 적합하지 않습니다.

Nuxt는 `nuxt build`를 실행할 때 이 dist를 [`.output`](/docs/4.x/directory-structure/output) 디렉터리에 생성합니다.

이 출력물에는 어떤 환경에서든(실험적인 브라우저 서비스 워커 포함) Nuxt 서버를 실행하고 정적 파일을 제공할 수 있는 런타임 코드가 포함되어 있어 Nuxt를 진정한 JAMstack용 하이브리드 프레임워크로 만들어 줍니다. 또한 Nuxt는 다중 소스 드라이버와 로컬 에셋을 지원하는 네이티브 스토리지 레이어도 구현합니다.
