## ESLint %{#eslint}%

Nuxt에서 권장하는 접근 방식은 [`@nuxt/eslint`](https://eslint.nuxt.com/packages/module) 모듈을 사용해 ESLint 지원을 활성화하는 것이며, 이 모듈은 프로젝트를 인식하는 ESLint 구성을 설정해 줍니다.

:::callout{icon="i-lucide-lightbulb"}
이 모듈은 [새 ESLint flat config format](https://eslint.org/docs/latest/use/configure/configuration-files)을 위해 설계되었으며, 이는 [ESLint v9부터 기본 형식](https://eslint.org/blog/2024/04/eslint-v9.0.0-released/)입니다. 레거시 `.eslintrc` 구성을 사용 중이라면 [`@nuxt/eslint-config`로 수동 구성](https://eslint.nuxt.com/packages/config#customizing-the-config)해야 합니다. 미래 호환성을 위해 flat config로 마이그레이션하는 것을 강력히 권장합니다.
:::

## 빠른 설정 %{#quick-setup}%

```bash
npx nuxt module add eslint
```

Nuxt 앱을 시작하면 프로젝트 루트 아래에 `eslint.config.mjs` 파일이 생성됩니다. 필요에 따라 이를 사용자 지정할 수 있습니다.

[Nuxt ESLint 문서](https://eslint.nuxt.com/packages/module)에서 모듈과 사용자 지정 방법을 더 자세히 알아볼 수 있습니다.
