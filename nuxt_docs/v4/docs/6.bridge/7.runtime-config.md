## Runtime Config 업데이트 %{#update-runtime-config}%

Nuxt 3는 Nuxt 2와 다르게 runtime config에 접근하며, 새로운 통합 `runtimeConfig` 옵션을 사용합니다.

먼저 `publicRuntimeConfig`와 `privateRuntimeConfig` 속성을 `runtimeConfig`라는 새 속성 하나로 합쳐야 하며, 공개 설정은 `public`이라는 키 안에 넣어야 합니다.

```diff
// nuxt.config.js
- privateRuntimeConfig: {
-   apiKey: process.env.NUXT_API_KEY || 'super-secret-key'
- },
- publicRuntimeConfig: {
-   websiteURL: 'https://public-data.com'
- }
+ runtimeConfig: {
+   apiKey: process.env.NUXT_API_KEY || 'super-secret-key',
+   public: {
+     websiteURL: 'https://public-data.com'
+   }
+ }
```

이는 공개 runtime config에 접근해야 할 때 `public`이라는 속성 뒤에 위치한다는 뜻이기도 합니다. public runtime config를 사용한다면 코드를 업데이트해야 합니다.

```diff
// MyWidget.vue
- <div>Website: {{ $config.websiteURL }}</div>
+ <div>Website: {{ $config.public.websiteURL }}</div>
```
