---
title: 메타 태그
description: 'Nuxt 2에서 Nuxt Bridge의 새로운 메타 태그로 마이그레이션하는 방법을 알아보세요.'
---

`head`로 컴포넌트 상태에 접근해야 한다면 [`useHead`](/docs/4.x/api/composables/use-head) 사용으로 마이그레이션해야 합니다.

Options API를 사용해야 한다면 `defineNuxtComponent`를 사용할 때 `head()` 메서드를 사용할 수 있습니다.

## Migration %{#migration}%

### `bridge.meta` 설정 %{#set-bridge-meta}%

```js
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    meta: true,
    nitro: false, // Nitro로의 마이그레이션이 완료되면 true로 설정
  },
})
```

### head 속성 업데이트 %{#update-head-properties}%

`nuxt.config`에서 `head`를 `app.head`로 이름을 바꾸세요. (객체에는 더 이상 중복 제거를 위한 `hid` 키가 없습니다.)

::code-group

```ts [Nuxt 2]
export default {
  head: {
    titleTemplate: '%s - Nuxt',
    meta: [
      { charset: 'utf-8' },
      { name: 'viewport', content: 'width=device-width, initial-scale=1' },
      { hid: 'description', name: 'description', content: 'Meta description' },
    ],
  },
}
```

```ts [Nuxt 3]
export default defineNuxtConfig({
  app: {
    head: {
      titleTemplate: '%s - Nuxt',
      meta: [
        { charset: 'utf-8' },
        { name: 'viewport', content: 'width=device-width, initial-scale=1' },
        { name: 'description', content: 'Meta description' },
      ],
    },
  },
})
```

::

## `useHead` 컴포저블 %{#usehead-composables}%

Nuxt Bridge는 새로운 [`useHead`](/docs/4.x/api/composables/use-head) 컴포저블로 접근할 수 있는 새로운 Nuxt 3 메타 API를 제공합니다.

```vue
<script setup lang="ts">
useHead({
  title: 'My Nuxt App',
})
</script>
```

::tip
이 [`useHead`](/docs/4.x/api/composables/use-head) 컴포저블은 내부적으로 `vue-meta` 대신 `@unhead/vue`를 사용해 `<head>`를 조작합니다.
::

::warning
충돌할 수 있으므로 [`useHead`](/docs/4.x/api/composables/use-head)와 함께 기본 Nuxt 2 `head()` 속성을 추가로 사용하지 않는 것을 권장합니다.
::

이 컴포저블의 사용법에 대한 자세한 내용은 [문서](/docs/4.x/getting-started/seo-meta)를 참고하세요.

## Options API %{#options-api}%

```vue
<script>
// Options API의 `head` 메서드를 사용한다면 `defineNuxtComponent`를 사용해야 합니다
export default defineNuxtComponent({
  head (nuxtApp) {
    // `head`는 nuxt app을 전달받지만 컴포넌트 인스턴스에는 접근할 수 없습니다
    return {
      meta: [{
        name: 'description',
        content: 'This is my page description.',
      }],
    }
  },
})
</script>
```

::warning
잠재적인 브레이킹 체인지: `head`는 nuxt app을 전달받지만 컴포넌트 인스턴스에는 접근할 수 없습니다. `head` 안의 코드가 `this` 또는 `this.$data`를 통해 data 객체에 접근하려고 한다면 `useHead` 컴포저블로 마이그레이션해야 합니다.
::

## Title Template %{#title-template}%

함수(완전한 제어를 위해)를 사용하고 싶다면, 이는 nuxt.config에서 설정할 수 없으며 대신 `/layouts` 디렉터리 안에서 설정하는 것을 권장합니다.

```vue [app/layouts/default.vue]
<script setup lang="ts">
useHead({
  titleTemplate: (titleChunk) => {
    return titleChunk ? `${titleChunk} - Site Title` : 'Site Title'
  },
})
</script>
```
