::warning
Nuxt Bridge는 Nuxt 3와 동일한 기능([docs](/docs/4.x/guide/concepts/auto-imports))을 제공하지만 몇 가지 제한이 있습니다. 특히 [`useAsyncData`](/docs/4.x/api/composables/use-async-data)와 [`useFetch`](/docs/4.x/api/composables/use-fetch) 컴포저블은 사용할 수 없습니다. 자세한 내용은 이 페이지의 나머지 부분을 읽어 주세요.
::

Bridge는 Nuxt 모듈을 설치하고 활성화하는 것만으로 Nuxt 3의 새로운 기능 다수를 경험할 수 있게 해 주는 전방 호환 레이어입니다.

Nuxt Bridge를 사용하면 프로젝트가 Nuxt 3에 (거의) 준비되었는지 확인할 수 있고, Nuxt 3 전환을 점진적으로 진행할 수 있습니다.

## 첫 단계 %{#first-step}%

### Nuxt 2 업그레이드 %{#upgrade-nuxt-2}%

개발 서버(`nuxt dev`)가 실행 중이 아닌지 확인하고, 패키지 lock 파일(`package-lock.json`, `yarn.lock`)을 제거한 다음 최신 Nuxt 2 버전을 설치하세요:

```diff [package.json]
- "nuxt": "^2.16.3"
+ "nuxt": "^2.17.3"
```

그런 다음 의존성을 다시 설치하세요:

::code-group{sync="pm"}

```bash [npm]
npm install
```

```bash [yarn]
yarn install
```

```bash [pnpm]
pnpm install
```

```bash [bun]
bun install
```

```bash [deno]
deno install
```

::

::note
설치가 완료되면 계속 진행하기 전에 development와 production 빌드가 모두 예상대로 동작하는지 확인하세요.
::

### Nuxt Bridge 설치 %{#install-nuxt-bridge}%

개발 의존성으로 `@nuxt/bridge`와 `nuxi`를 설치하세요:

::code-group{sync="pm"}

```bash [npm]
npm install -D @nuxt/bridge nuxi
```

```bash [yarn]
yarn add --dev @nuxt/bridge nuxi
```

```bash [pnpm]
pnpm add -D @nuxt/bridge nuxi
```

```bash [bun]
bun add -D @nuxt/bridge nuxi
```

```bash [deno]
deno add -D npm:@nuxt/bridge npm:nuxi
```

::

### `nuxt.config` 업데이트 %{#update-nuxt-config}%

구성 파일에서 `module.exports`, `require`, `require.resolve` 같은 CommonJS 문법은 사용하지 않도록 해 주세요. 곧 더 이상 권장되지 않으며 지원도 중단될 예정입니다.

대신 정적 `import`, 동적 `import()`, `export default`를 사용할 수 있습니다. [`nuxt.config.ts`](/docs/4.x/directory-structure/nuxt-config)로 이름을 바꿔 TypeScript를 사용하는 것도 가능하며 권장됩니다.

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: false,
})
```

### 명령어 업데이트 %{#update-commands}%

이제 `nuxt` 명령은 `nuxt2` 명령으로 변경해야 합니다.

```diff
{
  "scripts": {
-   "dev": "nuxt",
+   "dev": "nuxt2",
-   "build": "nuxt build",
+   "build": "nuxt2 build",
-   "start": "nuxt start",
+   "start": "nuxt2 start"
  }
}
```

여기서 `nuxt2`를 한 번 실행해 보세요. 애플리케이션이 이전과 같이 동작하는 것을 볼 수 있습니다.

(`bridge`가 false로 설정되어 있으면 애플리케이션은 변경 없이 이전처럼 동작합니다.)

## CommonJS에서 ESM으로 마이그레이션 %{#migrate-from-commonjs-to-esm}%

Nuxt 3는 TypeScript와 ECMAScript Modules를 기본적으로 지원합니다. 자세한 정보와 업그레이드 방법은 [Native ES Modules](/docs/4.x/guide/concepts/esm)를 참고하세요.
