---
title: Vite
description: 'Nuxt Bridge를 사용해 Nuxt 2 애플리케이션에 Vite를 활성화합니다.'
---

::warning
`vite`를 사용할 때는 [nitro](/docs/4.x/bridge/nitro)가 구성되어 있어야 합니다.
::

## 모듈 제거 %{#remove-modules}%

- `nuxt-vite` 제거: Bridge가 동일한 기능을 활성화합니다

## 설정 업데이트 %{#update-config}%

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    vite: true,
    nitro: true,
  },
})
```

## 설정 %{#configuration}%

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  vite: {
    // Vite용 설정
  },
})
```
