## `useRuntimeConfig` %{#useruntimeconfig}%

빌드 시점에는 resolve된 Nuxt [runtime config](/docs/4.x/guide/going-further/runtime-config)에 접근할 수 있습니다.

### 타입 %{#type}%

```ts
function useRuntimeConfig (): Record<string, unknown>
```

## `updateRuntimeConfig` %{#updateruntimeconfig}%

런타임 설정을 업데이트하는 것도 가능합니다. 이는 기존 런타임 설정과 병합되며, Nitro가 이미 초기화된 경우 Nitro runtime config를 다시 로드하기 위한 HMR 이벤트를 트리거합니다.

### 타입 %{#type}%

```ts
function updateRuntimeConfig (config: Record<string, unknown>): void | Promise<void>
```
