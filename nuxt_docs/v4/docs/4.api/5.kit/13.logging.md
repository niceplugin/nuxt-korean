Nuxt는 추가 기능과 함께 메시지를 기록할 수 있는 로거 인스턴스를 제공합니다. `useLogger`를 사용하면 로거 인스턴스를 가져올 수 있습니다.

## `useLogger` %{uselogger}%

로거 인스턴스를 반환합니다. 내부적으로 [consola](https://github.com/unjs/consola)를 사용합니다.

### Usage %{usage}%

```ts twoslash
import { defineNuxtModule, useLogger } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const logger = useLogger('my-module')

    logger.info('Hello from my module!')
  },
})
```

### Type %{type}%

```ts
function useLogger (tag?: string, options?: Partial<ConsolaOptions>): ConsolaInstance
```

### Parameters %{parameters}%

**`tag`**: 모든 로그 메시지에 접미사로 붙는 태그로, 타임스탬프 오른쪽에 표시됩니다.

**`options`**: Consola 설정 옵션입니다.

### Examples %{examples}%

```ts twoslash
import { defineNuxtModule, useLogger } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const logger = useLogger('my-module', { level: options.quiet ? 0 : 3 })

    logger.info('Hello from my module!')
  },
})
```
