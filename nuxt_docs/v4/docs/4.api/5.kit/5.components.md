컴포넌트는 Nuxt 애플리케이션의 구성 요소입니다. 사용자 인터페이스를 만들기 위해 사용할 수 있는 재사용 가능한 Vue 인스턴스입니다. Nuxt에서는 기본적으로 components 디렉터리의 컴포넌트가 자동 import됩니다. 하지만 다른 디렉터리에서 컴포넌트를 가져와야 하거나 필요에 따라 선택적으로 import하고 싶다면 `@nuxt/kit`가 `addComponentsDir`와 `addComponent` 메서드를 제공합니다. 이 유틸리티를 사용하면 필요에 더 잘 맞도록 컴포넌트 구성을 사용자 지정할 수 있습니다.

::tip{icon="i-lucide-video" to="https://vueschool.io/lessons/injecting-components-and-component-directories?friend=nuxt" target="_blank"}
컴포넌트 주입에 관한 Vue School 영상을 시청하세요.
::

## `addComponentsDir` %{#addcomponentsdir}%

컴포넌트를 스캔할 디렉터리를 등록하고 사용될 때만 import되도록 합니다. `global: true` 옵션을 지정하기 전까지는 컴포넌트가 전역 등록되지 않는다는 점에 유의하세요.

### Usage %{#usage}%

```ts
export default defineNuxtModule({
  meta: {
    name: '@nuxt/ui',
    configKey: 'ui',
  },
  setup () {
    addComponentsDir({
      path: resolve('./runtime/components'),
      prefix: 'U',
      pathPrefix: false,
    })
  },
})
```

### Type %{#type}%

```ts
function addComponentsDir (dir: ComponentsDir, opts: { prepend?: boolean } = {}): void
```

### Parameters %{#parameters}%

`dir` 다음 속성을 가진 객체:

| 속성              | 타입                                                                                     | 필수 여부 | 설명                                                                                                                                                                                                                                                    |
|-------------------|------------------------------------------------------------------------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `path`            | `string`                                                                                 | `true`   | 컴포넌트가 들어 있는 디렉터리 경로입니다 (절대 또는 상대). Nuxt 별칭(~ 또는 @)을 사용해 프로젝트 내부 디렉터리를 가리키거나 require와 비슷하게 npm 패키지 경로를 직접 사용할 수 있습니다.                                                            |
| `pattern`         | `string \| string[]`{lang="ts"}                                                          | `false`  | 지정된 경로에 대해 실행할 패턴을 받습니다.                                                                                                                                                                                                              |
| `ignore`          | `string[]`                                                                               | `false`  | 지정된 경로에 대해 실행할 무시 패턴입니다.                                                                                                                                                                                                              |
| `prefix`          | `string`                                                                                 | `false`  | 일치한 모든 컴포넌트 앞에 이 문자열을 접두사로 붙입니다.                                                                                                                                                                                                |
| `pathPrefix`      | `boolean`                                                                                | `false`  | 경로를 기준으로 컴포넌트 이름에 접두사를 붙입니다.                                                                                                                                                                                                      |
| `prefetch`        | `boolean`                                                                                | `false`  | 이 속성들(prefetch/preload)은 프로덕션에서 Lazy 접두사가 있는 컴포넌트를 webpack이 매직 코멘트를 통해 어떻게 처리할지 구성하는 데 사용됩니다. 자세한 내용은 [webpack documentation](https://webpack.js.org/api/module-methods/#magic-comments)을 참고하세요. |
| `preload`         | `boolean`                                                                                | `false`  | 이 속성들(prefetch/preload)은 프로덕션에서 Lazy 접두사가 있는 컴포넌트를 webpack이 매직 코멘트를 통해 어떻게 처리할지 구성하는 데 사용됩니다. 자세한 내용은 [webpack documentation](https://webpack.js.org/api/module-methods/#magic-comments)을 참고하세요. |
| `isAsync`         | `boolean`                                                                                | `false`  | 이 플래그는 Lazy 접두사 사용 여부와 관계없이 컴포넌트를 비동기(별도 청크 포함)로 로드해야 함을 나타냅니다.                                                                                                                                             |
| `extendComponent` | `(component: Component) => Promise<Component \| void> \| (Component \| void)`{lang="ts"} | `false`  | 디렉터리에서 발견된 각 컴포넌트마다 호출될 함수입니다. 컴포넌트 객체를 받아 컴포넌트 객체 또는 컴포넌트 객체로 resolve되는 promise를 반환해야 합니다.                                                                                                  |
| `global`          | `boolean`                                                                                | `false`  | 활성화하면 컴포넌트를 전역에서 사용할 수 있도록 등록합니다.                                                                                                                                                                                              |
| `island`          | `boolean`                                                                                | `false`  | 활성화하면 컴포넌트를 island로 등록합니다. island에 대해서는 [`<NuxtIsland/>`](/docs/4.x/api/components/nuxt-island) 컴포넌트 설명에서 더 읽어볼 수 있습니다.                                                                                           |
| `watch`           | `boolean`                                                                                | `false`  | 파일 추가와 삭제를 포함해 지정된 경로의 변경 사항을 감시합니다.                                                                                                                                                                                          |
| `extensions`      | `string[]`                                                                               | `false`  | Nuxt builder가 지원하는 확장자입니다.                                                                                                                                                                                                                    |
| `transpile`       | `'auto' \| boolean`{lang="ts"}                                                           | `false`  | build.transpile을 사용해 지정된 경로를 트랜스파일합니다. `'auto'`로 설정하면 경로에 `node_modules/`가 있을 때 `transpile: true`를 설정합니다.                                                                                                           |

`opts`

| 속성      | 타입      | 필수 여부 | 설명                                                                                                 |
|-----------|-----------|----------|------------------------------------------------------------------------------------------------------|
| `prepend` | `boolean` | `false`  | `true`로 설정하면 디렉터리는 `push()` 대신 `unshift()`로 배열 앞쪽에 추가됩니다.                    |

## `addComponent` %{#addcomponent}%

자동 import될 컴포넌트를 등록합니다.

### Usage %{#usage}%

```ts
import { addComponent, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  meta: {
    name: '@nuxt/image',
    configKey: 'image',
  },
  setup () {
    const resolver = createResolver(import.meta.url)

    addComponent({
      name: 'NuxtImg',
      filePath: resolver.resolve('./runtime/components/NuxtImg.vue'),
    })

    addComponent({
      name: 'NuxtPicture',
      filePath: resolver.resolve('./runtime/components/NuxtPicture.vue'),
    })
  },
})
```

### Type %{#type}%

```ts
function addComponent (options: AddComponentOptions): void
```

### Parameters %{#parameters}%

`options`: 다음 속성을 가진 객체:

| 속성              | 타입                                       | 필수 여부 | 설명                                                                                                                                                                                                                                                    |
|-------------------|--------------------------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|  
| `name`            | `string`                                   | `true`   | 컴포넌트 이름입니다.                                                                                                                                                                                                                                    |
| `filePath`        | `string`                                   | `true`   | 컴포넌트 경로입니다.                                                                                                                                                                                                                                    |
| `declarationPath` | `string`                                   | `false`  | 컴포넌트 선언 파일 경로입니다. 컴포넌트의 [type templates](/docs/4.x/api/kit/templates#addtypetemplate)를 생성하는 데 사용되며, 제공하지 않으면 대신 `filePath`가 사용됩니다.                                                                         |
| `pascalName`      | `string`                                   | `false`  | 파스칼 케이스 컴포넌트 이름입니다. 제공하지 않으면 컴포넌트 이름에서 생성됩니다.                                                                                                                                                                         |
| `kebabName`       | `string`                                   | `false`  | 케밥 케이스 컴포넌트 이름입니다. 제공하지 않으면 컴포넌트 이름에서 생성됩니다.                                                                                                                                                                           |
| `export`          | `string`                                   | `false`  | named export 또는 default export를 지정합니다. 제공하지 않으면 `'default'`로 설정됩니다.                                                                                                                                                                |
| `shortPath`       | `string`                                   | `false`  | 컴포넌트의 짧은 경로입니다. 제공하지 않으면 컴포넌트 경로에서 생성됩니다.                                                                                                                                                                                |
| `chunkName`       | `string`                                   | `false`  | 컴포넌트의 청크 이름입니다. 제공하지 않으면 컴포넌트 이름에서 생성됩니다.                                                                                                                                                                                |
| `prefetch`        | `boolean`                                  | `false`  | 이 속성들(prefetch/preload)은 프로덕션에서 Lazy 접두사가 있는 컴포넌트를 webpack이 매직 코멘트를 통해 어떻게 처리할지 구성하는 데 사용됩니다. 자세한 내용은 [webpack documentation](https://webpack.js.org/api/module-methods/#magic-comments)을 참고하세요. |  
| `preload`         | `boolean`                                  | `false`  | 이 속성들(prefetch/preload)은 프로덕션에서 Lazy 접두사가 있는 컴포넌트를 webpack이 매직 코멘트를 통해 어떻게 처리할지 구성하는 데 사용됩니다. 자세한 내용은 [webpack documentation](https://webpack.js.org/api/module-methods/#magic-comments)을 참고하세요. |
| `global`          | `boolean`                                  | `false`  | 활성화하면 컴포넌트를 전역에서 사용할 수 있도록 등록합니다.                                                                                                                                                                                               |
| `island`          | `boolean`                                  | `false`  | 활성화하면 컴포넌트를 island로 등록합니다. island에 대해서는 [`<NuxtIsland/>`](/docs/4.x/api/components/nuxt-island) 컴포넌트 설명에서 더 읽어볼 수 있습니다.                                                                                           |
| `mode`            | `'client' \| 'server' \| 'all'`{lang="ts"} | `false`  | 이 옵션은 컴포넌트를 클라이언트, 서버 또는 양쪽 모두에서 렌더링할지 나타냅니다. 기본적으로는 클라이언트와 서버 모두에서 렌더링됩니다.                                                                                                                   |
| `priority`        | `number`                                   | `false`  | 컴포넌트 우선순위입니다. 동일한 이름의 컴포넌트가 여러 개 있으면 가장 높은 우선순위를 가진 것이 사용됩니다.                                                                                                                                              |

### Examples %{#examples}%

npm 패키지에서 컴포넌트를 자동 import하고 싶고 그 컴포넌트가 default가 아닌 named export라면 `export` 옵션으로 지정할 수 있습니다.

```ts
import { addComponent, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    // import { MyComponent as MyAutoImportedComponent } from 'my-npm-package'
    addComponent({
      name: 'MyAutoImportedComponent',
      export: 'MyComponent',
      filePath: 'my-npm-package',
    })
  },
})
```
