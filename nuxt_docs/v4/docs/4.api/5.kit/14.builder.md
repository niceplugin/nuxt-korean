Nuxt는 [Vite](https://github.com/nuxt/nuxt/tree/main/packages/vite)와 [webpack](https://github.com/nuxt/nuxt/tree/main/packages/webpack)을 기반으로 하는 builder를 제공합니다. `extendViteConfig`와 `extendWebpackConfig` 함수를 사용해 각각에 전달되는 설정을 확장할 수 있습니다. 또한 `addVitePlugin`, `addWebpackPlugin`, `addBuildPlugin`을 통해 추가 플러그인을 넣을 수도 있습니다.

## `extendViteConfig` %{#extendviteconfig}%

Vite 설정을 확장합니다. 클라이언트와 서버 빌드 모두에 적용될 때 callback 함수가 여러 번 호출될 수 있습니다.

::warning
이 훅은 이제 deprecated되었으며, 대신 Vite 플러그인의 `config` 훅을 사용하거나, 환경별 설정이 필요하다면 `applyToEnvironment` 훅을 사용하는 것을 권장합니다.
::

### 사용법 %{#usage}%

```ts twoslash
import { defineNuxtModule, extendViteConfig } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    extendViteConfig((config) => {
      config.optimizeDeps ||= {}
      config.optimizeDeps.include ||= []
      config.optimizeDeps.include.push('cross-fetch')
    })
  },
})
```

Nuxt 5+에서 환경별 설정이 필요하다면 대신 `addVitePlugin()`을 사용하세요:

```ts twoslash
import { addVitePlugin, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    // 전역 설정용 (모든 환경에 영향)
    addVitePlugin(() => ({
      name: 'my-global-plugin',
      config (config) {
        // 환경 설정 전에 실행됩니다
        config.optimizeDeps ||= {}
        config.optimizeDeps.include ||= []
        config.optimizeDeps.include.push('cross-fetch')
      },
    }))

    // 환경별 설정용
    addVitePlugin(() => ({
      name: 'my-client-plugin',
      applyToEnvironment (environment) {
        return environment.name === 'client'
      },
      configEnvironment (name, config) {
        // 클라이언트 환경에만 영향을 줍니다
        config.optimizeDeps ||= {}
        config.optimizeDeps.include ||= []
        config.optimizeDeps.include.push('client-only-package')
      },
    }))
  },
})
```

::warning
**중요:** `config` 훅은 `applyToEnvironment`보다 먼저 실행되며 전역 설정을 수정합니다. 환경별 설정 변경에는 `configEnvironment`를 사용하세요.
::

### 매개변수 %{#parameters}%

**`callback`**: Vite 설정 객체와 함께 호출되는 callback 함수입니다.

**`options`**: callback 함수에 전달할 옵션입니다. 이 객체는 다음 속성을 가질 수 있습니다:

| Property  | Type      | Required | Description                                                                                                                                                                   |
|-----------|-----------|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `dev`     | `boolean` | `false`  | `true`로 설정하면 개발 모드 빌드 시 callback 함수가 호출됩니다.                                                                                                                |
| `build`   | `boolean` | `false`  | `true`로 설정하면 프로덕션 모드 빌드 시 callback 함수가 호출됩니다.                                                                                                             |
| `server`  | `boolean` | `false`  | `true`로 설정하면 서버 번들 빌드 시 callback 함수가 호출됩니다. **Nuxt 5+에서는 deprecated되었습니다.** 대신 `applyToEnvironment()`와 함께 `addVitePlugin()`을 사용하세요. |
| `client`  | `boolean` | `false`  | `true`로 설정하면 클라이언트 번들 빌드 시 callback 함수가 호출됩니다. **Nuxt 5+에서는 deprecated되었습니다.** 대신 `applyToEnvironment()`와 함께 `addVitePlugin()`을 사용하세요. |
| `prepend` | `boolean` | `false`  | `true`로 설정하면 callback 함수가 `push()` 대신 `unshift()`로 배열 앞에 추가됩니다.                                                                                            |

## `extendWebpackConfig` %{#extendwebpackconfig}%

webpack 설정을 확장합니다. 클라이언트와 서버 빌드 모두에 적용될 때 callback 함수가 여러 번 호출될 수 있습니다.

### 사용법 %{#usage}%

```ts twoslash
import { defineNuxtModule, extendWebpackConfig } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    extendWebpackConfig((config) => {
      config.module!.rules!.push({
        test: /\.txt$/,
        use: 'raw-loader',
      })
    })
  },
})
```

## `addVitePlugin` %{#addviteplugin}%

설정에 Vite 플러그인을 추가합니다.

::warning
Nuxt 5+에서는 `server: false` 또는 `client: false` 옵션으로 등록된 플러그인의 `config` 또는 `configResolved` 훅이 호출되지 않습니다. 대신 환경별 플러그인에는 `applyToEnvironment()` 메서드를 사용하세요.
::

### 사용법 %{#usage}%

```ts twoslash
// @errors: 2307
// ---cut---
import { addVitePlugin, defineNuxtModule } from '@nuxt/kit'
import { svg4VuePlugin } from 'vite-plugin-svg4vue'

export default defineNuxtModule({
  meta: {
    name: 'nuxt-svg-icons',
    configKey: 'nuxtSvgIcons',
  },
  defaults: {
    svg4vue: {
      assetsDirName: 'assets/icons',
    },
  },
  setup (options) {
    addVitePlugin(svg4VuePlugin(options.svg4vue))

    // 또는 하나의 환경에만 vite 플러그인을 추가
    addVitePlugin(() => ({
      name: 'my-client-plugin',
      applyToEnvironment (environment) {
        return environment.name === 'client'
      },
      // ... 나머지 클라이언트 전용 플러그인
    }))
  },
})
```

### 타입 %{#type}%

```ts twoslash
// @errors: 2391

import type { ExtendViteConfigOptions } from '@nuxt/kit'
// ---cut---
function addVitePlugin (pluginOrGetter: VitePlugin | VitePlugin[] | (() => VitePlugin | VitePlugin[]), options?: ExtendViteConfigOptions): void
```

::tip
Vite 플러그인에 대한 자세한 내용은 [Vite 웹사이트](https://vite.dev/guide/api-plugin)를 참고하세요. 필요에 맞는 플러그인은 [이 저장소](https://github.com/vitejs/awesome-vite#plugins)에서도 찾을 수 있습니다.
::

### 매개변수 %{#parameters}%

**`pluginOrGetter`**: Vite 플러그인 인스턴스 또는 Vite 플러그인 인스턴스 배열입니다. 함수가 제공되면 Vite 플러그인 인스턴스 또는 배열을 반환해야 합니다. 함수는 async이거나 Promise를 반환할 수도 있으며, 플러그인을 지연 로딩할 때 유용합니다:

```ts twoslash
// @errors: 2307
import { addVitePlugin, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    // 실제 빌드가 실행될 때만 플러그인을 import합니다
    addVitePlugin(() => import('my-vite-plugin').then(r => r.default()))
  },
})
```

**`options`**: callback 함수에 전달할 옵션입니다. 이 객체는 다음 속성을 가질 수 있습니다:

| Property  | Type      | Required | Description                                                                                                                                            |
|-----------|-----------|----------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| `dev`     | `boolean` | `false`  | `true`로 설정하면 개발 모드 빌드 시 callback 함수가 호출됩니다.                                                                                        |
| `build`   | `boolean` | `false`  | `true`로 설정하면 프로덕션 모드 빌드 시 callback 함수가 호출됩니다.                                                                                     |
| `server`  | `boolean` | `false`  | `true`로 설정하면 서버 번들 빌드 시 callback 함수가 호출됩니다. **Nuxt 5+에서는 deprecated되었습니다.** 대신 `applyToEnvironment()`를 사용하세요. |
| `client`  | `boolean` | `false`  | `true`로 설정하면 클라이언트 번들 빌드 시 callback 함수가 호출됩니다. **Nuxt 5+에서는 deprecated되었습니다.** 대신 `applyToEnvironment()`를 사용하세요. |
| `prepend` | `boolean` | `false`  | `true`로 설정하면 callback 함수가 `push()` 대신 `unshift()`로 배열 앞에 추가됩니다.                                                                     |

## `addWebpackPlugin` %{#addwebpackplugin}%

설정에 webpack 플러그인을 추가합니다.

### 사용법 %{#usage}%

```ts
import EslintWebpackPlugin from 'eslint-webpack-plugin'
import { addWebpackPlugin, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  meta: {
    name: 'nuxt-eslint',
    configKey: 'eslint',
  },
  defaults: nuxt => ({
    include: [`${nuxt.options.srcDir}/**/*.{js,jsx,ts,tsx,vue}`],
    lintOnStart: true,
  }),
  setup (options, nuxt) {
    const webpackOptions = {
      ...options,
      context: nuxt.options.srcDir,
      files: options.include,
      lintDirtyModulesOnly: !options.lintOnStart,
    }
    addWebpackPlugin(new EslintWebpackPlugin(webpackOptions), { server: false })
  },
})
```

### 타입 %{#type}%

```ts twoslash

// ---cut---
```

## `addBuildPlugin` %{#addbuildplugin}%

`addVitePlugin`과 `addWebpackPlugin`의 builder-agnostic 버전입니다. Vite와 webpack 설정이 모두 존재한다면 양쪽에 모두 플러그인을 추가합니다.

### 타입 %{#type}%

```ts twoslash
// @errors: 2391
import type { ExtendConfigOptions } from '@nuxt/kit'
import type { Plugin as VitePlugin } from 'vite'
import type { WebpackPluginInstance } from 'webpack'
import type { RspackPluginInstance } from '@rspack/core'

interface AddBuildPluginFactory {
  vite?: () => VitePlugin | VitePlugin[]
  webpack?: () => WebpackPluginInstance | WebpackPluginInstance[]
  rspack?: () => RspackPluginInstance | RspackPluginInstance[]
}
// ---cut---
function addBuildPlugin (pluginFactory: AddBuildPluginFactory, options?: ExtendConfigOptions): void
```

### 매개변수 %{#parameters}%

**`pluginFactory`**: `vite` 및/또는 `webpack` 속성을 가진 객체를 반환하는 팩토리 함수입니다. 이 속성들은 Vite 플러그인 인스턴스 또는 배열과/또는 webpack 플러그인 인스턴스 또는 배열을 반환하는 함수여야 합니다.

**`options`**: callback 함수에 전달할 옵션입니다. 이 객체는 다음 속성을 가질 수 있습니다:

| Property  | Type      | Required | Description                                                                                                  |
|-----------|-----------|----------|--------------------------------------------------------------------------------------------------------------|
| `dev`     | `boolean` | `false`  | `true`로 설정하면 개발 모드 빌드 시 callback 함수가 호출됩니다.                                              |
| `build`   | `boolean` | `false`  | `true`로 설정하면 프로덕션 모드 빌드 시 callback 함수가 호출됩니다.                                           |
| `server`  | `boolean` | `false`  | `true`로 설정하면 서버 번들 빌드 시 callback 함수가 호출됩니다.                                               |
| `client`  | `boolean` | `false`  | `true`로 설정하면 클라이언트 번들 빌드 시 callback 함수가 호출됩니다.                                         |
| `prepend` | `boolean` | `false`  | `true`로 설정하면 callback 함수가 `push()` 대신 `unshift()`로 배열 앞에 추가됩니다.                          |
