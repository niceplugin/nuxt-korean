Nuxt 레이어는 프로젝트 전반에서 기능을 공유하고 확장할 수 있는 강력한 방법을 제공합니다. 모듈에서 레이어를 다룰 때는 각 레이어의 디렉터리 경로에 접근해야 하는 경우가 많습니다. Nuxt Kit은 Nuxt 애플리케이션의 모든 레이어에 대해 해석된 디렉터리 경로에 접근할 수 있도록 `getLayerDirectories` 유틸리티를 제공합니다.

## `getLayerDirectories` %{#getlayerdirectories}%

Nuxt 애플리케이션의 모든 레이어에 대한 해석된 디렉터리 경로를 가져옵니다. 이 함수는 비공개 `nuxt.options._layers` 속성에 직접 접근하지 않고도 레이어 디렉터리에 접근할 수 있는 구조화된 방법을 제공합니다.

### 사용법 %{#usage}%

```ts twoslash
import { defineNuxtModule, getLayerDirectories } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    const layerDirs = getLayerDirectories()

    // 모든 레이어의 디렉터리에 접근합니다
    for (const [index, layer] of layerDirs.entries()) {
      console.log(`레이어 ${index}:`)
      console.log(`  루트: ${layer.root}`)
      console.log(`  앱: ${layer.app}`)
      console.log(`  서버: ${layer.server}`)
      console.log(`  페이지: ${layer.appPages}`)
      // ... 기타 디렉터리
    }
  },
})
```

### 타입 %{#type}%

```ts twoslash
// @errors: 2391
import type { Nuxt } from '@nuxt/schema'
// ---cut---
function getLayerDirectories (nuxt?: Nuxt): LayerDirectories[]

interface LayerDirectories {
  /** Nuxt rootDir (기본값은 `/`) */
  readonly root: string
  /** Nitro 소스 디렉터리 (기본값은 `/server`) */
  readonly server: string
  /** 로컬 모듈 디렉터리 (기본값은 `/modules`) */
  readonly modules: string
  /** 공유 디렉터리 (기본값은 `/shared`) */
  readonly shared: string
  /** public 디렉터리 (기본값은 `/public`) */
  readonly public: string
  /** Nuxt srcDir (기본값은 `/app/`) */
  readonly app: string
  /** 레이아웃 디렉터리 (기본값은 `/app/layouts`) */
  readonly appLayouts: string
  /** 미들웨어 디렉터리 (기본값은 `/app/middleware`) */
  readonly appMiddleware: string
  /** 페이지 디렉터리 (기본값은 `/app/pages`) */
  readonly appPages: string
  /** 플러그인 디렉터리 (기본값은 `/app/plugins`) */
  readonly appPlugins: string
}
```

### 매개변수 %{#parameters}%

**`nuxt`** (선택 사항): 레이어를 가져올 Nuxt 인스턴스입니다. 제공하지 않으면 함수는 현재 Nuxt 컨텍스트를 사용합니다.

### 반환 값 %{#return-value}%

`getLayerDirectories` 함수는 애플리케이션의 각 레이어마다 하나씩, `LayerDirectories` 객체 배열을 반환합니다.

**레이어 우선순위 순서**: 레이어는 우선순위에 따라 정렬되며, 다음과 같습니다:
- **첫 번째 레이어**는 사용자/프로젝트 레이어입니다 (가장 높은 우선순위)
- 배열에서 **앞에 있는 레이어가 뒤에 있는 레이어를 덮어씁니다**
- **기반 레이어는** 배열의 마지막에 나타납니다 (가장 낮은 우선순위)

이 순서는 사용자 정의 설정과 파일이 기반 레이어의 것보다 우선하는 Nuxt의 레이어 해석 시스템과 일치합니다.

**`LayerDirectories`**: 레이어의 해석된 디렉터리 경로를 담고 있는 객체입니다.

| Property        | Type     | Description                                                  |
|-----------------|----------|--------------------------------------------------------------|
| `root`          | `string` | 레이어의 루트 디렉터리 (`rootDir`와 동일)                    |
| `server`        | `string` | Nitro 서버 측 코드용 서버 디렉터리                           |
| `modules`       | `string` | 로컬 모듈 디렉터리                                           |
| `shared`        | `string` | 클라이언트와 서버 모두에서 사용하는 코드용 공유 디렉터리     |
| `app`           | `string` | 레이어의 소스 디렉터리 (`srcDir`와 동일)                     |
| `public`        | `string` | 정적 자산용 public 디렉터리                                  |
| `appLayouts`    | `string` | Vue 레이아웃 컴포넌트용 layouts 디렉터리                     |
| `appMiddleware` | `string` | 라우트 미들웨어용 middleware 디렉터리                        |
| `appPages`      | `string` | 파일 기반 라우팅용 pages 디렉터리                            |
| `appPlugins`    | `string` | Nuxt 플러그인용 plugins 디렉터리                             |

### 예제 %{#examples}%

**모든 레이어의 파일 처리하기:**

```ts twoslash
// @errors: 2307
// ---cut---
import { defineNuxtModule, getLayerDirectories } from '@nuxt/kit'
import { resolve } from 'pathe'
import { globby } from 'globby'

export default defineNuxtModule({
  async setup () {
    const layerDirs = getLayerDirectories()

    // 레이어 전반의 모든 컴포넌트 파일을 찾습니다
    // 참고: layerDirs[0]은 사용자 레이어입니다 (가장 높은 우선순위)
    // 배열에서 뒤에 오는 레이어는 더 낮은 우선순위를 가집니다
    const componentFiles = []
    for (const [index, layer] of layerDirs.entries()) {
      const files = await globby('**/*.vue', {
        cwd: resolve(layer.app, 'components'),
        absolute: true,
      })
      console.log(`레이어 ${index} (${index === 0 ? 'user' : 'base'}):`, files.length, '컴포넌트')
      componentFiles.push(...files)
    }
  },
})
```

**여러 레이어에서 템플릿 추가하기:**

```ts twoslash
import { addTemplate, defineNuxtModule, getLayerDirectories } from '@nuxt/kit'
import { basename, resolve } from 'pathe'
import { existsSync } from 'node:fs'

export default defineNuxtModule({
  setup () {
    const layerDirs = getLayerDirectories()

    // 각 레이어에 존재하는 설정 파일을 추가합니다
    for (const dirs of layerDirs) {
      const configPath = resolve(dirs.app, 'my-module.config.ts')
      if (existsSync(configPath)) {
        addTemplate({
          filename: `my-module-${basename(dirs.root)}.config.ts`,
          src: configPath,
        })
      }
    }
  },
})
```

**레이어 우선순위 존중하기:**

```ts twoslash
import { defineNuxtModule, getLayerDirectories } from '@nuxt/kit'
import { resolve } from 'pathe'
import { existsSync, readFileSync } from 'node:fs'

export default defineNuxtModule({
  setup () {
    const layerDirs = getLayerDirectories()

    // 특정 설정 파일을 가진 첫 번째(가장 높은 우선순위) 레이어를 찾습니다
    // 이는 레이어 우선순위 시스템을 따릅니다
    let configContent = null
    for (const dirs of layerDirs) {
      const configPath = resolve(dirs.app, 'my-config.json')
      if (existsSync(configPath)) {
        configContent = readFileSync(configPath, 'utf-8')
        console.log(`레이어의 설정을 사용합니다: ${dirs.root}`)
        break // 찾은 첫 번째(가장 높은 우선순위) 설정을 사용합니다
      }
    }

    // 대안: 사용자 레이어가 우선하도록 모든 레이어의 설정을 수집합니다
    const allConfigs = {}
    for (const dirs of layerDirs.reverse()) { // 가장 낮은 우선순위부터 가장 높은 우선순위까지 처리합니다
      const configPath = resolve(dirs.app, 'my-config.json')
      if (existsSync(configPath)) {
        const config = JSON.parse(readFileSync(configPath, 'utf-8'))
        Object.assign(allConfigs, config) // 나중 할당이 이전 할당을 덮어씁니다
      }
    }
  },
})
```

**레이어별 전용 디렉터리 확인하기:**

```ts twoslash
import { defineNuxtModule, getLayerDirectories } from '@nuxt/kit'
import { existsSync } from 'node:fs'
import { resolve } from 'pathe'

export default defineNuxtModule({
  setup () {
    const layerDirs = getLayerDirectories()

    // 특정 사용자 정의 디렉터리를 가진 레이어를 찾습니다
    const layersWithAssets = layerDirs.filter((layer) => {
      return existsSync(resolve(layer.app, 'assets'))
    })

    console.log(`assets 디렉터리가 있는 레이어를 ${layersWithAssets.length}개 찾았습니다`)
  },
})
```

::note
`getLayerDirectories` 함수는 동일한 레이어에 대해 디렉터리 경로를 반복 계산하지 않도록 WeakMap을 통한 캐싱을 포함하므로, 여러 번 호출될 때 성능이 향상됩니다.
::

::note
이 함수가 반환하는 디렉터리 경로에는 일관성을 위해 항상 후행 슬래시가 포함됩니다.
::
