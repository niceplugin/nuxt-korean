Nuxt는 helper 함수, 컴포저블, Vue API를 명시적으로 import하지 않아도 애플리케이션 전반에서 사용할 수 있도록 auto-import합니다. 디렉터리 구조를 기반으로 모든 Nuxt 애플리케이션은 자체 컴포저블과 플러그인에 대해서도 auto-import를 사용할 수 있습니다.

Nuxt Kit를 사용하면 자체 auto-import도 추가할 수 있습니다. `addImports`와 `addImportsDir`는 Nuxt 애플리케이션에 import를 추가할 수 있게 해 줍니다. `addImportsSources`는 서드파티 패키지의 지정된 import를 Nuxt 애플리케이션에 추가할 수 있게 해 줍니다.

이 유틸리티는 Nuxt에서 사용하는 기반 auto-import 메커니즘을 제공하는 [`unimport`](https://github.com/unjs/unimport)를 통해 동작합니다.

::note
이 함수들은 자체 유틸, 컴포저블, Vue API를 등록하기 위해 설계되었습니다. 페이지, 컴포넌트, 플러그인에 대해서는 각각의 섹션을 참고하세요: [Pages](/docs/4.x/api/kit/pages), [Components](/docs/4.x/api/kit/components), [Plugins](/docs/4.x/api/kit/plugins).
::

## `addImports` %{#addimports}%

Nuxt 애플리케이션에 import를 추가합니다. 수동으로 import할 필요 없이 Nuxt 앱 컨텍스트에서 해당 import를 사용할 수 있게 합니다.

::tip
Nitro 서버 컨텍스트용 import를 추가하려면 [`addServerImports`](/docs/4.x/api/kit/nitro#addserverimports) 함수를 참고하세요.
::

### Usage %{#usage}%

```ts twoslash
import { addImports, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const names = [
      'useStoryblok',
      'useStoryblokApi',
      'useStoryblokBridge',
      'renderRichText',
      'RichTextSchema',
    ]

    names.forEach(name =>
      addImports({ name, as: name, from: '@storyblok/vue' }),
    )
  },
})
```

### Type %{#type}%

```ts
function addImports (imports: Import | Import[]): void
```

### Parameters %{#parameters}%

`imports`: 다음 속성을 가진 객체 또는 객체 배열입니다:

| 속성       | 타입                  | 필수 여부 | 설명                                                                                                            |
|------------|-----------------------|----------|-----------------------------------------------------------------------------------------------------------------|
| `name`     | `string`              | `true`   | 감지할 import 이름입니다.                                                                                       |
| `from`     | `string`              | `true`   | import할 모듈 지정자입니다.                                                                                     |
| `priority` | `number`              | `false`  | import 우선순위입니다. 동일한 이름의 import가 여러 개면 가장 높은 우선순위의 항목이 사용됩니다.                |
| `disabled` | `boolean`             | `false`  | 이 import를 비활성화할지 여부입니다.                                                                            |
| `meta`     | `Record<string, any>` | `false`  | import의 메타데이터입니다.                                                                                      |
| `type`     | `boolean`             | `false`  | 이 import가 순수 타입 import인지 여부입니다.                                                                    |
| `typeFrom` | `string`              | `false`  | 타입 선언 생성 시 `from` 값으로 이것을 사용합니다.                                                              |
| `as`       | `string`              | `false`  | 이 이름으로 import합니다.                                                                                       |

## `addImportsDir` %{#addimportsdir}%

디렉터리에서 Nuxt 애플리케이션으로 import를 추가합니다. 디렉터리의 모든 파일을 자동으로 import하고, 수동 import 없이 Nuxt 애플리케이션에서 사용할 수 있게 합니다.

### Usage %{#usage}%

```ts twoslash
import { addImportsDir, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  meta: {
    name: '@vueuse/motion',
    configKey: 'motion',
  },
  setup (options, nuxt) {
    const resolver = createResolver(import.meta.url)
    addImportsDir(resolver.resolve('./runtime/composables'))
  },
})
```

### Type %{#type}%

```ts
function addImportsDir (dirs: string | string[], options?: { prepend?: boolean }): void
```

### Parameters %{#parameters}%

| 속성      | 타입                               | 필수 여부 | 설명                                                                                                                |
|-----------|------------------------------------|----------|---------------------------------------------------------------------------------------------------------------------|
| `dirs`    | `string \| string[]`{lang="ts"}    | `true`   | import할 디렉터리 경로를 담은 문자열 또는 문자열 배열입니다.                                                       |
| `options` | `{ prepend?: boolean }`{lang="ts"} | `false`  | import에 전달할 옵션입니다. `prepend`가 `true`이면 import가 import 목록 앞쪽에 추가됩니다.                        |

## `addImportsSources` %{#addimportssources}%

지정된 import를 Nuxt 애플리케이션에 추가합니다.

### Usage %{#usage}%

```ts twoslash
import { addImportsSources, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    addImportsSources([
      { package: '@vueuse/core' },
      {
        from: 'h3',
        imports: [
          'defineEventHandler',
          'getQuery',
          'getRouterParams',
          'readBody',
          'sendRedirect',
        ],
      },
    ])
  },
})
```

### Type %{#type}%

```ts
function addImportsSources (importSources: Preset | Preset[]): void
```

### Parameters %{#parameters}%

**importSources**: 다음 속성을 가진 객체 또는 객체 배열입니다:

- InlinePreset

| 속성      | 타입                                        | 필수 여부 | 설명                                                                                           |
|-----------|---------------------------------------------|----------|------------------------------------------------------------------------------------------------|
| `from`    | `string`                                    | `true`   | import할 모듈 지정자입니다.                                                                    |
| `imports` | `PresetImport \| ImportSource[]`{lang="ts"} | `true`   | import 이름, import 객체, import source가 될 수 있는 객체 또는 객체 배열입니다.               |

- PackagePreset

| 속성      | 타입                                        | 필수 여부 | 설명                                                                                           |
|-----------|---------------------------------------------|----------|------------------------------------------------------------------------------------------------|
| `package` | `string`                                    | `true`   | 패키지 이름입니다.                                                                             |
