## `extendPages` %{#extendpages}%

Nuxt에서는 `app/pages` 디렉터리 안 파일 구조를 기반으로 라우트가 자동 생성됩니다. 하지만 이런 라우트를 사용자 지정하고 싶은 상황이 있을 수 있습니다. 예를 들어 Nuxt가 생성하지 않은 동적 페이지용 라우트를 추가하거나, 기존 라우트를 제거하거나, 라우트 구성을 수정해야 할 수 있습니다. 이런 사용자 지정을 위해 Nuxt는 페이지 구성을 확장하고 변경할 수 있는 `extendPages` 기능을 제공합니다.

::tip{icon="i-lucide-video" to="https://vueschool.io/lessons/extend-and-alter-nuxt-pages?friend=nuxt" target="_blank"}
extendPages에 관한 Vue School 영상을 시청하세요.
::

### Usage %{#usage}%

```ts twoslash
import { createResolver, defineNuxtModule, extendPages } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options) {
    const { resolve } = createResolver(import.meta.url)

    extendPages((pages) => {
      pages.unshift({
        name: 'prismic-preview',
        path: '/preview',
        file: resolve('runtime/preview.vue'),
      })
    })
  },
})
```

### Type %{#type}%

```ts
function extendPages (callback: (pages: NuxtPage[]) => void): void
```

### Parameters %{#parameters}%

**callback**: pages 구성과 함께 호출될 함수입니다. 요소를 추가, 삭제, 수정해 이 배열을 변경할 수 있습니다. 참고: 복사한 배열에 가한 변경은 구성에 반영되지 않으므로 제공된 pages 배열을 직접 수정해야 합니다.

| 속성       | 타입                               | 필수 여부 | 설명                                                                                         |
| ---------- | ---------------------------------- | -------- | -------------------------------------------------------------------------------------------- |
| `name`     | `string`                           | `false`  | 라우트 이름입니다. 프로그래밍 방식 탐색과 라우트 식별에 유용합니다.                          |
| `path`     | `string`                           | `false`  | 라우트 URL 경로입니다. 설정하지 않으면 Nuxt가 파일 위치에서 추론합니다.                      |
| `file`     | `string`                           | `false`  | 라우트의 컴포넌트로 사용할 Vue 파일 경로입니다.                                              |
| `meta`     | `Record<string, any>`{lang="ts"}   | `false`  | 라우트의 사용자 지정 메타데이터입니다. 레이아웃, 미들웨어, navigation guard에서 사용할 수 있습니다. |
| `alias`    | `string[] \| string`{lang="ts"}    | `false`  | 라우트용 별칭 경로 하나 이상입니다. 여러 URL을 지원할 때 유용합니다.                         |
| `redirect` | `RouteLocationRaw`{lang="ts"}      | `false`  | 라우트의 리디렉션 규칙입니다. 이름 있는 라우트, 객체 또는 문자열 경로를 지원합니다.         |
| `children` | `NuxtPage[]`{lang="ts"}            | `false`  | 레이아웃 또는 뷰 중첩을 위한 이 라우트 아래의 중첩 자식 라우트입니다.                        |

## `extendRouteRules` %{#extendrouterules}%

Nuxt는 [Nitro](https://nitro.build/) 서버 엔진으로 동작합니다. Nitro를 사용하면 리디렉션, 프록시, 캐싱, 라우트에 헤더 추가 같은 작업에 유용한 고수준 로직을 구성에 직접 통합할 수 있습니다. 이 구성은 라우트 패턴을 특정 라우트 설정과 연결하는 방식으로 동작합니다.

::tip
[Nitro documentation](https://nitro.build/guide/routing#route-rules)에서 Nitro 라우트 규칙에 대해 더 읽어볼 수 있습니다.
::

::tip{icon="i-lucide-video" to="https://vueschool.io/lessons/adding-route-rules-and-route-middlewares?friend=nuxt" target="_blank"}
라우트 규칙과 라우트 미들웨어 추가에 관한 Vue School 영상을 시청하세요.
::

### Usage %{#usage}%

```ts twoslash
import { createResolver, defineNuxtModule, extendPages, extendRouteRules } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options) {
    const { resolve } = createResolver(import.meta.url)

    extendPages((pages) => {
      pages.unshift({
        name: 'preview-new',
        path: '/preview-new',
        file: resolve('runtime/preview.vue'),
      })
    })

    extendRouteRules('/preview', {
      redirect: {
        to: '/preview-new',
        status: 302,
      },
    })

    extendRouteRules('/preview-new', {
      cache: {
        maxAge: 60 * 60 * 24 * 7,
      },
    })
  },
})
```

### Type %{#type}%

```ts
function extendRouteRules (route: string, rule: NitroRouteConfig, options?: ExtendRouteRulesOptions): void
```

### Parameters %{#parameters}%

**route**: 일치시킬 라우트 패턴입니다.\
**rule**: 일치한 라우트에 적용할 라우트 규칙 구성입니다.

::tip
라우트 규칙 구성에 대해서는 [Hybrid Rendering > Route Rules](/docs/4.x/guide/concepts/rendering#route-rules)에서 더 자세히 확인할 수 있습니다.
::

**options**: 라우트 구성에 전달할 객체입니다. `override`를 `true`로 설정하면 기존 라우트 구성을 덮어씁니다.

| 이름       | 타입      | 기본값  | 설명                                         |
| ---------- | --------- | ------- | -------------------------------------------- |
| `override` | `boolean` | `false` | 라우트 규칙 구성을 덮어씁니다. 기본값은 false입니다 |

## `addRouteMiddleware` %{#addroutemiddleware}%

모든 라우트 또는 특정 라우트에서 사용할 수 있도록 라우트 미들웨어를 등록합니다.

라우트 미들웨어는 플러그인 안에서 [`addRouteMiddleware`](/docs/4.x/api/utils/add-route-middleware) 컴포저블을 통해서도 정의할 수 있습니다.

::tip
[Route middleware documentation](/docs/4.x/getting-started/routing#route-middleware)에서 라우트 미들웨어에 대해 더 읽어보세요.
::

::tip{icon="i-lucide-video" to="https://vueschool.io/lessons/adding-route-rules-and-route-middlewares?friend=nuxt" target="_blank"}
라우트 규칙과 라우트 미들웨어 추가에 관한 Vue School 영상을 시청하세요.
::

### Usage %{#usage}%

::code-group

```ts twoslash [module.ts]
import { addRouteMiddleware, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    const { resolve } = createResolver(import.meta.url)

    addRouteMiddleware({
      name: 'auth',
      path: resolve('runtime/auth'),
      global: true,
    }, { prepend: true })
  },
})
```

```ts twoslash [runtime/auth.ts]
function isAuthenticated (): boolean { return false }
// ---cut---
export default defineNuxtRouteMiddleware((to, from) => {
  // isAuthenticated()는 사용자가 인증되었는지 확인하는 예시 메서드입니다
  if (to.path !== '/login' && isAuthenticated() === false) {
    return navigateTo('/login')
  }
})
```

::

### Type %{#type}%

```ts
function addRouteMiddleware (input: NuxtMiddleware | NuxtMiddleware[], options?: AddRouteMiddlewareOptions): void
```

### Parameters %{#parameters}%

**input**: 다음 속성을 가진 미들웨어 객체 또는 미들웨어 객체 배열입니다:

| 속성     | 타입      | 필수 여부 | 설명                                                |
| -------- | --------- | -------- | --------------------------------------------------- |
| `name`   | `string`  | `true`   | 미들웨어 이름입니다.                                |
| `path`   | `string`  | `true`   | 미들웨어 파일 경로입니다.                           |
| `global` | `boolean` | `false`  | `true`로 설정하면 모든 라우트에 미들웨어를 적용합니다. |

**options**: 다음 속성을 가진 객체입니다:

| 속성       | 타입      | 기본값  | 설명                                                        |
| ---------- | --------- | ------- | ----------------------------------------------------------- |
| `override` | `boolean` | `false` | `true`이면 같은 이름의 미들웨어를 대체합니다.               |
| `prepend`  | `boolean` | `false` | `true`이면 기존 미들웨어보다 앞에 미들웨어를 추가합니다.    |
