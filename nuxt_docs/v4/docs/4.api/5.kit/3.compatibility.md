Nuxt Kit 유틸리티는 Nuxt 3, Bridge가 있는 Nuxt 2, 심지어 Bridge가 없는 Nuxt 2에서도 사용할 수 있습니다. 모듈이 모든 버전과 호환되는지 확인하려면 `checkNuxtCompatibility`, `assertNuxtCompatibility`, `hasNuxtCompatibility` 함수를 사용할 수 있습니다. 이 함수들은 현재 Nuxt 버전이 제공한 제약 조건을 만족하는지 확인합니다. 더 세밀한 검사에는 `isNuxt2`, `isNuxt3`, `getNuxtVersion` 함수도 사용할 수 있습니다.

## `checkNuxtCompatibility` %{#checknuxtcompatibility}%

현재 Nuxt 버전이 제약 조건을 만족하는지 확인합니다. 만족하지 않으면 메시지 배열을 반환합니다. Nuxt 2 버전에서는 `bridge` 지원도 함께 검사합니다.

### Usage %{#usage}%

```ts twoslash
import { checkNuxtCompatibility, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  async setup (_options, nuxt) {
    const issues = await checkNuxtCompatibility({ nuxt: '^2.16.0' }, nuxt)
    if (issues.length) {
      console.warn('Nuxt 호환성 문제를 찾았습니다:\n' + issues.toString())
    } else {
      // 무언가 수행
    }
  },
})
```

### Type %{#type}%

```ts
function checkNuxtCompatibility (constraints: NuxtCompatibility, nuxt?: Nuxt): Promise<NuxtCompatibilityIssues>
```

### Parameters %{#parameters}%

**`constraints`**: 검사할 버전 및 빌더 제약 조건입니다. 다음 속성을 받습니다:

| 속성     | 타입                                          | 필수 여부 | 설명                                                                                                                                             |
| -------- | --------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `nuxt`   | `string`                                      | `false`   | semver 형식의 Nuxt 버전입니다. 버전은 Node.js 방식으로 정의할 수 있습니다. 예: `>=2.15.0 <3.0.0`.                                              |
| `bridge` | `Record<string, string \| false>`{lang="ts"}  | `false`   | `vite`, `webpack`, `rspack` 같은 특정 Nuxt 빌더에 대한 버전 제약을 지정하거나 호환성을 비활성화합니다. 비활성화하려면 `false`를 사용하세요.    |

**`nuxt`**: Nuxt 인스턴스입니다. 제공하지 않으면 `useNuxt()` 호출을 통해 컨텍스트에서 가져옵니다.

## `assertNuxtCompatibility` %{#assertnuxtcompatibility}%

현재 Nuxt 버전이 제약 조건을 만족한다고 단언합니다. 만족하지 않으면 문제 목록을 문자열로 담은 오류를 발생시킵니다.

### Type %{#type}%

```ts twoslash
// @errors: 2391
import type { Nuxt, NuxtCompatibility } from '@nuxt/schema'
// ---cut---
function assertNuxtCompatibility (constraints: NuxtCompatibility, nuxt?: Nuxt): Promise<true>
```

### Parameters %{#parameters}%

**`constraints`**: 검사할 버전 및 빌더 제약 조건입니다. 자세한 내용은 [`checkNuxtCompatibility`의 제약 조건 표](/docs/4.x/api/kit/compatibility#parameters)를 참고하세요.

**`nuxt`**: Nuxt 인스턴스입니다. 제공하지 않으면 `useNuxt()` 호출을 통해 컨텍스트에서 가져옵니다.

## `hasNuxtCompatibility` %{#hasnuxtcompatibility}%

현재 Nuxt 버전이 제약 조건을 만족하는지 확인합니다. 모든 제약 조건을 만족하면 `true`, 아니면 `false`를 반환합니다. Nuxt 2 버전에서는 `bridge` 지원도 함께 검사합니다.

### Usage %{#usage}%

```ts twoslash
import { defineNuxtModule, hasNuxtCompatibility } from '@nuxt/kit'

export default defineNuxtModule({
  async setup (_options, nuxt) {
    const usingNewPostcss = await hasNuxtCompatibility({ nuxt: '^2.16.0' }, nuxt)
    if (usingNewPostcss) {
      // 무언가 수행
    } else {
      // 다른 작업 수행
    }
  },
})
```

### Type %{#type}%

```ts
function hasNuxtCompatibility (constraints: NuxtCompatibility, nuxt?: Nuxt): Promise<boolean>
```

### Parameters %{#parameters}%

**`constraints`**: 검사할 버전 및 빌더 제약 조건입니다. 자세한 내용은 [`checkNuxtCompatibility`의 제약 조건 표](/docs/4.x/api/kit/compatibility#parameters)를 참고하세요.

**`nuxt`**: Nuxt 인스턴스입니다. 제공하지 않으면 `useNuxt()` 호출을 통해 컨텍스트에서 가져옵니다.

## `isNuxtMajorVersion` %{#isnuxtmajorversion}%

현재 Nuxt 인스턴스가 지정된 메이저 버전인지 확인합니다

### Usage %{#usage}%

```ts twoslash
import { defineNuxtModule, isNuxtMajorVersion } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    if (isNuxtMajorVersion(3)) {
      // Nuxt 3용 작업 수행
    } else {
      // 다른 버전용 작업 수행
    }
  },
})
```

### Type %{#type}%

```ts
function isNuxtMajorVersion (major: number, nuxt?: Nuxt): boolean
```

### Parameters %{#parameters}%

**`major`**: 검사할 메이저 버전입니다.

**`nuxt`**: Nuxt 인스턴스입니다. 제공하지 않으면 `useNuxt()` 호출을 통해 컨텍스트에서 가져옵니다.

## `isNuxt3` %{#isnuxt3}%

현재 Nuxt 버전이 3.x인지 확인합니다.

::note
대신 `isNuxtMajorVersion(2, nuxt)`를 사용하세요. 이는 \@nuxt/kit v5 또는 향후 메이저 버전에서 제거될 수 있습니다.
::

### Type %{#type}%

```ts
function isNuxt3 (nuxt?: Nuxt): boolean
```

### Parameters %{#parameters}%

**`nuxt`**: Nuxt 인스턴스입니다. 제공하지 않으면 `useNuxt()` 호출을 통해 컨텍스트에서 가져옵니다.
