때로는 현재 모듈 기준의 경로를, 이름이나 확장자를 모르는 상태에서 해석해야 할 수 있습니다. 예를 들어 모듈과 같은 디렉터리에 있는 플러그인을 추가하고 싶을 수 있습니다. 이런 경우를 처리하기 위해 Nuxt는 경로 해석용 유틸리티 집합을 제공합니다. `resolvePath`와 `resolveAlias`는 현재 모듈 기준으로 경로를 해석하는 데 사용됩니다. `findPath`는 주어진 경로들 중 처음으로 존재하는 파일을 찾는 데 사용됩니다. `createResolver`는 기준 경로에 상대적인 resolver를 생성하는 데 사용됩니다.

## `resolvePath` %{#resolvepath}%

Nuxt 별칭과 확장자 옵션을 고려해 파일 또는 디렉터리의 전체 경로를 해석합니다. 경로를 해석할 수 없으면 정규화된 입력 경로가 반환됩니다.

### Usage %{#usage}%

```ts
import { defineNuxtModule, resolvePath } from '@nuxt/kit'

export default defineNuxtModule({
  async setup () {
    const entrypoint = await resolvePath('@unhead/vue')
    console.log(`Unhead entrypoint is ${entrypoint}`)
  },
})
```

### Type %{#type}%

```ts
function resolvePath (path: string, options?: ResolvePathOptions): Promise<string>
```

### Parameters %{#parameters}%

**`path`**: 해석할 경로입니다.

**`options`**: resolver에 전달할 옵션입니다. 이 객체는 다음 속성을 가질 수 있습니다:

| 속성                 | 타입                                | 필수 여부 | 설명                                                                                                                         |
| -------------------- | ----------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `cwd`                | `string`                            | `false`  | 경로 해석의 기준입니다. 기본값은 Nuxt rootDir입니다.                                                                         |
| `alias`              | `Record<string, string>`{lang="ts"} | `false`  | 별칭 객체입니다. 기본값은 Nuxt에 설정된 별칭입니다.                                                                          |
| `extensions`         | `string[]`                          | `false`  | 시도할 파일 확장자입니다. 기본값은 Nuxt에 설정된 확장자입니다.                                                               |
| `virtual`            | `boolean`                           | `false`  | Nuxt VFS에 존재하는 파일(예: Nuxt 템플릿)을 해석할지 여부입니다.                                                             |
| `fallbackToOriginal` | `boolean`                           | `false`  | 해석된 경로가 존재하지 않을 때 정규화된 입력 경로를 반환하는 대신 원래 경로로 되돌아갈지 여부입니다.                      |

### Examples %{#examples}%

```ts
import { defineNuxtModule, resolvePath } from '@nuxt/kit'
import { join } from 'pathe'

const headlessComponents: ComponentGroup[] = [
  {
    relativePath: 'combobox/combobox.js',
    chunkName: 'headlessui/combobox',
    exports: [
      'Combobox',
      'ComboboxLabel',
      'ComboboxButton',
      'ComboboxInput',
      'ComboboxOptions',
      'ComboboxOption',
    ],
  },
]

export default defineNuxtModule({
  meta: {
    name: 'nuxt-headlessui',
    configKey: 'headlessui',
  },
  defaults: {
    prefix: 'Headless',
  },
  async setup (options) {
    const entrypoint = await resolvePath('@headlessui/vue')
    const root = join(entrypoint, '../components')

    for (const group of headlessComponents) {
      for (const e of group.exports) {
        addComponent(
          {
            name: e,
            export: e,
            filePath: join(root, group.relativePath),
            chunkName: group.chunkName,
            mode: 'all',
          },
        )
      }
    }
  },
})
```

## `resolveAlias` %{#resolvealias}%

Nuxt 별칭 옵션을 고려해 경로 별칭을 해석합니다.

### Type %{#type}%
  
```ts
function resolveAlias (path: string, alias?: Record<string, string>): string
```

### Parameters %{#parameters}%

**`path`**: 해석할 경로입니다.

**`alias`**: 별칭 객체입니다. 제공하지 않으면 `nuxt.options.alias`에서 읽습니다.

## `findPath` %{#findpath}%

주어진 경로들 중 처음으로 존재하는 파일을 해석하려고 시도합니다.

### Usage %{#usage}%

```ts
import { defineNuxtModule, findPath } from '@nuxt/kit'
import { join } from 'pathe'

export default defineNuxtModule({
  async setup (_, nuxt) {
    // 메인(app.vue) 해석
    const mainComponent = await findPath([
      join(nuxt.options.srcDir, 'App'),
      join(nuxt.options.srcDir, 'app'),
    ])
  },
})
```

### Type %{#type}%

```ts
function findPath (paths: string | string[], options?: ResolvePathOptions, pathType: 'file' | 'dir'): Promise<string | null>
```

### Parameters %{#parameters}%

**`paths`**: 해석할 경로 또는 경로 배열입니다.

**`options`**: resolver에 전달할 옵션입니다. 이 객체는 다음 속성을 가질 수 있습니다:

| 속성                 | 타입                                | 필수 여부 | 설명                                                                                                                         |
| -------------------- | ----------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `cwd`                | `string`                            | `false`  | 경로 해석의 기준입니다. 기본값은 Nuxt rootDir입니다.                                                                         |
| `alias`              | `Record<string, string>`{lang="ts"} | `false`  | 별칭 객체입니다. 기본값은 Nuxt에 설정된 별칭입니다.                                                                          |
| `extensions`         | `string[]`                          | `false`  | 시도할 파일 확장자입니다. 기본값은 Nuxt에 설정된 확장자입니다.                                                               |
| `virtual`            | `boolean`                           | `false`  | Nuxt VFS에 존재하는 파일(예: Nuxt 템플릿)을 해석할지 여부입니다.                                                             |
| `fallbackToOriginal` | `boolean`                           | `false`  | 해석된 경로가 존재하지 않을 때 정규화된 입력 경로를 반환하는 대신 원래 경로로 되돌아갈지 여부입니다.                      |

## `createResolver` %{#createresolver}%

기준 경로에 상대적인 resolver를 생성합니다.

::tip{icon="i-lucide-video" to="https://vueschool.io/lessons/resolving-paths-and-injecting-assets-to-the-app?friend=nuxt" target="_blank"}
createResolver에 관한 Vue School 영상을 시청하세요.
::

### Usage %{#usage}%

```ts
import { createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup (_, nuxt) {
    const { resolve, resolvePath } = createResolver(import.meta.url)
  },
})
```

### Type %{#type}%

```ts
function createResolver (basePath: string | URL): Resolver
```

### Parameters %{#parameters}%

**`basePath`**: 해석 기준이 되는 경로입니다. 문자열 또는 URL일 수 있습니다.

### Return Value %{#return-value}%

`createResolver` 함수는 다음 속성을 가진 객체를 반환합니다:

| 속성          | 타입                                                                         | 설명                                                                                                      |
| ------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `resolve`     | `(path: string) => string`{lang="ts"}                                        | 기준 경로에 상대적인 경로를 해석하는 함수입니다.                                                          |
| `resolvePath` | `(path: string, options?: ResolvePathOptions) => Promise<string>`{lang="ts"} | 기준 경로에 상대적인 경로를 해석하고 Nuxt 별칭 및 확장자 옵션을 고려하는 함수입니다.                    |

### Examples %{#examples}%

```ts
import { createResolver, defineNuxtModule, isNuxt2 } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const resolver = createResolver(import.meta.url)

    nuxt.hook('modules:done', () => {
      if (isNuxt2()) {
        addPlugin(resolver.resolve('./runtime/plugin.vue2'))
      } else {
        addPlugin(resolver.resolve('./runtime/plugin.vue3'))
      }
    })
  },
})
```
