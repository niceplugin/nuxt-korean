레이아웃은 페이지를 감싸는 래퍼로 사용됩니다. 예를 들어 헤더와 푸터 같은 공통 컴포넌트로 페이지를 감쌀 수 있습니다. 레이아웃은 `addLayout` 유틸리티로 등록할 수 있습니다.

## `addLayout` %{#addlayout}%

템플릿을 레이아웃으로 등록하고 layouts에 추가합니다.

::note
Nuxt 2에서는 `error` 레이아웃도 이 유틸리티로 등록할 수 있습니다. Nuxt 3+에서는 `error` 레이아웃이 프로젝트 루트의 `error.vue` 페이지로 [대체되었습니다](/docs/4.x/getting-started/error-handling#error-page).
::

### 사용법 %{#usage}%

```ts twoslash
import { addLayout, createResolver, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    const { resolve } = createResolver(import.meta.url)

    addLayout({
      src: resolve('templates/custom-layout.ts'),
      filename: 'custom-layout.ts',
    }, 'custom')
  },
})
```

### 타입 %{#type}%

```ts
function addLayout (layout: NuxtTemplate | string, name: string): void
```

### 매개변수 %{#parameters}%

**`layout`**: 템플릿 객체이거나 템플릿 경로를 담은 문자열입니다. 문자열이 제공되면 `src`가 해당 문자열 값인 템플릿 객체로 변환됩니다. 템플릿 객체가 제공되면 다음 속성을 가져야 합니다:

| 속성          | 타입                                             | 필수 여부 | 설명                                                                                                                                                                             |
| ------------- | ------------------------------------------------ | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src`         | `string`                                         | `false`  | 템플릿 경로입니다. `src`가 제공되지 않으면 대신 `getContents`가 제공되어야 합니다.                                                                                               |
| `filename`    | `string`                                         | `false`  | 템플릿 파일 이름입니다. `filename`이 제공되지 않으면 `src` 경로를 기준으로 생성됩니다. 이 경우 `src` 옵션이 필요합니다.                                                         |
| `dst`         | `string`                                         | `false`  | 대상 파일 경로입니다. `dst`가 제공되지 않으면 `filename` 경로와 nuxt `buildDir` 옵션을 기준으로 생성됩니다.                                                                     |
| `options`     | `Record<string, any>`{lang="ts"}                 | `false`  | 템플릿에 전달할 옵션입니다.                                                                                                                                                     |
| `getContents` | `(data) => string \| Promise<string>`{lang="ts"} | `false`  | `options` 객체를 인자로 받아 호출될 함수입니다. 문자열 또는 문자열로 resolve되는 promise를 반환해야 합니다. `src`가 제공되면 이 함수는 무시됩니다.                              |
| `write`       | `boolean`                                        | `false`  | `true`로 설정하면 템플릿이 대상 파일에 기록됩니다. 그렇지 않으면 템플릿은 가상 파일 시스템에서만 사용됩니다.                                                                     |

**`name`**: 레이아웃을 등록할 이름입니다(예: `default`, `custom` 등).

### 예제 %{#example}%

이 코드는 페이지를 헤더와 푸터로 감싸는 `custom`이라는 레이아웃을 등록합니다.

```ts twoslash
import { addLayout, defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup () {
    addLayout({
      write: true,
      filename: 'my-layout.vue',
      getContents: () => `<template>
  <div>
    <header>내 헤더</header>
    <slot />
    <footer>내 푸터</footer>
  </div>
</template>`,
    }, 'custom')
  },
})
```

이후 이 레이아웃을 페이지에서 사용할 수 있습니다:

```vue [app/pages/about.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'custom',
})
</script>

<template>
  <div>소개 페이지</div>
</template>
```

::warning
`@vitejs/plugin-vue`가 가상 `.vue` 파일을 지원하지 않기 때문에, `addLayout`의 첫 번째 인자로 `write: true`를 전달해 이 제한을 우회할 수 있습니다.
::
