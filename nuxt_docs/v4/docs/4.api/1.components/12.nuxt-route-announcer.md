::important
이 컴포넌트는 Nuxt v3.12+에서 사용할 수 있습니다.
::

## Usage %{#usage}%

보조 기술에 페이지 제목 변경을 알려 접근성을 높이려면 [`app.vue`](/docs/4.x/directory-structure/app/app) 또는 [`app/layouts/`](/docs/4.x/directory-structure/app/layouts)에 `<NuxtRouteAnnouncer/>`를 추가하세요. 이렇게 하면 스크린 리더에 의존하는 사용자에게 탐색 변경 사항이 전달됩니다.

```vue [app/app.vue]
<template>
  <NuxtRouteAnnouncer />
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

## Slots %{#slots}%

route announcer의 기본 슬롯을 통해 사용자 정의 HTML이나 컴포넌트를 전달할 수 있습니다.

```vue
<template>
  <NuxtRouteAnnouncer>
    <template #default="{ message }">
      <p>{{ message }} 페이지를 불러왔습니다.</p>
    </template>
  </NuxtRouteAnnouncer>
</template>
```

## Props %{#props}%

- `atomic`: 스크린 리더가 변경 사항만 읽을지 전체 콘텐츠를 읽을지 제어합니다. 업데이트 시 전체 내용을 읽게 하려면 true, 변경 사항만 읽게 하려면 false로 설정합니다. (기본값 `false`)
- `politeness`: 스크린 리더 안내의 긴급도를 설정합니다: `off` (안내 비활성화), `polite` (조용해질 때까지 대기), `assertive` (즉시 끼어들기). (기본값 `polite`)

::callout
이 컴포넌트는 선택 사항입니다. :br
완전히 사용자 정의하려면 [소스 코드](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/components/nuxt-route-announcer.ts)를 바탕으로 직접 구현할 수 있습니다.
::

::callout
기본 announcer 인스턴스에는 [`useRouteAnnouncer` 컴포저블](/docs/4.x/api/composables/use-route-announcer)로 연결할 수 있으며, 이를 통해 사용자 정의 안내 메시지를 설정할 수 있습니다.
::

::callout
페이지 내부 콘텐츠 변경 사항(폼 검증, 토스트 알림, 로딩 상태 등)을 알리려면 [`useAnnouncer`](/docs/4.x/api/composables/use-announcer) 컴포저블과 함께 [`<NuxtAnnouncer>`](/docs/4.x/api/components/nuxt-announcer) 컴포넌트를 대신 사용하세요.
::
