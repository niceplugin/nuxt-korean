::important
이 컴포넌트는 Nuxt v3.17+에서 사용할 수 있습니다.
::

## Usage %{#usage}%

스크린 리더에 동적 콘텐츠 변경을 알리려면 [`app.vue`](/docs/4.x/directory-structure/app/app) 또는 [`app/layouts/`](/docs/4.x/directory-structure/app/layouts)에 `<NuxtAnnouncer/>`를 추가하세요. 이는 폼 검증, 토스트 알림, 로딩 상태 및 기타 페이지 내 업데이트에 유용합니다.

```vue [app/app.vue]
<template>
  <NuxtAnnouncer />
  <NuxtRouteAnnouncer />
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

그런 다음 앱 어디에서든 [`useAnnouncer`](/docs/4.x/api/composables/use-announcer) 컴포저블을 사용해 메시지를 알릴 수 있습니다:

```vue [app/pages/contact.vue]
<script setup lang="ts">
const { polite, assertive } = useAnnouncer()

async function submitForm () {
  try {
    await $fetch('/api/contact', { method: 'POST', body: formData })
    polite('메시지가 성공적으로 전송되었습니다')
  } catch (error) {
    assertive('오류: 메시지 전송에 실패했습니다')
  }
}
</script>
```

## Slots %{#slots}%

announcer의 기본 슬롯을 통해 사용자 정의 HTML이나 컴포넌트를 전달할 수 있습니다.

```vue
<template>
  <NuxtAnnouncer>
    <template #default="{ message }">
      <p>{{ message }}</p>
    </template>
  </NuxtAnnouncer>
</template>
```

## Props %{#props}%

- `atomic`: 스크린 리더가 변경 사항만 읽을지 전체 콘텐츠를 읽을지 제어합니다. 업데이트 시 전체 내용을 읽게 하려면 true, 변경 사항만 읽게 하려면 false로 설정합니다. (기본값 `true`)
- `politeness`: 스크린 리더 안내의 기본 긴급도를 설정합니다: `off` (안내 비활성화), `polite` (조용해질 때까지 대기), `assertive` (즉시 끼어들기). (기본값 `polite`)

## `<NuxtRouteAnnouncer>`와의 차이점 %{#differences-from}%

| 항목 | `<NuxtRouteAnnouncer>` | `<NuxtAnnouncer>` |
|--------|------------------------|-------------------|
| **목적** | 라우트/페이지 변경을 알림 | 모든 동적 콘텐츠를 알림 |
| **트리거** | 탐색 시 자동 | `polite()`/`assertive()`로 수동 호출 |
| **메시지 소스** | 페이지 `<title>` | 개발자가 제공 |
| **atomic 기본값** | `false` | `true` |

::callout
이 컴포넌트는 선택 사항입니다. :br
완전히 사용자 정의하려면 [소스 코드](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/components/nuxt-announcer.ts)를 바탕으로 직접 구현할 수 있습니다.
::

::
