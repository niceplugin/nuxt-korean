`<NuxtImg>`는 네이티브 `<img>` 태그를 대체할 수 있는 drop-in 컴포넌트입니다.

- 내장 provider를 사용해 로컬 및 원격 이미지를 최적화합니다
- `src`를 provider 최적화 URL로 변환합니다
- `width`와 `height`를 기준으로 이미지를 자동 리사이즈합니다
- `sizes` 옵션을 제공하면 반응형 크기를 생성합니다
- 네이티브 lazy loading과 기타 `<img>` 속성을 지원합니다

## 설정 %{#setup}%

`<NuxtImg>`를 사용하려면 Nuxt Image 모듈을 설치하고 활성화해야 합니다:

```bash [Terminal]
npx nuxt module add image
```

## 사용법 %{#usage}%

`<NuxtImg>`는 네이티브 `img` 태그를 직접 출력합니다(별도의 wrapper 없이). `<img>` 태그를 사용하듯이 사용하면 됩니다:

```html
<NuxtImg src="/nuxt-icon.png" />
```

결과는 다음과 같습니다:

```html
<img src="/nuxt-icon.png" />
```
