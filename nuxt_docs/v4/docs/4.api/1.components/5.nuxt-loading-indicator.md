## 사용법 %{#usage}%

[`app.vue`](/docs/4.x/directory-structure/app/app) 또는 [`app/layouts/`](/docs/4.x/directory-structure/app/layouts)에 `<NuxtLoadingIndicator/>`를 추가하세요.

```vue [app/app.vue]
<template>
  <NuxtLoadingIndicator />
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

:link-example{to="/docs/4.x/examples/routing/pages"}

## Slots %{#slots}%

로딩 인디케이터의 기본 슬롯을 통해 사용자 정의 HTML이나 컴포넌트를 전달할 수 있습니다.

## Props %{#props}%

- `color`: 로딩 바의 색상입니다. 명시적인 색상 스타일링을 끄려면 `false`로 설정할 수 있습니다.
- `errorColor`: `error`가 `true`로 설정되었을 때의 로딩 바 색상입니다.
- `height`: 로딩 바의 높이(픽셀 단위, 기본값 `3`)입니다.
- `duration`: 로딩 바의 지속 시간(밀리초 단위, 기본값 `2000`)입니다.
- `throttle`: 표시/숨김에 대한 throttle 시간(밀리초 단위, 기본값 `200`)입니다.
- `estimatedProgress`: 기본적으로 Nuxt는 100%에 가까워질수록 속도를 늦춥니다. 진행도 추정을 사용자 정의 함수로 바꿀 수 있으며, 이 함수는 로딩 바의 지속 시간(위 값)과 경과 시간을 받아 0에서 100 사이 값을 반환해야 합니다.

::note
이 컴포넌트는 선택 사항입니다. :br
완전한 사용자 지정을 원한다면 [소스 코드](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/components/nuxt-loading-indicator.ts)를 기반으로 직접 구현할 수 있습니다.
::

::note
[the `useLoadingIndicator` composable](/docs/4.x/api/composables/use-loading-indicator)을 사용해 내부 인디케이터 인스턴스에 hook할 수 있으며, 이를 통해 start/finish 이벤트를 직접 트리거할 수 있습니다.
::

::tip
로딩 인디케이터의 속도는 `estimatedProgress`가 제어하는 특정 지점에 도달한 뒤 점차 감소합니다. 이 조정은 더 긴 페이지 로딩 시간을 더 정확하게 반영하고, 인디케이터가 너무 일찍 100% 완료를 표시하는 것을 방지합니다.
::
