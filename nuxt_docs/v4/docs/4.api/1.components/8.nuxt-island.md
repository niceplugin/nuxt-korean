island 컴포넌트를 렌더링할 때 island 컴포넌트의 콘텐츠는 정적이므로 클라이언트 사이드에서 JS를 내려받지 않습니다.

island 컴포넌트의 props를 변경하면 island 컴포넌트를 다시 가져와 재렌더링합니다.

::note
애플리케이션의 전역 스타일은 응답과 함께 전송됩니다.
::

::tip
Server only 컴포넌트는 내부적으로 `<NuxtIsland>`를 사용합니다
::

## Props %{#props}%

- `name` : 렌더링할 컴포넌트의 이름입니다.
  - **type**: `string`
  - **required**
- `lazy`: 컴포넌트를 비차단 방식으로 만듭니다.
  - **type**: `boolean`
  - **default**: `false`
- `props`: 렌더링할 컴포넌트에 전달할 Props입니다.
  - **type**: `Record<string, any>`
- `source`: island를 렌더링하기 위해 호출할 원격 소스입니다.
  - **type**: `string`
- **dangerouslyLoadClientComponents**: 원격 소스에서 클라이언트 컴포넌트를 불러오려면 필요합니다.
  - **type**: `boolean`
  - **default**: `false`

::note
원격 island를 사용하려면 `nuxt.config`에서 `experimental.componentIslands`를 `'local+remote'`로 설정해야 합니다.
::

::warning{icon="i-ph-warning-duotone"}
원격 서버의 콘텐츠를 렌더링하기 위해 `source` prop을 사용하는 것은 본질적으로 위험합니다. 원격 `source`를 지정하면, 해당 서버가 애플리케이션에 직접 렌더링될 안전한 HTML 콘텐츠를 제공한다고 전적으로 신뢰하게 됩니다.

이는 외부 콘텐츠에 `v-html`을 사용하는 것과 비슷합니다. 원격 서버는 잠재적으로 악의적인 콘텐츠를 포함한 어떤 HTML이든 주입할 수 있습니다. **`source`는 완전히 신뢰하고 제어할 수 있는 서버에만 사용하세요.**

`dangerouslyLoadClientComponents` prop은 추가적인 위험 계층을 제어합니다. 즉, 원격 소스에서 클라이언트 컴포넌트도 내려받아 실행할지 여부입니다. `dangerouslyLoadClientComponents`를 비활성화한 상태(기본값)에서도 여전히 원격 서버의 HTML 출력을 신뢰하게 됩니다.
::

::note
컴포넌트 props와 컨텍스트는 캐싱을 가능하게 하기 위해 GET 쿼리 매개변수로 전송됩니다. 쿼리 매개변수는 서버 접근 로그, CDN 캐시, HTTP `Referer` 헤더에 노출될 수 있습니다.
::

::note
기본적으로 컴포넌트 island는 `~/components/islands/` 디렉터리에서 스캔됩니다. 따라서 `~/components/islands/MyIsland.vue` 컴포넌트는 `<NuxtIsland name="MyIsland" />`로 렌더링할 수 있습니다.
::

## Slots %{#slots}%

선언되어 있다면 슬롯을 island 컴포넌트에 전달할 수 있습니다.

모든 슬롯은 부모 컴포넌트가 제공하는 것이므로 상호작용 가능합니다.

일부 슬롯은 특수한 경우를 위해 `NuxtIsland`에 예약되어 있습니다.

- `#fallback`: island가 로드되기 전에(컴포넌트가 lazy인 경우) 또는 `NuxtIsland`가 컴포넌트를 가져오지 못했을 때 렌더링할 콘텐츠를 지정합니다.

## Ref %{#ref}%

- `refresh()`
  - **type**: `() => Promise<void>`
  - **description**: 다시 가져와 서버 컴포넌트를 강제로 다시 가져옵니다.

## Events %{#events}%

- `error`
  - **parameters**:
    - **error**:
      - **type**: `unknown`
  - **description**: `NuxtIsland`가 새 island를 가져오지 못했을 때 발생합니다.
