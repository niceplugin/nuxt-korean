::important
이 컴포넌트는 Nuxt v3.17+에서 사용할 수 있습니다.
::

`<NuxtTime>` 컴포넌트는 올바른 `<time>` HTML 의미 체계와 함께 날짜와 시간을 로캘 친화적인 형식으로 표시할 수 있게 해줍니다. hydration 불일치 없이 서버와 클라이언트 간 일관된 렌더링을 보장합니다.

## Usage %{#usage}%

앱 어디에서든 `<NuxtTime>` 컴포넌트를 사용할 수 있습니다:

```vue
<template>
  <NuxtTime :datetime="Date.now()" />
</template>
```

## Props %{#props}%

### `datetime` %{#datetime}%

- Type: `Date | number | string`
- Required: `true`

표시할 날짜 및 시간 값입니다. 다음 중 하나를 제공할 수 있습니다:
- `Date` 객체
- 타임스탬프(숫자)
- ISO 형식의 날짜 문자열

```vue
<template>
  <NuxtTime :datetime="Date.now()" />
  <NuxtTime :datetime="new Date()" />
  <NuxtTime datetime="2023-06-15T09:30:00.000Z" />
</template>
```

### `locale` %{#locale}%

- Type: `string`
- Required: `false`
- Default: 브라우저 또는 서버의 기본 로캘 사용

포맷팅에 사용할 [BCP 47 language tag](https://datatracker.ietf.org/doc/html/rfc5646)입니다(예: 'en-US', 'fr-FR', 'ja-JP'):

```vue
<template>
  <NuxtTime
    :datetime="Date.now()"
    locale="fr-FR"
  />
</template>
```

### 포맷팅 Props %{#formatting-props}%

이 컴포넌트는 [Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/DateTimeFormat) 옵션의 모든 속성을 받을 수 있습니다:

```vue
<template>
  <NuxtTime
    :datetime="Date.now()"
    year="numeric"
    month="long"
    day="numeric"
    hour="2-digit"
    minute="2-digit"
  />
</template>
```

이 경우 `"2025년 4월 22일 오전 08:30"`과 같은 형식으로 출력됩니다

### `relative` %{#relative}%

- Type: `boolean`
- Required: `false`
- Default: `false`

Intl.RelativeTimeFormat API를 사용한 상대 시간 포맷팅을 활성화합니다:

```vue
<template>
  <!-- "5분 전"과 같은 형식으로 표시됩니다 -->
  <NuxtTime
    :datetime="Date.now() - 5 * 60 * 1000"
    relative
  />
</template>
```

### 상대 시간 포맷팅 Props %{#relative-time-formatting-props}%

`relative`를 `true`로 설정하면 이 컴포넌트는 [Intl.RelativeTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/RelativeTimeFormat/RelativeTimeFormat)의 속성도 받을 수 있습니다:

::warning
`style`은 예약된 prop이므로 대신 `relativeStyle` prop을 사용합니다.
::

```vue
<template>
  <NuxtTime
    :datetime="Date.now() - 3 * 24 * 60 * 60 * 1000"
    relative
    numeric="auto"
    relative-style="long"
  />
</template>
```

이 경우 `numeric` 설정에 따라 `"3일 전"` 또는 `"지난 금요일"`과 같은 형식으로 출력됩니다.

## Examples %{#examples}%

### 기본 사용법 %{#basic-usage}%

```vue
<template>
  <NuxtTime :datetime="Date.now()" />
</template>
```

### 커스텀 포맷팅 %{#custom-formatting}%

```vue
<template>
  <NuxtTime
    :datetime="Date.now()"
    weekday="long"
    year="numeric"
    month="short"
    day="numeric"
    hour="numeric"
    minute="numeric"
    second="numeric"
    time-zone-name="short"
  />
</template>
```

### 상대 시간 %{#relative-time}%

```vue
<template>
  <div>
    <p>
      <NuxtTime
        :datetime="Date.now() - 30 * 1000"
        relative
      />
      <!-- 30초 전 -->
    </p>
    <p>
      <NuxtTime
        :datetime="Date.now() - 45 * 60 * 1000"
        relative
      />
      <!-- 45분 전 -->
    </p>
    <p>
      <NuxtTime
        :datetime="Date.now() + 2 * 24 * 60 * 60 * 1000"
        relative
      />
      <!-- 2일 후 -->
    </p>
  </div>
</template>
```

### 커스텀 로캘과 함께 사용하기 %{#with-custom-locale}%

```vue
<template>
  <div>
    <NuxtTime
      :datetime="Date.now()"
      locale="en-US"
      weekday="long"
    />
    <NuxtTime
      :datetime="Date.now()"
      locale="fr-FR"
      weekday="long"
    />
    <NuxtTime
      :datetime="Date.now()"
      locale="ja-JP"
      weekday="long"
    />
  </div>
</template>
```
