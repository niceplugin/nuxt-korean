`<NuxtPicture>`는 기본 `<picture>` 태그를 그대로 대체할 수 있는 컴포넌트입니다.

`<NuxtPicture>`의 사용법은 [`<NuxtImg>`](/docs/4.x/api/components/nuxt-img)와 거의 동일하지만, 가능한 경우 `webp`와 같은 최신 포맷으로 제공할 수도 있습니다.

[`<picture>` 태그에 대해 MDN에서 더 알아보기](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/picture).

## Setup %{setup}%

`<NuxtPicture>`를 사용하려면 Nuxt Image 모듈을 설치하고 활성화해야 합니다:

```bash [Terminal]
npx nuxt module add image
```
