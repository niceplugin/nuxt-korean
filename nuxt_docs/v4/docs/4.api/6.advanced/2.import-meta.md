## `import.meta` 객체 %{#the-import-meta-object}%

ES 모듈에서는 ES 모듈을 가져오거나 컴파일하는 코드로부터 몇 가지 메타데이터를 얻을 수 있습니다.
이 작업은 `import.meta`를 통해 수행되며, 이는 코드에 이 정보를 제공하는 객체입니다.
Nuxt 문서 전반에서 이미 이를 사용하여 현재 코드가
클라이언트 사이드에서 실행 중인지 서버 사이드에서 실행 중인지 판단하는 스니펫을 볼 수 있습니다.

::read-more{to="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/import.meta"}
`import.meta`에 대해 더 알아보세요.
::

## 런타임(App) 속성 %{#runtime-app-properties}%

이 값들은 정적으로 주입되며 런타임 코드의 tree-shaking에 사용할 수 있습니다.

속성 | 타입 | 설명
--- | --- | ---
`import.meta.client` | boolean | 클라이언트 사이드에서 평가될 때 true입니다.
`import.meta.browser` | boolean | 클라이언트 사이드에서 평가될 때 true입니다.
`import.meta.server` | boolean | 서버 사이드에서 평가될 때 true입니다.
`import.meta.nitro` | boolean | 서버 사이드에서 평가될 때 true입니다.
`import.meta.dev` | boolean | Nuxt dev 서버 실행 중일 때 true입니다.
`import.meta.test` | boolean | 테스트 컨텍스트에서 실행 중일 때 true입니다.
`import.meta.prerender` | boolean | 빌드의 prerender 단계에서 서버가 HTML을 렌더링할 때 true입니다.

## 빌더 속성 %{#builder-properties}%

이 값들은 모듈과 `nuxt.config` 양쪽 모두에서 사용할 수 있습니다.

속성 | 타입 | 설명
--- | --- | ---
`import.meta.env` | object | `process.env`와 같습니다
`import.meta.url` | string | 현재 파일의 resolve 가능한 경로입니다.

## Examples %{#examples}%

### 모듈 내부 파일을 resolve하기 위해 `import.meta.url` 사용하기 %{#using-import-meta-url-to-resolve-files-within-modules}%

```ts [modules/my-module/index.ts]
import { createResolver } from 'nuxt/kit'

// 현재 파일을 기준으로 상대 경로를 resolve합니다
const resolver = createResolver(import.meta.url)

export default defineNuxtModule({
  meta: { name: 'myModule' },
  setup () {
    addComponent({
      name: 'MyModuleComponent',
      // '/modules/my-module/components/MyModuleComponent.vue'로 resolve됩니다
      filePath: resolver.resolve('./components/MyModuleComponent.vue'),
    })
  },
})
```
