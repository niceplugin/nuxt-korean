## 앱 훅 (런타임) %{#app-hooks-runtime}%

사용 가능한 모든 훅은 [app 소스 코드](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/nuxt.ts#L37)를 확인하세요.

| 훅                           | 인자                | 환경            | 설명                                                                                                                                                                                  |
|------------------------------|---------------------|-----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `app:created`                | `vueApp`            | 서버 및 클라이언트 | 초기 `vueApp` 인스턴스가 생성될 때 호출됩니다.                                                                                                                                         |
| `app:error`                  | `err`               | 서버 및 클라이언트 | 치명적인 오류가 발생할 때 호출됩니다.                                                                                                                                                 |
| `app:error:cleared`          | `{ redirect? }`     | 서버 및 클라이언트 | 치명적인 오류가 발생할 때 호출됩니다.                                                                                                                                                 |
| `vue:setup`                  | -                   | 서버 및 클라이언트 | Nuxt 루트의 setup이 초기화될 때 호출됩니다. 이 콜백은 동기식이어야 합니다.                                                                                                            |
| `vue:error`                  | `err, target, info` | 서버 및 클라이언트 | Vue 오류가 루트 컴포넌트까지 전파될 때 호출됩니다. [자세히 보기](https://vuejs.org/api/composition-api-lifecycle#onerrorcaptured).                                                   |
| `app:rendered`               | `renderContext`     | 서버            | SSR 렌더링이 완료되면 호출됩니다.                                                                                                                                                     |
| `app:redirected`             | -                   | 서버            | SSR 리디렉션 전에 호출됩니다.                                                                                                                                                         |
| `app:beforeMount`            | `vueApp`            | 클라이언트      | 앱을 마운트하기 전에 호출되며, 클라이언트 측에서만 호출됩니다.                                                                                                                        |
| `app:mounted`                | `vueApp`            | 클라이언트      | Vue 앱이 초기화되어 브라우저에 마운트되면 호출됩니다.                                                                                                                                 |
| `app:suspense:resolve`       | `appComponent`      | 클라이언트      | [Suspense](https://vuejs.org/guide/built-ins/suspense#suspense)의 resolve 이벤트에서 호출됩니다.                                                                                      |
| `app:manifest:update`        | `{ id, timestamp }` | 클라이언트      | 앱의 더 새로운 버전이 감지되면 호출됩니다.                                                                                                                                             |
| `app:data:refresh`           | `keys?`             | 클라이언트      | `refreshNuxtData`가 호출될 때 호출됩니다.                                                                                                                                             |
| `link:prefetch`              | `to`                | 클라이언트      | `<NuxtLink>`가 프리페치 대상으로 감지되면 호출됩니다.                                                                                                                                 |
| `page:start`                 | `pageComponent?`    | 클라이언트      | `NuxtPage` 내부 [Suspense](https://vuejs.org/guide/built-ins/suspense#suspense)의 pending 이벤트에서 호출됩니다.                                                                      |
| `page:finish`                | `pageComponent?`    | 클라이언트      | `NuxtPage` 내부 [Suspense](https://vuejs.org/guide/built-ins/suspense#suspense)의 resolve 이벤트에서 호출됩니다.                                                                      |
| `page:loading:start`         | -                   | 클라이언트      | 라우트 탐색이 시작될 때(해결 전) 또는 페이지 키가 바뀔 때 호출됩니다. 페이지가 재사용되는 경우(`definePageMeta`에 정적인 `key`가 있는 경우 등) 페이지 컴포넌트의 `setup()`이 다시 실행되지 않아도 발생할 수 있습니다. |
| `page:loading:end`           | -                   | 클라이언트      | `page:finish` 이후에 호출됩니다.                                                                                                                                                      |
| `page:transition:finish`     | `pageComponent?`    | 클라이언트      | 페이지 전환의 [onAfterLeave](https://vuejs.org/guide/built-ins/transition#javascript-hooks) 이벤트 이후에 호출됩니다.                                                                  |
| `dev:ssr-logs`               | `logs`              | 클라이언트      | 서버 측 로그가 클라이언트로 전달된 배열과 함께 호출됩니다 (`features.devLogs`가 활성화된 경우).                                                                                         |
| `page:view-transition:start` | `transition`        | 클라이언트      | [실험적 viewTransition 지원이 활성화된 경우](/docs/4.x/getting-started/transitions#view-transitions-api-experimental) `document.startViewTransition`가 호출된 뒤 호출됩니다. `transition` 인자는 `types` 속성([`ViewTransitionTypeSet`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransitionTypeSet))을 가진 [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition) 객체이며 읽거나 수정할 수 있습니다. |

## Nuxt 훅 (빌드 타임) %{#nuxt-hooks-build-time}%

사용 가능한 모든 훅은 [schema 소스 코드](https://github.com/nuxt/nuxt/blob/main/packages/schema/src/types/hooks.ts#L83)를 확인하세요.

| 훅                          | 인자                                                     | 설명                                                                                                                                                                                                                                                                                         |
|-----------------------------|----------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `kit:compatibility`         | `compatibility, issues`                                  | 호환성 검사를 확장할 수 있습니다.                                                                                                                                                                                                                                                            |
| `ready`                     | `nuxt`                                                   | Nuxt 초기화 후, Nuxt 인스턴스가 작업할 준비가 되면 호출됩니다.                                                                                                                                                                                                                               |
| `close`                     | `nuxt`                                                   | Nuxt 인스턴스가 정상적으로 종료될 때 호출됩니다.                                                                                                                                                                                                                                             |
| `restart`                   | `{ hard?: boolean }`                                     | 현재 Nuxt 인스턴스를 재시작하기 위해 호출됩니다.                                                                                                                                                                                                                                             |
| `modules:before`            | -                                                        | Nuxt 초기화 중, 사용자 모듈을 설치하기 전에 호출됩니다.                                                                                                                                                                                                                                      |
| `modules:done`              | -                                                        | Nuxt 초기화 중, 사용자 모듈을 설치한 후에 호출됩니다.                                                                                                                                                                                                                                        |
| `app:resolve`               | `app`                                                    | `app` 인스턴스가 resolve된 후 호출됩니다.                                                                                                                                                                                                                                                    |
| `app:templates`             | `app`                                                    | `NuxtApp` 생성 중에 호출되며, 빌드 디렉터리에 새 파일을 사용자 지정, 수정 또는 추가할 수 있게 합니다 (가상으로 추가하거나 `.nuxt`에 기록 가능).                                                                                                                                             |
| `app:templatesGenerated`    | `app`                                                    | 템플릿이 [가상 파일 시스템](/docs/4.x/directory-structure/nuxt) (vfs)에 컴파일된 후 호출됩니다.                                                                                                                                                                                              |
| `build:before`              | -                                                        | Nuxt 번들 빌더 전에 호출됩니다.                                                                                                                                                                                                                                                              |
| `build:done`                | -                                                        | Nuxt 번들 빌더가 완료된 후 호출됩니다.                                                                                                                                                                                                                                                       |
| `build:manifest`            | `manifest`                                               | Vite와 webpack의 매니페스트 빌드 중에 호출됩니다. 이를 통해 Nitro가 최종 HTML에서 `<script>` 및 `<link>` 태그를 렌더링할 때 사용할 매니페스트를 사용자 지정할 수 있습니다.                                                                                                                   |
| `builder:generateApp`       | `options`                                                | 앱을 생성하기 전에 호출됩니다.                                                                                                                                                                                                                                                               |
| `builder:watch`             | `event, path`                                            | 개발 중 빌드 시 감시기가 프로젝트의 파일 또는 디렉터리 변경을 감지하면 호출됩니다.                                                                                                                                                                                                          |
| `pages:extend`              | `pages`                                                  | 페이지 라우트가 파일 시스템에서 스캔된 후 호출됩니다.                                                                                                                                                                                                                                        |
| `pages:resolved`            | `pages`                                                  | 페이지 라우트에 스캔된 메타데이터가 보강된 후 호출됩니다.                                                                                                                                                                                                                                    |
| `pages:routerOptions`       | `{ files: Array<{ path: string, optional?: boolean }> }` | `router.options` 파일을 resolve할 때 호출됩니다. 배열의 뒤쪽 항목이 앞쪽 항목을 덮어씁니다.                                                                                                                                                                                                  |
| `server:devHandler`         | `handler`                                                | Nitro 개발 서버에 dev 미들웨어가 등록될 때 호출됩니다.                                                                                                                                                                                                                                      |
| `imports:sources`           | `presets`                                                | 설정 시 모듈이 소스를 확장할 수 있도록 호출됩니다.                                                                                                                                                                                                                                           |
| `imports:extend`            | `imports`                                                | 설정 시 모듈이 imports를 확장할 수 있도록 호출됩니다.                                                                                                                                                                                                                                        |
| `imports:context`           | `context`                                                | [unimport](https://github.com/unjs/unimport) 컨텍스트가 생성될 때 호출됩니다.                                                                                                                                                                                                                |
| `imports:dirs`              | `dirs`                                                   | import 디렉터리를 확장할 수 있습니다.                                                                                                                                                                                                                                                        |
| `components:dirs`           | `dirs`                                                   | `app:resolve` 내에서 호출되며, 자동 import 가능한 컴포넌트를 스캔하는 디렉터리를 확장할 수 있게 합니다.                                                                                                                                                                                     |
| `components:extend`         | `components`                                             | 새 컴포넌트를 확장할 수 있습니다.                                                                                                                                                                                                                                                            |
| `nitro:config`              | `nitroConfig`                                            | Nitro 초기화 전에 호출되며 Nitro 구성을 사용자 지정할 수 있습니다.                                                                                                                                                                                                                            |
| `nitro:init`                | `nitro`                                                  | Nitro가 초기화된 후 호출되며, Nitro 훅을 등록하고 Nitro와 직접 상호작용할 수 있습니다.                                                                                                                                                                                                       |
| `nitro:build:before`        | `nitro`                                                  | Nitro 인스턴스를 빌드하기 전에 호출됩니다.                                                                                                                                                                                                                                                   |
| `nitro:build:public-assets` | `nitro`                                                  | 공개 자산이 복사된 후 호출됩니다. Nitro 서버가 빌드되기 전에 공개 자산을 수정할 수 있습니다.                                                                                                                                                                                                 |
| `prerender:routes`          | `ctx`                                                    | 사전 렌더링할 라우트를 확장할 수 있습니다.                                                                                                                                                                                                                                                   |
| `build:error`               | `error`                                                  | 빌드 시 오류가 발생하면 호출됩니다.                                                                                                                                                                                                                                                          |
| `prepare:types`             | `options`                                                | `@nuxt/cli`가 TypeScript 구성 파일(`.nuxt/tsconfig.app.json`, `.nuxt/tsconfig.server.json` 등)과 `.nuxt/nuxt.d.ts`를 기록하기 전에 호출되며, `nuxt.d.ts`에 사용자 정의 참조와 선언을 추가하거나 생성된 구성의 옵션을 직접 수정할 수 있게 합니다.                                          |
| `listen`                    | `listenerServer, listener`                               | 개발 서버가 로드될 때 호출됩니다.                                                                                                                                                                                                                                                            |
| `schema:extend`             | `schemas`                                                | 기본 스키마를 확장할 수 있습니다.                                                                                                                                                                                                                                                            |
| `schema:resolved`           | `schema`                                                 | resolve된 스키마를 확장할 수 있습니다.                                                                                                                                                                                                                                                       |
| `schema:beforeWrite`        | `schema`                                                 | 지정된 스키마를 기록하기 전에 호출됩니다.                                                                                                                                                                                                                                                    |
| `schema:written`            | -                                                        | 스키마가 기록된 후 호출됩니다.                                                                                                                                                                                                                                                               |
| `vite:extend`               | `viteBuildContext`                                       | Vite 기본 컨텍스트를 확장할 수 있습니다.                                                                                                                                                                                                                                                     |
| `vite:extendConfig`         | `viteInlineConfig, env`                                  | Vite 기본 구성을 확장할 수 있습니다. **Nuxt 5+에서는 더 이상 권장되지 않습니다.** Nuxt 5에서는 분리된 클라이언트/서버 구성 대신 공유 구성을 대상으로 동작합니다.                                                                                                                             |
| `vite:configResolved`       | `viteInlineConfig, env`                                  | resolve된 Vite 구성을 읽을 수 있습니다. **Nuxt 5+에서는 더 이상 권장되지 않습니다.** Nuxt 5에서는 분리된 클라이언트/서버 구성 대신 공유 구성을 대상으로 동작합니다.                                                                                                                          |
| `vite:serverCreated`        | `viteServer, env`                                        | Vite 서버가 생성될 때 호출됩니다.                                                                                                                                                                                                                                                            |
| `vite:compiled`             | -                                                        | Vite 서버가 컴파일된 후 호출됩니다.                                                                                                                                                                                                                                                          |
| `webpack:config`            | `webpackConfigs`                                         | webpack 컴파일러를 구성하기 전에 호출됩니다.                                                                                                                                                                                                                                                 |
| `webpack:configResolved`    | `webpackConfigs`                                         | resolve된 webpack 구성을 읽을 수 있습니다.                                                                                                                                                                                                                                                   |
| `webpack:compile`           | `options`                                                | 컴파일 직전에 호출됩니다.                                                                                                                                                                                                                                                                     |
| `webpack:compiled`          | `options`                                                | 리소스가 로드된 후 호출됩니다.                                                                                                                                                                                                                                                               |
| `webpack:change`            | `shortPath`                                              | WebpackBar에서 `change` 시 호출됩니다.                                                                                                                                                                                                                                                       |
| `webpack:error`             | -                                                        | WebpackBar에 오류가 있으면 `done` 시 호출됩니다.                                                                                                                                                                                                                                             |
| `webpack:done`              | -                                                        | WebpackBar에서 `allDone` 시 호출됩니다.                                                                                                                                                                                                                                                      |
| `webpack:progress`          | `statesArray`                                            | WebpackBar에서 `progress` 시 호출됩니다.                                                                                                                                                                                                                                                     |

## Nitro 앱 훅 (런타임, 서버 사이드) %{#nitro-app-hooks-runtime-server-side}%
