Nuxt의 head 태그 관리는 [Unhead](https://unhead.unjs.io)로 구동됩니다. Unhead는 합리적인 기본값, 여러 강력한 컴포저블,
그리고 앱의 head와 SEO 메타 태그를 관리하기 위한 다양한 설정 옵션을 제공합니다.

## Nuxt 설정 %{#nuxt-config}%

[`nuxt.config.ts`](/docs/4.x/directory-structure/nuxt-config)에 [`app.head`](/docs/4.x/api/nuxt-config#head) 속성을 제공하면 앱 전체의 head를 정적으로 사용자 정의할 수 있습니다.

::important
이 방법은 반응형 데이터를 제공할 수 없습니다. `app.vue`에서 `useHead()`를 사용하는 것을 권장합니다.
::

사이트 기본 제목, 언어, 파비콘처럼 변경되지 않을 태그는 여기에서 설정하는 것이 좋습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      title: 'Nuxt', // 기본 대체 제목
      htmlAttrs: {
        lang: 'en',
      },
      link: [
        { rel: 'icon', type: 'image/x-icon', href: '/favicon.ico' },
      ],
    },
  },
})
```

아래 [타입](/docs/4.x/getting-started/seo-meta#types)에 나열된 키도 제공할 수 있습니다.

### 기본 태그 %{#defaults-tags}%

일부 태그는 웹사이트가 별도 설정 없이도 잘 동작하도록 Nuxt가 기본으로 제공합니다.

- `viewport`: `width=device-width, initial-scale=1`
- `charset`: `utf-8`

대부분의 사이트는 이 기본값을 재정의할 필요가 없지만, 키 단축 구문을 사용해 업데이트할 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      // Nuxt 기본값 업데이트
      charset: 'utf-16',
      viewport: 'width=device-width, initial-scale=1, maximum-scale=1',
    },
  },
})
```

## `useHead` %{#usehead}%

[`useHead`](/docs/4.x/api/composables/use-head) 컴포저블 함수는 반응형 입력을 지원하므로 head 태그를 프로그래밍 방식으로 관리할 수 있습니다.

```vue twoslash [app/app.vue]
<script setup lang="ts">
useHead({
  title: '내 앱',
  meta: [
    { name: 'description', content: '내 멋진 사이트입니다.' },
  ],
  bodyAttrs: {
    class: 'test',
  },
  script: [{ innerHTML: 'console.log(\'안녕하세요 세상\')' }],
})
</script>
```

[`useHead`](/docs/4.x/api/composables/use-head)와 [`useHeadSafe`](/docs/4.x/api/composables/use-head-safe) 컴포저블도 함께 살펴보는 것을 권장합니다.

## `useSeoMeta` %{#useseometa}%

[`useSeoMeta`](/docs/4.x/api/composables/use-seo-meta) 컴포저블을 사용하면 사이트의 SEO 메타 태그를 완전한 타입 안정성을 갖춘 객체로 정의할 수 있습니다.

이를 통해 `property` 대신 `name`을 사용하는 것과 같은 오타와 흔한 실수를 피할 수 있습니다.

```vue twoslash [app/app.vue]
<script setup lang="ts">
useSeoMeta({
  title: '내 멋진 사이트',
  ogTitle: '내 멋진 사이트',
  description: '이곳은 내 멋진 사이트입니다. 자세히 소개해 드릴게요.',
  ogDescription: '이곳은 내 멋진 사이트입니다. 자세히 소개해 드릴게요.',
  ogImage: 'https://example.com/image.png',
  twitterCard: 'summary_large_image',
})
</script>
```

:read-more{to="/docs/4.x/api/composables/use-seo-meta"}

## 컴포넌트 %{#components}%

모든 경우에 [`useHead`](/docs/4.x/api/composables/use-head)를 사용하는 것을 권장하지만, 개인적으로는 컴포넌트를 사용해 템플릿에서 head 태그를 정의하는 방식을 선호할 수도 있습니다.

Nuxt는 이 목적을 위해 다음 컴포넌트를 제공합니다: `<Title>`, `<Base>`, `<NoScript>`, `<Style>`, `<Meta>`, `<Link>`, `<Body>`, `<Html>`, `<Head>`. 여기서
중요한 점은 잘못된 네이티브 HTML 태그를 사용하지 않도록 이 컴포넌트들의 대문자 표기를 지키는 것입니다.

`<Head>`와 `<Body>`는 중첩된 메타 태그를 받을 수 있지만(가독성을 위한 용도), 이것이 최종 HTML에서 중첩된 메타 태그가 렌더링되는 _위치_ 에 영향을 주지는 않습니다.

<!-- @case-police-ignore html -->

```vue [app/app.vue]
<script setup lang="ts">
const title = ref('안녕하세요 세계')
</script>

<template>
  <div>
    <Head>
      <Title>{{ title }}</Title>
      <Meta
        name="description"
        :content="title"
      />
      <Style>
        body { background-color: green; }
      </Style>
    </Head>

    <h1>{{ title }}</h1>
  </div>
</template>
```

태그가 더 직관적으로 중복 제거되도록 컴포넌트를 `<Head>` 또는 `<Html>` 컴포넌트로 감싸는 것을 권장합니다.

::warning
클라이언트-서버 경계를 넘어 태그를 중복해야 한다면 `<Head>` 컴포넌트에 `key` 속성을 적용하세요.
::

## 타입 %{#types}%

아래는 [`useHead`](/docs/4.x/api/composables/use-head), [`app.head`](/docs/4.x/api/nuxt-config#head), 컴포넌트에서 사용하는 비반응형 타입입니다.

```ts
interface MetaObject {
  title?: string
  titleTemplate?: string | ((title?: string) => string)
  templateParams?: Record<string, string | Record<string, string>>
  base?: Base
  link?: Link[]
  meta?: Meta[]
  style?: Style[]
  script?: Script[]
  noscript?: Noscript[]
  htmlAttrs?: HtmlAttributes
  bodyAttrs?: BodyAttributes
}
```

더 자세한 타입은 [@unhead/vue](https://github.com/unjs/unhead/blob/main/packages/vue/src/types/schema.ts)를 참고하세요.

## 기능 %{#features}%

### 반응성 %{#reactivity}%

계산된 값, getter, 반응형 객체를 제공하면 모든 속성에서 반응성을 지원합니다.

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  const description = ref('내 멋진 사이트입니다.')

  useHead({
    meta: [
      { name: 'description', content: description },
    ],
  })
  </script>
  ```

  ```vue twoslash [useSeoMeta]
  <script setup lang="ts">
  const description = ref('내 멋진 사이트입니다.')

  useSeoMeta({
    description,
  })
  </script>
  ```

  ```vue [app/Components]
  <script setup lang="ts">
  const description = ref('내 멋진 사이트입니다.')
  </script>

  <template>
    <div>
      <Meta
        name="description"
        :content="description"
      />
    </div>
  </template>
  ```

::

### 제목 템플릿 %{#title-template}%

`titleTemplate` 옵션을 사용하면 사이트 제목을 사용자 정의하기 위한 동적 템플릿을 제공할 수 있습니다. 예를 들어 모든 페이지 제목에 사이트 이름을 추가할 수 있습니다.

`titleTemplate`는 `%s`가 제목으로 대체되는 문자열일 수도 있고, 함수일 수도 있습니다.

함수(완전한 제어를 위해)를 사용하려면 이를 `nuxt.config`에 설정할 수 없습니다. 대신 사이트의 모든 페이지에 적용되도록 `app.vue` 파일 안에서 설정하는 것을 권장합니다:

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    titleTemplate: (titleChunk) => {
      return titleChunk ? `${titleChunk} - 사이트 제목` : '사이트 제목'
    },
  })
  </script>
  ```

::

이제 사이트의 다른 페이지에서 [`useHead`](/docs/4.x/api/composables/use-head)로 제목을 `내 페이지`로 설정하면 브라우저 탭에는 '내 페이지 - 사이트 제목'으로 표시됩니다. 기본값인 '사이트 제목'을 사용하려면 `null`을 전달할 수도 있습니다.

### 템플릿 매개변수 %{#template-params}%

`templateParams`를 사용하면 기본 `%s` 외에도 `titleTemplate`에 추가 플레이스홀더를 제공할 수 있습니다. 이를 통해 더 동적인 제목 생성이 가능합니다.

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    titleTemplate: (titleChunk) => {
      return titleChunk ? `${titleChunk} %separator %siteName` : '%siteName'
    },
    templateParams: {
      siteName: '사이트 제목',
      separator: '-',
    },
  })
  </script>
  ```

::

### Body 태그 %{#body-tags}%

적용 가능한 태그에 `tagPosition: 'bodyClose'` 옵션을 사용하면 `<body>` 태그의 끝에 태그를 추가할 수 있습니다.

예를 들어:

```vue twoslash
<script setup lang="ts">
useHead({
  script: [
    {
      src: 'https://third-party-script.com',
      // 유효한 옵션: 'head' | 'bodyClose' | 'bodyOpen'
      tagPosition: 'bodyClose',
    },
  ],
})
</script>
```

## 예시 %{#examples}%

### `definePageMeta`와 함께 %{#with-definepagemeta}%

[`app/pages/` 디렉터리](/docs/4.x/directory-structure/app/pages) 안에서는 [`useHead`](/docs/4.x/api/composables/use-head)와 함께 `definePageMeta`를 사용하여 현재 라우트를 기반으로 메타데이터를 설정할 수 있습니다.

예를 들어 현재 페이지 제목을 먼저 설정할 수 있습니다(이는 매크로를 통해 빌드 시 추출되므로 동적으로 설정할 수 없습니다):

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  title: '일부 페이지',
})
</script>
```

그다음 레이아웃 파일에서 앞서 설정한 라우트 메타데이터를 사용할 수 있습니다:

```vue twoslash [layouts/default.vue]
<script setup lang="ts">
const route = useRoute()

useHead({
  meta: [{ property: 'og:title', content: `앱 이름 - ${route.meta.title}` }],
})
</script>
```

:read-more{to="/docs/4.x/directory-structure/app/pages/#page-metadata"}

### 동적 제목 %{#dynamic-title}%

아래 예시에서는 `titleTemplate`를 `%s` 플레이스홀더가 포함된 문자열 또는 `function`으로 설정하며, 이를 통해 Nuxt 앱의 각 라우트마다 페이지 제목을 더 유연하게 동적으로 설정할 수 있습니다:

```vue twoslash [app/app.vue]
<script setup lang="ts">
useHead({
  // 문자열로 사용
  // `%s`는 제목으로 대체됩니다
  titleTemplate: '%s - 사이트 제목',
})
</script>
```

```vue twoslash [app/app.vue]
<script setup lang="ts">
useHead({
  // 또는 함수로 사용
  titleTemplate: (productCategory) => {
    return productCategory
      ? `${productCategory} - 사이트 제목`
      : '사이트 제목'
  },
})
</script>
```

페이지 제목을 설정하는 다른 방법으로 `nuxt.config`도 사용할 수 있습니다. 하지만 `nuxt.config`는 페이지 제목을 동적으로 설정할 수 없습니다. 따라서 `app.vue` 파일에서 `titleTemplate`를 사용해 동적 제목을 추가하고, 이를 Nuxt 앱의 모든 라우트에 적용하는 방식을 권장합니다.

### 외부 CSS %{#external-css}%

아래 예시는 [`useHead`](/docs/4.x/api/composables/use-head) 컴포저블의 `link` 속성이나 `<Link>` 컴포넌트를 사용해 Google Fonts를 활성화하는 방법을 보여줍니다:

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    link: [
      {
        rel: 'preconnect',
        href: 'https://fonts.googleapis.com',
      },
      {
        rel: 'stylesheet',
        href: 'https://fonts.googleapis.com/css2?family=Roboto&display=swap',
        crossorigin: '',
      },
    ],
  })
  </script>
  ```

  ```vue [app/Components]
  <template>
    <div>
      <Link
        rel="preconnect"
        href="https://fonts.googleapis.com"
      />
      <Link
        rel="stylesheet"
        href="https://fonts.googleapis.com/css2?family=Roboto&display=swap"
        crossorigin=""
      />
    </div>
  </template>
  ```

::
