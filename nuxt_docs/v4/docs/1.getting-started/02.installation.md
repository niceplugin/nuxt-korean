## 온라인에서 사용해 보기 %{#play-online}%

프로젝트를 설정하지 않고 브라우저에서 Nuxt를 가볍게 사용해 보고 싶다면 온라인 샌드박스 중 하나를 사용할 수 있습니다.

::card-group
  :card{title="StackBlitz에서 열기" icon="i-simple-icons-stackblitz" to="https://nuxt.new/s/v4" target="_blank"}
  :card{title="CodeSandbox에서 열기" icon="i-simple-icons-codesandbox" to="https://nuxt.new/c/v4" target="_blank"}
::

또는 아래 단계에 따라 컴퓨터에 새 Nuxt 프로젝트를 설정할 수 있습니다.

## 새 프로젝트 %{#new-project}%

### 사전 요구 사항 %{#prerequisites}%

- **Node.js** - [`20.x`](https://nodejs.org/en) 이상(하지만 [현재 활성 LTS 릴리스](https://github.com/nodejs/release#release-schedule)를 권장합니다)
- **텍스트 편집기** - 특정 IDE가 꼭 필요한 것은 아니지만, [공식 Vue 확장](https://marketplace.visualstudio.com/items?itemName=Vue.volar)(이전 이름은 Volar)이 설치된 [Visual Studio Code](https://code.visualstudio.com/) 또는 [WebStorm](https://www.jetbrains.com/webstorm/)을 권장합니다. 이는 [다른 JetBrains IDE](https://www.jetbrains.com/ides/)와 함께 기본 상태에서 훌륭한 Nuxt 지원을 제공합니다. Neovim 같은 다른 편집기를 사용한다면 [Vue Language Tools 설정 가이드](https://github.com/vuejs/language-tools/wiki)를 따라 [Vue Language Server](https://github.com/vuejs/language-tools) 지원을 구성할 수 있습니다.
- **터미널** - Nuxt 명령을 실행하기 위해 필요합니다

::note
  ::details
  :summary[최적의 설정을 위한 추가 참고 사항:]
  - **Node.js**: 짝수 버전(20, 22 등)을 사용해야 합니다.
  - **Neovim**: Vue TypeScript 플러그인을 설정할 때 `location`이 바이너리가 아니라 `@vue/language-server` 패키지 디렉터리를 가리키도록 하세요. 동작하는 구성은 [Neovim 설정 가이드](https://github.com/vuejs/language-tools/wiki/Neovim)를 참고하세요.
  - **WSL**: Windows를 사용 중이고 HMR이 느리다면, 성능 문제를 해결할 수 있는 [WSL(Windows Subsystem for Linux)](https://learn.microsoft.com/en-us/windows/wsl/install) 사용을 시도해 볼 수 있습니다.
  - **Windows의 느린 DNS 확인**: Windows에서 로컬 개발 서버에 `localhost:3000` 대신 `127.0.0.1`을 사용하면 브라우저 로딩 속도가 훨씬 빨라질 수 있습니다.
  ::
::

터미널을 열고([Visual Studio Code](https://code.visualstudio.com)를 사용 중이라면 [통합 터미널](https://code.visualstudio.com/docs/terminal/basics)을 열 수 있습니다) 다음 명령으로 새 스타터 프로젝트를 생성하세요.

::code-group{sync="pm"}

```bash [npm]
npm create nuxt@latest <project-name>
```

```bash [yarn]
yarn create nuxt <project-name>
```

```bash [pnpm]
pnpm create nuxt@latest <project-name>
```

```bash [bun]
bun create nuxt@latest <project-name>
```

```bash [deno]
deno -A npm:create-nuxt@latest <project-name>
```

::

::tip
또는 [nuxt.new](https://nuxt.new)를 열고 안내를 따라 다른 스타터나 테마를 찾을 수 있습니다.
::

Visual Studio Code에서 프로젝트 폴더를 여세요.

```bash [Terminal]
code <project-name>
```

또는 터미널에서 새 프로젝트 디렉터리로 이동하세요.

```bash
cd <project-name>
```

## 개발 서버 %{#development-server}%

이제 개발 모드에서 Nuxt 앱을 시작할 수 있습니다.

::code-group{sync="pm"}

```bash [npm]
npm run dev -- -o
```

```bash [yarn]
yarn dev --open
```

```bash [pnpm]
pnpm dev -o
```

```bash [bun]
bun run dev -o

# 개발 중 Bun 런타임을 사용하려면
# bun --bun run dev -o
```

```bash [deno]
deno run dev -o
```
::

::tip{icon="i-lucide-circle-check"}
잘했습니다! <http://localhost:3000>에 대한 브라우저 창이 자동으로 열릴 것입니다.
::
