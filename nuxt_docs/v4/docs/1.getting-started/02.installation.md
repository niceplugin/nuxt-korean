## 온라인에서 실행하기 %{play-online}%

프로젝트를 설정하지 않고 브라우저에서 Nuxt를 간단히 사용해 보고 싶다면, 아래 온라인 샌드박스 중 하나를 사용할 수 있습니다:

::card-group
  :card{title="StackBlitz에서 열기" icon="i-simple-icons-stackblitz" to="https://nuxt.new/s/v4" target="_blank"}
  :card{title="CodeSandbox에서 열기" icon="i-simple-icons-codesandbox" to="https://nuxt.new/c/v4" target="_blank"}
::

또는 아래 단계를 따라 컴퓨터에 새 Nuxt 프로젝트를 설정할 수 있습니다.

#### 사전 준비 사항 %{prerequisites}%

- **Node.js** - [`20.x`](https://nodejs.org/en) 이상 (하지만 [활성 LTS 릴리스](https://github.com/nodejs/release#release-schedule)를 권장합니다)
- **텍스트 에디터** - 필수 IDE는 없지만, [공식 Vue 확장](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (이전 명칭 Volar)과 함께 사용하는 [Visual Studio Code](https://code.visualstudio.com/) 또는 [WebStorm](https://www.jetbrains.com/webstorm/)을 권장합니다. [다른 JetBrains IDE](https://www.jetbrains.com/ides/)와 함께 사용할 경우, 별도 설정 없이도 훌륭한 Nuxt 지원을 제공합니다.
- **터미널** - Nuxt 명령을 실행하기 위해 필요합니다

::note
  ::details
  :summary[최적의 설정을 위한 추가 참고 사항:]
  - **Node.js**: 짝수 버전(20, 22 등)을 사용하고 있는지 확인하세요.
  - **Nuxtr**: 커뮤니티에서 개발한 [Nuxtr 확장](https://marketplace.visualstudio.com/items?itemName=Nuxtr.nuxtr-vscode)을 설치하세요.
  - **WSL**: Windows를 사용하면서 HMR이 느리다면, [WSL (Windows Subsystem for Linux)](https://learn.microsoft.com/en-us/windows/wsl/install)을 사용해 보는 것을 고려해 보세요. 일부 성능 문제를 해결할 수 있습니다.
  - **Windows의 느린 DNS 해석**: Windows에서 로컬 개발 서버에 `localhost:3000` 대신 `127.0.0.1`을 사용하면 브라우저에서 훨씬 더 빠른 로딩 경험을 얻을 수 있습니다.
  ::
::

터미널을 열고(만약 [Visual Studio Code](https://code.visualstudio.com)를 사용 중이라면, [통합 터미널](https://code.visualstudio.com/docs/terminal/basics)을 열 수 있습니다) 다음 명령을 사용해 새 스타터 프로젝트를 생성하세요:

::code-group{sync="pm"}

```bash [npm]
npm create nuxt@latest <project-name>
```

```bash [yarn]
yarn create nuxt@latest <project-name>
```

```bash [pnpm]
pnpm create nuxt@latest <project-name>
```

```bash [bun]
bun create nuxt@latest <project-name>
```

```bash [deno]
deno -A npm:create-nuxt@latest <project-name>
```

::

::tip
또는 [nuxt.new](https://nuxt.new)를 열고 안내에 따라 다른 스타터나 테마를 찾을 수도 있습니다.
::

Visual Studio Code에서 프로젝트 폴더를 여세요:

```bash [Terminal]
code <project-name>
```

또는 터미널에서 새 프로젝트 디렉터리로 이동하세요:

```bash
cd <project-name>
```

## 개발 서버 %{development-server}%

이제 Nuxt 앱을 개발 모드로 실행할 수 있습니다:

::code-group{sync="pm"}

```bash [npm]
npm run dev -- -o
```

```bash [yarn]
yarn dev --open
```

```bash [pnpm]
pnpm dev -o
```

```bash [bun]
bun run dev -o

# 개발 중에 Bun 런타임을 사용하려면
# bun --bun run dev -o
```

```bash [deno]
deno run dev -o
```
::

::tip{icon="i-lucide-circle-check"}
잘하셨습니다! <http://localhost:3000> 주소로 브라우저 창이 자동으로 열릴 것입니다.
::
