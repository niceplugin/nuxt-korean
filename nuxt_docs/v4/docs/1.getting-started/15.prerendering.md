Nuxt는 애플리케이션의 일부 페이지를 빌드 시 렌더링할 수 있게 해줍니다. Nuxt는 요청이 들어오면 즉석에서 생성하는 대신 미리 빌드된 페이지를 제공합니다.

:read-more{title="Nuxt 렌더링 모드" to="/docs/4.x/guide/concepts/rendering"}

## 크롤링 기반 프리렌더링 %{#crawl-based-pre-rendering}%

[`nuxt generate` 명령](/docs/4.x/api/commands/generate)을 사용하면 [Nitro](/docs/4.x/guide/concepts/server-engine) 크롤러를 이용해 애플리케이션을 빌드하고 프리렌더링할 수 있습니다. 이 명령은 `nitro.static` 옵션을 `true`로 설정한 `nuxt build` 또는 `nuxt build --prerender` 실행과 유사합니다.

이렇게 하면 사이트를 빌드하고, nuxt 인스턴스를 띄운 다음, 기본적으로 루트 페이지 `/`와 그 페이지가 링크하는 사이트의 모든 페이지, 그리고 그 페이지들이 다시 링크하는 페이지들을 차례로 프리렌더링합니다.

::code-group{sync="pm"}

```bash [npm]
npx nuxt generate
```

```bash [yarn]
yarn nuxt generate
```

```bash [pnpm]
pnpm nuxt generate
```

```bash [bun]
bun x nuxt generate
```

```bash [deno]
deno x nuxt generate
```

::

이제 `.output/public` 디렉터리를 어떤 정적 호스팅 서비스에든 배포하거나 `npx serve .output/public`으로 로컬에서 미리 볼 수 있습니다.

Nitro 크롤러의 동작 방식:

1. 애플리케이션의 루트 라우트(`/`), `~/pages` 디렉터리의 비동적 페이지, `nitro.prerender.routes` 배열의 기타 라우트 HTML을 로드합니다.
2. HTML과 `payload.json`을 `~/.output/public/` 디렉터리에 저장하여 정적으로 제공할 수 있게 합니다.
3. HTML에서 다른 라우트로 이동할 수 있는 모든 앵커 태그(`<a href="...">`)를 찾습니다.
4. 더 이상 크롤링할 앵커 태그가 없을 때까지 찾은 각 앵커 태그에 대해 1~3단계를 반복합니다.

이는 발견 가능한 페이지에서 링크되지 않은 페이지는 자동으로 프리렌더링할 수 없기 때문에 중요합니다.

### Payload 추출 %{#payload-extraction}%

Nuxt는 다음에 대해 HTML과 함께 `_payload.json`을 생성합니다:
- 프리렌더링된 라우트 (빌드 시)
- ISR/SWR 라우트 (첫 요청 시)

Payload에는 `useAsyncData`와 `useFetch`의 직렬화된 데이터가 포함됩니다. 클라이언트 측 내비게이션은 데이터를 다시 가져오는 대신 이 캐시된 payload를 로드합니다. `pages/[...slug].vue` 같은 동적 라우트는 route rules로 `'/**': { isr: true }`처럼 설정하세요.

::read-more{to="/docs/4.x/api/commands/generate#nuxt-generate"}
`nuxt generate` 명령에 대해 더 알아보세요.
::

### 선택적 프리렌더링 %{#selective-pre-rendering}%

빌드 중 [Nitro](/docs/4.x/guide/concepts/server-engine)가 가져와 프리렌더링할 라우트를 수동으로 지정하거나, `nuxt.config` 파일에서 `/dynamic`처럼 프리렌더링하고 싶지 않은 라우트를 무시할 수 있습니다:

```ts twoslash [nuxt.config.ts]
// @errors: 2353
export default defineNuxtConfig({
  nitro: {
    prerender: {
      routes: ['/user/1', '/user/2'],
      ignore: ['/dynamic'],
    },
  },
})
```

이를 `crawlLinks` 옵션과 결합하면 크롤러가 발견할 수 없는 `/sitemap.xml`이나 `/robots.txt` 같은 라우트 집합도 프리렌더링할 수 있습니다:

```ts twoslash [nuxt.config.ts]
// @errors: 2353
export default defineNuxtConfig({
  nitro: {
    prerender: {
      crawlLinks: true,
      routes: ['/sitemap.xml', '/robots.txt'],
    },
  },
})
```

`nitro.prerender`를 `true`로 설정하는 것은 `nitro.prerender.crawlLinks`를 `true`로 설정하는 것과 유사합니다.

::read-more{to="https://nitro.build/config#prerender"}
Nitro 문서에서 프리렌더링에 대해 더 알아보세요.
::

마지막으로 routeRules를 사용해 이를 수동으로 설정할 수도 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    // prerender를 true로 설정하면 프리렌더링되도록 구성합니다
    '/rss.xml': { prerender: true },
    // false로 설정하면 프리렌더링에서 제외되도록 구성합니다
    '/this-DOES-NOT-get-prerendered': { prerender: false },
    // /blog 아래의 모든 항목은
    // 다른 페이지에서 링크되어 있다면 프리렌더링됩니다
    '/blog/**': { prerender: true },
  },
})
```

::read-more{to="https://nitro.build/config#routerules"}
Nitro의 `routeRules` 설정에 대해 더 알아보세요.
::

축약형으로는 페이지 파일에서 [`defineRouteRules`](/docs/4.x/api/utils/define-route-rules)를 사용해 이것을 설정할 수도 있습니다.

::read-more{to="/docs/4.x/guide/going-further/experimental-features#inlinerouterules" icon="i-lucide-star"}
이 기능은 실험적이며, 사용하려면 `nuxt.config`에서 `experimental.inlineRouteRules` 옵션을 활성화해야 합니다.
::

```vue [app/pages/index.vue]
<script setup>
// 또는 페이지 수준에서 설정
defineRouteRules({
  prerender: true,
})
</script>

<template>
  <div>
    <h1>홈페이지</h1>
    <p>빌드 시 프리렌더링됨</p>
  </div>
</template>
```

이는 다음과 같이 변환됩니다:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    '/': { prerender: true },
  },
})
```

## 런타임 프리렌더 설정 %{#runtime-prerender-configuration}%

### `prerenderRoutes` %{#prerenderroutes}%

[Nuxt context](/docs/4.x/guide/going-further/nuxt-app#the-nuxt-context) 내부 런타임에서 이를 사용해 Nitro가 프리렌더링할 라우트를 더 추가할 수 있습니다.

```vue [app/pages/index.vue]
<script setup>
prerenderRoutes(['/some/other/url'])
prerenderRoutes('/api/content/article/my-article')
</script>

<template>
  <div>
    <h1>이 페이지가 프리렌더링될 때 다른 라우트도 프리렌더링 대상으로 등록합니다</h1>
  </div>
</template>
```

:read-more{title="prerenderRoutes" to="/docs/4.x/api/utils/prerender-routes"}

### `prerender:routes` Nuxt hook %{#prerender-routes-nuxt-hook}%

추가 라우트를 등록하기 위해 프리렌더링 전에 호출됩니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  hooks: {
    async 'prerender:routes' (ctx) {
      const { pages } = await fetch('https://api.some-cms.com/pages').then(
        res => res.json(),
      )
      for (const page of pages) {
        ctx.routes.add(`/${page.name}`)
      }
    },
  },
})
```

### `prerender:generate` Nitro hook %{#prerender-generate-nitro-hook}%

프리렌더링 중 각 라우트마다 호출됩니다. 프리렌더링되는 각 라우트를 세밀하게 처리하는 데 사용할 수 있습니다.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  nitro: {
    hooks: {
      'prerender:generate' (route) {
        if (route.route?.includes('private')) {
          route.skip = true
        }
      },
    },
  },
})
```
