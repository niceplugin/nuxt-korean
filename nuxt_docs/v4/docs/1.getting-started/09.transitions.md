Nuxt는 Vue의 [`<Transition>`](https://vuejs.org/guide/built-ins/transition#the-transition-component) 컴포넌트를 활용해 페이지와 레이아웃 사이에 트랜지션을 적용합니다.
::

## 페이지 트랜지션 %{#page-transitions}%

페이지 트랜지션을 활성화하면 모든 [pages](/docs/4.x/directory-structure/app/pages)에 자동 트랜지션을 적용할 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: { name: 'page', mode: 'out-in' },
  },
})
```

::note
레이아웃과 페이지를 함께 변경하는 경우 여기에서 설정한 페이지 트랜지션은 실행되지 않습니다. 대신 [레이아웃 트랜지션](/docs/4.x/getting-started/transitions#layout-transitions)을 설정해야 합니다.
::

페이지 사이에 트랜지션을 추가하려면 [`app.vue`](/docs/4.x/directory-structure/app/app)에 다음 CSS를 추가하세요:

::code-group

```vue [app/app.vue]
<template>
  <NuxtPage />
</template>

<style>
.page-enter-active,
.page-leave-active {
  transition: all 0.4s;
}
.page-enter-from,
.page-leave-to {
  opacity: 0;
  filter: blur(1rem);
}
</style>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>홈 페이지</h1>
    <NuxtLink to="/about">소개 페이지</NuxtLink>
  </div>
</template>
```

```vue [app/pages/about.vue]
<template>
  <div>
    <h1>소개 페이지</h1>
    <NuxtLink to="/">홈 페이지</NuxtLink>
  </div>
</template>
```

## 레이아웃 트랜지션 %{#layout-transitions}%

레이아웃 트랜지션을 활성화하면 모든 [layouts](/docs/4.x/directory-structure/app/layouts)에 자동 트랜지션을 적용할 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    layoutTransition: { name: 'layout', mode: 'out-in' },
  },
})
```

페이지와 레이아웃 사이에 트랜지션을 추가하려면 [`app.vue`](/docs/4.x/directory-structure/app/app)에 다음 CSS를 추가하세요:

::code-group

```vue [app/app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>

<style>
.layout-enter-active,
.layout-leave-active {
  transition: all 0.4s;
}
.layout-enter-from,
.layout-leave-to {
  filter: grayscale(1);
}
</style>
```

```vue [app/layouts/default.vue]
<template>
  <div>
    <pre>기본 레이아웃</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: lightgreen;
}
</style>
```

```vue [app/layouts/orange.vue]
<template>
  <div>
    <pre>주황 레이아웃</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: #eebb90;
  padding: 20px;
  height: 100vh;
}
</style>
```

```vue [app/pages/index.vue]
<template>
  <div>
    <h1>홈 페이지</h1>
    <NuxtLink to="/about">소개 페이지</NuxtLink>
  </div>
</template>
```

```vue [app/pages/about.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'orange',
})
</script>

<template>
  <div>
    <h1>소개 페이지</h1>
    <NuxtLink to="/">홈 페이지</NuxtLink>
  </div>
</template>
```

## 전역 설정 %{#global-settings}%

`nuxt.config`를 사용해 이 기본 트랜지션 이름들을 전역으로 사용자 정의할 수 있습니다.

`pageTransition`과 `layoutTransition` 키는 모두 [`TransitionProps`](https://vuejs.org/api/built-in-components#transition)를 JSON 직렬화 가능한 값으로 받으며, 여기에 사용자 정의 CSS 트랜지션의 `name`, `mode`, 그 밖의 유효한 transition-props를 전달할 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: {
      name: 'fade',
      mode: 'out-in', // 기본값
    },
    layoutTransition: {
      name: 'slide',
      mode: 'out-in', // 기본값
    },
  },
})
```

::warning
`name` 속성을 변경하면 CSS 클래스 이름도 그에 맞게 바꿔야 합니다.
::

전역 트랜지션 속성을 재정의하려면 `definePageMeta`를 사용해 단일 Nuxt 페이지의 페이지 또는 레이아웃 트랜지션을 정의하고, `nuxt.config` 파일에 전역으로 정의된 페이지 또는 레이아웃 트랜지션을 덮어쓰세요.

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'bounce',
    mode: 'out-in', // 기본값
  },
})
</script>
```

## 트랜지션 비활성화 %{#disable-transitions}%

특정 라우트에 대해서는 `pageTransition`과 `layoutTransition`을 비활성화할 수 있습니다:

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: false,
  layoutTransition: false,
})
</script>
```

또는 `nuxt.config`에서 전역으로 비활성화할 수 있습니다:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: false,
    layoutTransition: false,
  },
})
```

## JavaScript 훅 %{#javascript-hooks}%

고급 사용 사례에서는 JavaScript 훅을 사용해 Nuxt 페이지용으로 매우 동적이고 사용자 정의된 트랜지션을 만들 수 있습니다.

이 방식은 [GSAP](https://gsap.com) 같은 JavaScript 애니메이션 라이브러리를 활용하기에 적합합니다.

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'custom-flip',
    mode: 'out-in',
    onBeforeEnter: (el) => {
      console.log('진입 전...')
    },
    onEnter: (el, done) => {},
    onAfterEnter: (el) => {},
  },
})
</script>
```

::tip
`Transition` 컴포넌트에서 사용할 수 있는 추가 [JavaScript 훅](https://vuejs.org/guide/built-ins/transition#javascript-hooks)을 더 알아보세요.
::

## 동적 트랜지션 %{#dynamic-transitions}%

조건부 로직을 사용해 동적 트랜지션을 적용하려면 인라인 [middleware](/docs/4.x/directory-structure/app/middleware)를 활용해 `to.meta.pageTransition`에 다른 트랜지션 이름을 할당할 수 있습니다.

::code-group

```vue twoslash [pages/[id\\].vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'slide-right',
    mode: 'out-in',
  },
  middleware (to, from) {
    if (to.meta.pageTransition && typeof to.meta.pageTransition !== 'boolean') {
      to.meta.pageTransition.name = +to.params.id! > +from.params.id! ? 'slide-left' : 'slide-right'
    }
  },
})
</script>

<template>
  <h1>#{{ $route.params.id }}</h1>
</template>

<style>
.slide-left-enter-active,
.slide-left-leave-active,
.slide-right-enter-active,
.slide-right-leave-active {
  transition: all 0.2s;
}
.slide-left-enter-from {
  opacity: 0;
  transform: translate(50px, 0);
}
.slide-left-leave-to {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-enter-from {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-leave-to {
  opacity: 0;
  transform: translate(50px, 0);
}
</style>
```

```vue [app/layouts/default.vue]
<script setup lang="ts">
const route = useRoute()
const id = computed(() => Number(route.params.id || 1))
const prev = computed(() => '/' + (id.value - 1))
const next = computed(() => '/' + (id.value + 1))
</script>

<template>
  <div>
    <slot />
    <div v-if="$route.params.id">
      <NuxtLink :to="prev">⬅️</NuxtLink> |
      <NuxtLink :to="next">➡️</NuxtLink>
    </div>
  </div>
</template>
```

::

이제 페이지는 다음 id로 이동할 때 `slide-left` 트랜지션을, 이전 id로 이동할 때 `slide-right`를 적용합니다:

## NuxtPage와 함께 쓰는 트랜지션 %{#transition-with-nuxtpage}%

`app.vue`에서 `<NuxtPage />`를 사용할 때는 `transition` prop으로 트랜지션을 설정해 전역 활성화할 수 있습니다.

```vue [app/app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage
        :transition="{
          name: 'bounce',
          mode: 'out-in',
        }"
      />
    </NuxtLayout>
  </div>
</template>
```

::note
이 페이지 트랜지션은 개별 페이지에서 `definePageMeta`로 재정의할 수 없다는 점을 기억하세요.
::

## View Transitions API(실험적) %{#view-transitions-api-experimental}%

Nuxt는 [**View Transitions API**](https://developer.chrome.com/docs/web-platform/view-transitions)의 실험적 구현을 함께 제공합니다([MDN](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API) 참고). 이것은 서로 다른 페이지의 관련 없는 요소 사이에서도 전환할 수 있는, 브라우저 네이티브 트랜지션을 구현하는 흥미로운 새로운 방법입니다.

[StackBlitz](https://stackblitz.com/edit/nuxt-view-transitions)에서 데모를 확인할 수 있습니다.

Nuxt 통합은 설정 파일의 `experimental.viewTransition` 옵션으로 활성화할 수 있습니다:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  experimental: {
    viewTransition: true,
  },
})
```

가능한 값은 `false`, `true`, `'always'`입니다.

`true`로 설정하면 사용자의 브라우저가 `prefers-reduced-motion: reduce`에 해당할 때 Nuxt는 트랜지션을 적용하지 않습니다(권장). `always`로 설정하면 Nuxt는 항상 트랜지션을 적용하며, 사용자 선호를 존중하는 책임은 개발자에게 있습니다.

기본적으로 view transition은 모든 [pages](/docs/4.x/directory-structure/app/pages)에서 활성화되지만, 다른 전역 기본값을 설정할 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    // view transition을 전역으로 비활성화하고 페이지별로 opt-in
    viewTransition: false,
  },
})
```

페이지의 [`definePageMeta`](/docs/4.x/api/utils/define-page-meta)에서 `viewTransition` 키를 설정하면 페이지별 기본 `viewTransition` 값을 재정의할 수 있습니다:

```vue twoslash [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: false,
})
</script>
```

::warning
페이지별 view transition 재정의는 `experimental.viewTransition` 옵션을 활성화한 경우에만 효과가 있습니다.
::

### View Transition 타입 %{#view-transition-types}%

[View transition 타입](https://developer.chrome.com/blog/view-transitions-update-io24#view-transition-types)을 사용하면 내비게이션 유형에 따라 서로 다른 CSS 애니메이션을 적용할 수 있습니다. 이는 비대칭 트랜지션(예: 앞으로 이동할 때와 뒤로 이동할 때 다른 애니메이션)을 만드는 데 유용합니다.

타입은 [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition)에 설정되며, CSS에서는 [`:active-view-transition-type()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:active-view-transition-type) 의사 클래스 선택자로 이를 대상으로 지정할 수 있습니다.

`nuxt.config.ts`에서 전역 기본 타입을 설정할 수 있습니다:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    viewTransition: {
      enabled: true,
      types: ['slide'],
    },
  },
})
```

또는 `definePageMeta`를 사용해 페이지별 타입을 설정할 수 있습니다. 페이지별 타입은 동적 동작을 위해 정적 배열과 함수를 모두 지원합니다:

```vue twoslash [pages/detail.vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: {
    enabled: true,
    // 이 페이지가 포함된 모든 트랜지션에 적용되는 타입
    types: ['slide'],
    // 이 페이지로 이동할 때만 적용되는 타입
    toTypes: ['slide-in'],
    // 이 페이지에서 벗어날 때만 적용되는 타입
    fromTypes: ['slide-out'],
  },
})
</script>
```

`definePageMeta`에서 `types`, `toTypes`, `fromTypes`에 함수를 사용해 라우트 기반으로 타입을 동적으로 결정할 수도 있습니다:

```vue twoslash [pages/[id].vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: {
    enabled: true,
    toTypes: (to, from) => {
      // 더 큰 ID로 갈 때는 왼쪽 슬라이드, 아니면 오른쪽 슬라이드
      return Number(to.params.id) > Number(from.params.id)
        ? ['slide-left']
        : ['slide-right']
    },
  },
})
</script>
```

그런 다음 CSS에서 이 타입들을 대상으로 지정하세요:

```css
/* 기본 크로스페이드 */
::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 0.3s;
}

/* 왼쪽 슬라이드 애니메이션 */
html:active-view-transition-type(slide-left) {
  &::view-transition-old(root) {
    animation: slide-out-left 0.3s ease-in-out;
  }
  &::view-transition-new(root) {
    animation: slide-in-right 0.3s ease-in-out;
  }
}

/* 오른쪽 슬라이드 애니메이션 */
html:active-view-transition-type(slide-right) {
  &::view-transition-old(root) {
    animation: slide-out-right 0.3s ease-in-out;
  }
  &::view-transition-new(root) {
    animation: slide-in-left 0.3s ease-in-out;
  }
}
```

::note
`types`, `toTypes`, `fromTypes`의 함수 값은 `definePageMeta`에서만 동작하며, `nuxt.config.ts`에서는 사용할 수 없습니다(여기서는 정적 `string[]`만 지원).
::

`page:view-transition:start` 훅은 [`ViewTransition`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition) 객체에 접근할 수 있게 해주며, 여기에는 런타임에 읽거나 수정할 수 있는 [`types`](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition/types) 속성(`ViewTransitionTypeSet`)이 포함됩니다:

```ts [plugins/view-transition.client.ts]
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('page:view-transition:start', (transition) => {
    // 런타임에 타입을 읽거나 수정
    console.log([...transition.types])
  })
})
```

새로운 View Transitions API와 같은 결과를 얻기 위해 `pageTransition`, `layoutTransition` 같은 Vue 트랜지션도 함께 사용 중이라면(위 참고), 사용자의 브라우저가 더 새로운 네이티브 웹 API를 지원할 때 Vue 트랜지션을 _비활성화_ 하고 싶을 수 있습니다. 이를 위해 `~/middleware/disable-vue-transitions.global.ts`를 만들고 다음 내용을 추가할 수 있습니다:

```ts
export default defineNuxtRouteMiddleware((to) => {
  if (import.meta.server || !document.startViewTransition) {
    return
  }

  // 내장 Vue 트랜지션 비활성화
  to.meta.pageTransition = false
  to.meta.layoutTransition = false
})
```
