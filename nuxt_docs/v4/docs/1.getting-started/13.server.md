## Nitro 기반 %{#powered-by-nitro}%

![서버 엔진](/assets/docs/getting-started/server.svg)

Nuxt의 서버는 [Nitro](https://github.com/nitrojs/nitro)입니다. 원래 Nuxt를 위해 만들어졌지만 이제는 [UnJS](https://unjs.io)의 일부가 되었고 다른 프레임워크에도 열려 있으며, 단독으로 사용할 수도 있습니다.

Nitro를 사용하면 Nuxt는 강력한 기능을 얻게 됩니다.

- 앱의 서버 측 부분에 대한 완전한 제어
- 어떤 제공업체든 가능한 범용 배포(다수는 제로 설정)
- 하이브리드 렌더링

Nitro는 내부적으로 고성능과 이식성을 위해 만들어진 최소한의 H(TTP) 프레임워크 [h3](https://github.com/h3js/h3)를 사용합니다.

## 서버 엔드포인트와 미들웨어 %{#server-endpoints-middleware}%

API 엔드포인트부터 미들웨어까지, Nuxt 앱의 서버 전용 부분을 쉽게 관리할 수 있습니다.

엔드포인트와 미들웨어는 모두 다음과 같이 정의할 수 있습니다.

```ts twoslash [server/api/test.ts]
import { defineEventHandler } from 'nitro/h3'

export default defineEventHandler(async (event) => {
  // ... 여기에서 원하는 작업을 수행하세요
})
```

그리고 `text`, `json`, `html`, 심지어 `stream`도 직접 반환할 수 있습니다.

별도 설정 없이도 Nuxt 애플리케이션의 다른 부분처럼 **핫 모듈 교체**와 **자동 import**를 지원합니다.

## 범용 배포 %{#universal-deployment}%

Nitro는 베어메탈 서버부터 엣지 네트워크까지 어디에나 Nuxt 앱을 배포할 수 있게 해주며, 시작 시간도 몇 밀리초에 불과합니다. 매우 빠릅니다.

:read-more{to="/blog/nuxt-on-the-edge"}

다양한 클라우드 제공업체와 서버용으로 Nuxt 앱을 빌드할 수 있는 프리셋이 15개 이상 있으며, 예를 들면 다음과 같습니다.

- [Cloudflare Workers](https://workers.cloudflare.com)
- [Netlify Functions](https://www.netlify.com/platform/core/functions/)
- [Vercel Cloud](https://vercel.com/home)

또는 다른 런타임용으로도 사용할 수 있습니다.

## 하이브리드 렌더링 %{#hybrid-rendering}%

Nitro에는 `routeRules`라는 강력한 기능이 있어, Nuxt 앱의 각 라우트가 어떻게 렌더링될지(그리고 그 외 동작도) 사용자 지정하는 규칙 집합을 정의할 수 있습니다.

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    // SEO를 위해 빌드 시 생성
    '/': { prerender: true },
    // 1시간 동안 캐시
    '/api/*': { cache: { maxAge: 60 * 60 } },
    // 404를 피하기 위한 리디렉션
    '/old-page': {
      redirect: { to: '/new-page', status: 302 },
    },
    // ...
  },
})
```

::read-more{to="/docs/4.x/guide/concepts/rendering#hybrid-rendering"}
라우트의 렌더링 모드를 사용자 지정할 수 있는 모든 route rule을 알아보세요.
::

또한 `ssr`, `appMiddleware`, `noScripts`처럼 페이지를 HTML로 렌더링할 때의 동작을 바꾸는 Nuxt 전용 route rule도 있습니다.

일부 route rule(`appMiddleware`, `redirect`, `prerender`)은 클라이언트 측 동작에도 영향을 줍니다.

Nitro는 서버 사이드 렌더링뿐 아니라 사전 렌더링을 위해서도 앱 빌드에 사용됩니다.
